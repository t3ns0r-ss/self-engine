## ac-abc099_b Stone Monument (tier 1, pattern closed-form, set practice)
- Budget: O(1).
- Idea: Adjacent towers differ by the index: tower i is i(i+1)/2 tall, and b − a is the height difference, so the east tower is index d = b − a. Its height is d(d+1)/2; snow = d(d+1)/2 − b.
- Techniques: 0.2, 0.1
- Needs this topic because: replacing a search over 999 towers by the closed form of 1 + 2 + … + d.
- Tier reasoning: ABC B.

## ac-abc167_b Easy Linear Programming (tier 1, pattern closed-form, set practice)
- Budget: A + B + C ≤ 2·10^9 → a loop over K picks is too slow; O(1).
- Idea: Take 1s first, then 0s, then −1s: if K ≤ A answer K; else if K ≤ A + B answer A; else A − (K − A − B).
- Techniques: 0.2, 0.1
- Needs this topic because: K up to 2·10^9 makes the simulation loop too slow, so the count is written directly.
- Tier reasoning: ABC B.

## ac-abc103_c Modulo Summation (tier 2, pattern closed-form, set practice)
- Budget: N ≤ 3000, a_i ≤ 10^5 → trying every m is unbounded; O(N).
- Idea: m mod a ≤ a − 1, and m = (product of all a_i) − 1 reaches every bound at once, so the maximum is Σ(a_i − 1). Nothing needs to be computed for m itself.
- Techniques: 0.2
- Needs this topic because: bounding the sum and seeing the bound is reached, instead of searching.
- Tier reasoning: ABC C.

## ac-abc405_c Sum of Product (tier 2, pattern closed-form, set practice)
- Budget: N ≤ 3·10^5 → O(N²) pairs (4.5·10^10) is too slow; O(N).
- Idea: Σ_{i<j} A_iA_j = (S² − Σ A_i²) / 2 with S = Σ A_i ≤ 3·10^9, so S² ≤ 9·10^18 fits in long long (unsigned is safer).
- Techniques: 0.2, 0.1
- Needs this topic because: the pair sum must be rewritten in closed form to meet the budget.
- Tier reasoning: ABC C.

## ac-abc130_c Rectangle Cutting (tier 2, pattern closed-form, set practice)
- Budget: O(1).
- Idea: Every line through the rectangle's centre halves it, and some line through (x, y) passes through the centre, so the answer is W·H/2. The cut is not unique only when (x, y) is the centre: 2x = W and 2y = H.
- Techniques: 0.2, 0.1
- Needs this topic because: a direct formula replaces any search over lines.
- Tier reasoning: ABC C.

## cses-1072 Two Knights (tier 2, pattern closed-form, set practice)
- Budget: n ≤ 10^4, one answer per k → O(1) per k.
- Idea: Pairs on a k×k board: C(k², 2). Attacking pairs: each 2×3 or 3×2 block holds 2 attacking pairs, so 4(k − 1)(k − 2). Answer k²(k²−1)/2 − 4(k−1)(k−2), in long long (k² reaches 10^8, so the product reaches 5·10^15).
- Techniques: 0.2, 0.1
- Needs this topic because: counting pairs per board would be O(k⁴); the closed form is O(1).
- Tier reasoning: CSES Introductory, mid-section; needs the block-counting insight.

## cses-1071 Number Spiral (tier 2, pattern closed-form, set practice)
- Budget: t ≤ 10^5 tests, coordinates ≤ 10^9 → O(1) per test.
- Idea: Layer L = max(y, x) ends at value L². Along that layer the values run in one direction when L is even and the other when L is odd; the answer is L² − (offset) or (L−1)² + (offset) by the parity of L and which coordinate is the larger. Values reach 10^18: long long.
- Techniques: 0.2, 0.1
- Needs this topic because: the spiral cannot be built; each cell's value must come from a formula.
- Tier reasoning: CSES Introductory; the case split on layer parity is a step above tier 1.

## cf-1475B New Year's Number (tier 3, pattern closed-form, set practice) †
- Budget: t tests, n ≤ 10^6 (recalled) → O(1) per test.
- Idea: n = 2020a + 2021b = 2020(a + b) + b. Let q = n / 2020 and r = n mod 2020; then b = r and a + b = q works iff r ≤ q.
- Techniques: 0.2, 0.1
- Needs this topic because: rewriting the sum removes the search over a and b.
- Tier reasoning: rating 900, Phase 0 tier 3.

## cf-1328B K-th Beautiful String (tier 5, pattern closed-form, set practice) †

## ac-abc330_c Minimize Abs 2 (tier 2, pattern budget-from-constraints, set practice)

- Needs this topic because: one loop over √D values instead of two.
