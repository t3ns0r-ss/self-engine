## ac-abc384_g Abs Sum (tier 5, pattern mo-offline, set practice)
- Budget: N ≤ 10^5, K ≤ 10^4, values ≤ 2·10^8.
- Idea: Query (X, Y): Σ_{i≤X} Σ_{j≤Y} |A_i − B_j|. Treat (X, Y) as a range-like pair of two moving pointers and order the queries as in Mo's algorithm (block of X, then Y). Keep two Fenwick trees over compressed values, one for A[1..X] and one for B[1..Y], each storing counts and sums. Moving X by one adds or removes Σ_{j≤Y}|A_X − B_j|, read from the B tree (count and sum below and above A_X); moving Y is symmetric. O(N√K log N).
- Techniques: 5.6, 5.2, 1.1
- Needs this topic because: the answer changes by a cheap computable amount when either pointer moves one step; queries are offline.
- Tier reasoning: ABC G with difficulty 2343, tier 5; practice only.

## ac-abc405_g Range Shuffle Query (tier 5, pattern mo-offline, set practice)
- Budget: N, Q ≤ 2.5·10^5, A_i, X ≤ N, answers modulo 998244353.
- Idea: For query (L, R, X) keep the elements of A[L..R] with value < X; the number of distinct arrangements is (Σ c_v)! / Π c_v! over v < X. Mo's algorithm over (L, R) maintains the counts c_v; the product of 1/c_v! over v < X and the sum of c_v over v < X must be readable fast. Store them per value bucket: a point change multiplies one value's factor by the inverse of its new count (adding) or by the old count (removing) and updates its bucket, O(1); a query combines whole buckets below X and single values in the last bucket, O(√N). Precompute factorials and inverses. O(N√Q + Q√N).
- Techniques: 5.6, 5.5, 2.2
- Needs this topic because: Mo's algorithm with an O(1)-update, O(√N)-query structure on values (the square-root buckets of topic 5.5).
- Tier reasoning: ABC G with difficulty 2354, tier 5; practice only.

## ac-joisc2014_c 歴史の研究 (Historical Research) (tier 5, pattern mo-variants, set practice)

## ac-abc477_g Frequency Query on Tree (tier 4, pattern mo-variants, set reserved, for checkpoint)
- Budget: N, Q ≤ 2·10^5, values ≤ N, a ≤ b per query.
- Idea: Query (s, t, a, b): the number of values y whose count on the path from s to t is between a and b. Mo's algorithm on the Euler tour (Theorem 5.6.4, with the lowest common ancestor added on its own). Keep cnt[y] and, for each count c, how many values have it, in blocks of about √N counts: a step changes two entries in O(1), and a query adds up whole blocks and single entries in O(√N). O((N + Q)√N) overall.
- Techniques: 5.6, 4.6, 4.7
- Needs this topic because: path queries on a tree with a count of counts; the statement was read on 2026-11-15.
- Tier reasoning: ABC G with AtCoder Problems difficulty 2226; tier 4.

## ac-abc242_g Range Pairing Query (tier 4, pattern mo-offline, set reserved, for lookalike)
- Budget: N ≤ 10^5, Q ≤ 10^6.
