# Bank notes: topic 5.4

Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## cf-220B Little Elephant and Array (tier 2, pattern threshold-split, set practice) †
- Budget: n, m ≤ 10^5 (recalled).
- Idea: (recalled) A value x can count only if it occurs at least x times overall, so fewer than √(2n) values qualify. Keep prefix counts for each candidate and answer every query by checking all candidates.
- Techniques: 5.4, 1.2
- Needs this topic because: few "large" candidates make per-candidate work affordable.
- Tier reasoning: rating 1800.

## cf-1514D Cut and Stick (tier 3, pattern mo, set practice) †
- Budget: n, q ≤ 3·10^5 (recalled).
- Idea: (recalled) With f = maximum frequency in [l, r] and len its length, the answer is max(1, 2f − len). Find f with Mo's algorithm: cnt[x] and cntOfCnt[c]; on removal, lower the current max when its cntOfCnt becomes 0.
- Techniques: 5.4
- Needs this topic because: maximum frequency maintained under Mo's add/remove.
- Tier reasoning: rating 2000.

## cf-86D Powerful array (tier 4, pattern mo, set practice) †
- Budget: n, t ≤ 2·10^5, values ≤ 10^6 (recalled).
- Idea: (recalled) Power = Σ cnt_s² · s. Mo's algorithm: adding s changes the answer by (2·cnt_s + 1)·s, removing by −(2·cnt_s − 1)·s. 64-bit.
- Techniques: 5.4
- Needs this topic because: an O(1) add/remove aggregate answered offline.
- Tier reasoning: rating 2200.

## cf-617E XOR and Favorite Number (tier 4, pattern mo, set reserved, for checkpoint) †
- Budget: n, m ≤ 10^5, values ≤ 10^6 (recalled).
- Idea: (recalled) Prefix XORs P; [i, j] works iff P_{i−1} XOR P_j = k. Run Mo's algorithm over prefix indices [l − 1, r] with cnt of each prefix value; adding P adds cnt[P XOR k].
- Techniques: 5.4, 1.7
- Needs this topic because: pair counting with Mo's algorithm on prefix values.
- Tier reasoning: rating 2200.

## cf-375D Tree and Queries (tier 5, pattern mo, set practice) †
- Budget: n, m ≤ 10^5 (recalled).
- Idea: (recalled) Euler tour turns a subtree into a range. Mo's algorithm with cnt[colour] and ge[k] = number of colours with count ≥ k; adding a colour increments ge[cnt + 1] after raising cnt, removal does the reverse.
- Techniques: 5.4, 4.5
- Needs this topic because: Mo's algorithm on Euler-tour ranges.
- Tier reasoning: rating 2400.

## cf-877F Ann and Books (tier 5, pattern mo, set practice) †
- Budget: n, q ≤ 10^5 (recalled).
- Idea: (recalled) Prefix differences P (math +a, economics −a). Count pairs i < j in [l − 1, r] with P_j − P_i = k. Compress P, P − k and P + k beforehand so each Mo step is an array lookup.
- Techniques: 5.4, 1.2
- Needs this topic because: Mo's algorithm with precomputed neighbours to keep steps O(1).
- Tier reasoning: rating 2300.

## cf-1000F One Occurrence (tier 5, pattern mo, set practice) †
- Budget: n, q ≤ 5·10^5 (recalled).
- Idea: (recalled) Mo's algorithm with cnt[x]; keep values with cnt = 1 in a √-bucketed presence structure (O(1) update, O(√V) query to find any one). Print 0 if none.
- Techniques: 5.4
- Needs this topic because: Mo's algorithm combined with sqrt buckets on values.
- Tier reasoning: rating 2400.

## cf-1207F Remainder Problem (tier 3, pattern threshold-split, set practice) †
- Budget: q ≤ 5·10^5, values index ≤ 5·10^5 (recalled).
- Idea: (recalled) For moduli x ≤ √N keep a table small[x][y] updated on every add (√N work). For x > √N, sum a[y], a[y + x], … directly (≤ N/x terms).
- Techniques: 5.4
- Needs this topic because: the textbook small/large split.
- Tier reasoning: rating 2100.

## cf-797E Array Queries (tier 3, pattern threshold-split, set practice) †
- Budget: n, q ≤ 10^5 (recalled).
- Idea: (recalled) For k ≤ √n precompute steps[k][p] from right to left (steps[k][p] = 1 + steps[k][p + a_p + k]). For larger k simulate: fewer than n/k ≤ √n jumps.
- Techniques: 5.4, 3.2
- Needs this topic because: precompute small parameters, simulate large ones.
- Tier reasoning: rating 2000.

## cf-1921F Sum of Progression (tier 3, pattern threshold-split, set practice) †
- Budget: Σ n ≤ 10^5, Σ q ≤ 2·10^5 (recalled).
- Idea: (recalled) For d ≤ √n precompute suffix sums with step d of a_i and of a_i · (its index in the progression); a query is a difference of two suffix values. For large d sum directly (≤ n/d terms). 64-bit.
- Techniques: 5.4, 1.2
- Needs this topic because: step-d prefix sums only for small steps.
- Tier reasoning: rating 1900.

## cf-103D Time to Raid Cowavans (tier 4, pattern threshold-split, set practice) †
- Budget: n, p ≤ 3·10^5 (recalled).
- Idea: (recalled) Group queries by step b offline. For b ≤ √n, compute suffix sums with step b once per distinct b (reusing one array) and answer its queries; for large b sum directly. 64-bit.
- Techniques: 5.4, 1.1
- Needs this topic because: offline grouping keeps the small-step tables within memory.
- Tier reasoning: rating 2100.

## cf-1806E Tree Master (tier 4, pattern threshold-split, set practice) †
- Budget: n, q ≤ 10^5 (recalled).
- Idea: (recalled) f(x, y) = a_x·a_y + f(parent x, parent y) on equal depths. Memoise pairs only at depths with at most √n vertices (index pairs by position within the depth); deeper levels with many vertices have few such levels, so total work is O(n√n).
- Techniques: 5.4, 4.5
- Needs this topic because: memoise only where the state space is small.
- Tier reasoning: rating 2200.

## cf-1580C Train Maintenance (tier 4, pattern threshold-split, set reserved, for review) †
- Budget: n, m ≤ 2·10^5 (recalled).
- Idea: (recalled) A train with period x + y ≤ √m is tracked in a table cnt[period][day mod period] (√m work per day to read). Larger periods have ≤ m/(x + y) working intervals: add them to a difference array (and cancel on removal).
- Techniques: 5.4, 1.2
- Needs this topic because: small periods by residue table, large periods by direct ranges.
- Tier reasoning: rating 2200.

## cf-785E Anton and Permutation (tier 4, pattern blocks, set practice) †
- Budget: n ≤ 2·10^5, q ≤ 5·10^4 (recalled).
- Idea: (recalled) Swapping positions l < r changes inversions by counting values in (l, r) between the two swapped values. Split the array into √ blocks each kept sorted; count with binary search in full blocks and directly in partial ones; re-sort the two affected blocks.
- Techniques: 5.4
- Needs this topic because: block decomposition with sorted blocks.
- Tier reasoning: rating 2200.

## cf-1619H Permutation and Queries (tier 5, pattern blocks, set practice) †
- Budget: n, q ≤ 10^5 (recalled).
- Idea: (recalled) Store jump[i] = p applied √n times to i. A query moves by jumps of √n then single steps. A swap changes p at two points; fix the jump values of the √n predecessors of each (walk p⁻¹ backwards).
- Techniques: 5.4
- Needs this topic because: √-length jumps with local rebuilds.
- Tier reasoning: rating 2400.

## cf-342E Xenia and Tree (tier 5, pattern blocks, set practice) †
- Budget: n, m ≤ 10^5 (recalled).
- Idea: (recalled) Keep dist[] to the nearest red vertex from the last rebuild and a list of reds painted since. A query = min(dist[v], dist via LCA to each pending red). When the pending list reaches √m, rebuild dist with a multi-source BFS.
- Techniques: 5.4, 4.6, 4.1
- Needs this topic because: rebuild every √ operations, brute force in between.
- Tier reasoning: rating 2400.
