## ac-dp_q Flowers (tier 3, pattern prefix-max-transition, set practice)
- Budget: N ≤ 2·10^5, heights a permutation.
- Idea: dp[i] = a_i + max dp[j] over earlier j with h_j < h_i. A Fenwick tree of prefix maxima indexed by height gives each transition in O(log N). 64-bit.
- Techniques: 7.3, 5.2
- Needs this topic because: the canonical prefix-max transition.
- Tier reasoning: Educational DP Contest Q; judgement tier 3.

## cf-1667B Optimal Partition (tier 3, pattern prefix-max-transition, set practice) †

- Idea: (recalled) dp[i] = max over j < i of dp[j] + sign(p_i − p_j)·(i − j) for prefix sums p. Keep three max-structures over compressed prefix values: dp[j] − j (for p_j < p_i), dp[j] (equal), dp[j] + j (greater).
- Techniques: 7.3, 5.2, 1.2
- Needs this topic because: split the transition by sign and query each part by prefix.
- Tier reasoning: rating 2100.

## lc-find-maximum-non-decreasing-array-length Find Maximum Non-decreasing Array Length (tier 4, pattern window-transition, set reserved, for review)
- Budget: n up to 10^5.
- Idea: Let p be the prefix sums. If the last piece of the first i numbers ends at i and starts after j, the piece before it has sum last[j], and we need p_i − p_j ≥ last[j], i.e. p_i ≥ p_j + last[j]. The key p_j + last[j] is increasing along a deque of candidates; pop from the front while the next key is ≤ p_i. dp[i] = dp[j] + 1 and last[i] = p_i − p_j.
- Techniques: 7.3, 1.2, 1.6
- Needs this topic because: the allowed starts form a prefix of a monotone sequence of keys; a deque gives the best.
- Tier reasoning: LeetCode Hard.

## lc-minimum-sum-of-values-by-dividing-array Minimum Sum of Values by Dividing Array (tier 4, pattern window-transition, set reserved, for review)

- Techniques: 7.3, 5.3, 1.6
- Needs this topic because: a range minimum over the starts, from layer j − 1.
- Tier reasoning: LeetCode Hard.

## lc-sum-of-beautiful-subsequences Sum of Beautiful Subsequences (tier 4, pattern counting-with-tree, set reserved, for review)
- Budget: n up to 10^4, values up to 7·10^4.
- Idea: For each d count the strictly increasing subsequences whose elements are all multiples of d with a Fenwick tree (counting with a prefix sum over values), giving f(d). The number with gcd exactly g is g(d) = f(d) − sum of g(2d), g(3d), …; the answer is the sum of d · g(d). The elements used for d are the multiples of d, so the total is about n times the number of divisors.
- Techniques: 7.3, 5.2, 2.1
- Needs this topic because: counting with a Fenwick tree for each divisor, then a subtraction over multiples.
- Tier reasoning: LeetCode Hard.
