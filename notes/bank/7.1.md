## cf-1528A Parsa's Humongous Tree (tier 1, pattern subtree-dp, set practice) †
- Budget: Σ n ≤ 2·10^5 (recalled).
- Idea: (recalled) Some optimal choice uses only endpoints l_v or r_v. dp[v][0/1] = best beauty of v's subtree when v takes l_v / r_v; children add max over their two choices of dp[c][j] + |value_v − value_c|.
- Techniques: 7.1
- Needs this topic because: two-state DP over a rooted tree.
- Tier reasoning: rating 1600.

## cf-1946C Tree Cutting (tier 1, pattern subtree-dp, set practice) †
- Budget: Σ n ≤ 10^5 (recalled).
- Idea: (recalled) Binary search x. DFS returning the size of the current piece; when a subtree piece reaches ≥ x, cut it (count++) and return 0. Feasible if count ≥ k + 1 (counting the root's remainder only if ≥ x).
- Techniques: 7.1, 1.4
- Needs this topic because: greedy cuts computed bottom-up.
- Tier reasoning: rating 1600.

## cses-1130 Tree Matching (tier 2, pattern subtree-dp, set reserved, for later_drill)
- Budget: n ≤ 2·10^5.
- Idea: dp[v][0] = best matching in v's subtree with v unmatched, dp[v][1] with v matched to one child: dp[v][1] = dp[v][0] + max over c of (dp[c][0] + 1 − max(dp[c][0], dp[c][1])). (A greedy leaf matching also works.)
- Techniques: 7.1
- Needs this topic because: matching in a tree as a two-state DP.
- Tier reasoning: first CSES tree DP problem.
