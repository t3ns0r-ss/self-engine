Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## cses-1687 Company Queries I (tier 2, pattern kth-ancestor, set reserved, for lookalike)
- Budget: n, q ≤ 2·10^5, k ≤ n.
- Idea: up[j][v] = 2^j-th boss (up[0] = parent, 0 for none). Answer by jumping along the set bits of k; −1 if the walk leaves the tree.
- Techniques: 4.6
- Needs this topic because: look-alike partner of Company Queries II: a fixed number of steps up, so jumps by the bits of k.
- Tier reasoning: first binary-lifting problem in CSES.

## cses-1688 Company Queries II (tier 3, pattern lca-query, set reserved, for lookalike)
- Budget: n, q ≤ 2·10^5.
- Idea: Depths plus the lifting table. Lift the deeper employee to equal depth; if equal, done; else jump both from high j to low while up[j] differ; answer is the parent.
- Techniques: 4.6
- Needs this topic because: look-alike partner of Company Queries I: the number of steps is unknown, so lift both until just below the meeting point.
- Tier reasoning: CSES tree section.

## cses-1750 Planets Queries I (tier 3, pattern kth-ancestor, set practice)
- Budget: n, q ≤ 2·10^5, k ≤ 10^9.
- Idea: Each planet has one teleporter: a functional graph. Doubling table next[j][x] for j < 30; answer each query by the bits of k.
- Techniques: 4.6
- Needs this topic because: binary lifting works on any "one successor" structure, not only trees.
- Tier reasoning: CSES graph section.

## ac-abc258_e Packing Potatoes (tier 4, pattern kth-ancestor, set practice)
- Budget: N, Q ≤ 2·10^5, X ≤ 10^9, K ≤ 10^12.
- Idea: For each starting index i of a box, compute its size c_i: whole cycles (X / ΣW)·N plus a binary search on doubled prefix sums for the rest. next(i) = (i + c_i) mod N. The K-th box starts at next^{K−1}(0), found by doubling; print c of that start.
- Techniques: 4.6, 1.2, 1.4
- Needs this topic because: jump K − 1 steps in a functional graph.
- Tier reasoning: ABC E.

## ac-abc267_f Exactly K Steps (tier 5, pattern kth-ancestor, set practice)
- Budget: N, Q ≤ 2·10^5.
- Idea: Take diameter endpoints a, b; the farthest vertex from u is one of them. Build lifting tables rooted at a and at b. If depth_a(u) ≥ K answer the K-th ancestor of u rooted at a; else try b; else −1.
- Techniques: 4.6, 4.5
- Needs this topic because: k-th vertex on a path toward a known far endpoint.
- Tier reasoning: ABC F.

## cses-1160 Planets Queries II (tier 5, pattern kth-ancestor, set practice)
- Budget: n, q ≤ 2·10^5.
- Idea: Functional graph: find each planet's cycle, its position on it, and its distance to the cycle. a reaches b if b is on a's tail (check with a jump of the depth difference), or if both reach the same cycle and b is on it (distance to cycle + steps around).
- Techniques: 4.6, 4.2
- Needs this topic because: k-th successor checks combined with cycle positions.
- Tier reasoning: CSES graph section, hard.

## cf-1175E Minimal Segment Cover (tier 5, pattern kth-ancestor, set practice) †

- Idea: (recalled) far[x] = farthest right end of an interval starting at or before x (prefix maximum). Build jumps up[j][x]; for a query, jump greedily while the target stays < y; answer jumps + 1, or −1 if unreachable.

## cf-932D Tree (tier 5, pattern kth-ancestor, set practice) †

- Idea: (recalled) Let u be the deepest chosen vertex and v the chosen vertex farthest from u. The set lies on one path iff every chosen w has dist(u, w) + dist(w, v) = dist(u, v). With q ≤ 5, BFS per query also works.
