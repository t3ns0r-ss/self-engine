## cf-919E Congruence Equation (tier 5, pattern crt, set practice) †
- Budget: p up to 10^6, x up to 10^12 (recalled).
- Idea: count n ≤ x with n·a^n ≡ b (mod p). Since a^n repeats with period p − 1 and n repeats with period p, for each exponent class i mod (p − 1) the congruence in n is linear and the pair (n mod p, n mod (p − 1)) is one residue modulo p·(p − 1) by CRT (p and p − 1 are coprime).
- Techniques: 2.5, 2.2
- Needs this topic because: combining the two residues of n into one by CRT, then counting in a range.
- Tier reasoning: rating 2100, Phase 2 tier 5.

## cf-1500B Two chandeliers (tier 5, pattern crt, set practice) †
- Budget: n, m ≤ 5·10^5, k ≤ 10^12 (recalled).
- Idea: the two colour sequences repeat with periods n and m. A day t has equal colours exactly when a pair (i, j) with the same colour has t ≡ i (mod n) and t ≡ j (mod m), solvable when i ≡ j (mod gcd(n, m)) and unique modulo the lcm. Collect those days within one lcm period, then binary search the day by which k differences have occurred.
- Techniques: 2.5, 1.4
- Needs this topic because: solving the pair of congruences with non-coprime moduli.
- Tier reasoning: rating 2200, Phase 2 tier 5.

## cf-338D GCD Table (tier 5, pattern crt, set practice) †
- Budget: n, m up to 10^12, k ≤ 10^4 (recalled).
- Idea (recalled): the table is G(i, j) = gcd(i, j); the sequence a_1..a_k appears starting at (i, j) if G(i, j + l − 1) = a_l for l = 1..k. Then a_l divides i for every l, so i must be a multiple of L = lcm(a_1..a_k) (and is best taken as L, which needs L ≤ n), and a_l divides j + l − 1 for every l, a system of congruences j ≡ −(l − 1) (mod a_l). Solve it by CRT with non-coprime moduli (inconsistent: answer NO), take the solution j in [1, L] and check j + k − 1 ≤ m and gcd(L, j + l − 1) = a_l for each l.
- Techniques: 2.5
- Needs this topic because: a system of up to 10^4 congruences with non-coprime moduli.
- Tier reasoning: rating 2900, Phase 2 tier 5.

## ac-agc063_d Many CRT (tier 5, pattern crt, set practice)
- Budget: N ≤ 10^6, a, b, c, d ≤ 10^6, moduli c + k·d up to about 10^12, answer modulo 998244353.
- Idea (my derivation, not checked against an editorial, which does not exist yet on the contest page): with m_k = c + k·d and r_k = a + k·b, the number d·r_k − b·m_k = a·d − b·c does not depend on k. So x ≡ r_k (mod m_k) gives d·x ≡ a·d − b·c (mod m_k) for every k, hence modulo L = lcm(m_0, …, m_{N−1}). The converse holds up to the factor gcd(d, m_k) = gcd(c, d), which must be handled separately. Computing L needs the factorisation of the terms of an arithmetic progression by a sieve over small primes; the smallest x is then (Δ + t·L) / d with a small t found modulo d, evaluated modulo 998244353.
- Techniques: 2.5, 2.2
- Needs this topic because: it is a system of N congruences with non-coprime moduli; existence and uniqueness modulo the lcm is Theorem 2.5.3.
- Tier reasoning: AGC D, difficulty about 3609, judged tier 5. The hints are a derivation and say so.

## ac-abc315_g Ai + Bj + Ck = X (1 <= i, j, k <= N) (tier 4, pattern diophantine, set reserved, for review)
- Budget: N, A, B, C, X up to about 10^10 as given (N ≤ 10^6 loop over one variable).
- Idea: count triples (i, j, k) with 1 ≤ i, j, k ≤ N and A·i + B·j + C·k = X. Loop over i; for each i solve B·j + C·k = X − A·i, a two-variable equation: solvable iff gcd(B, C) divides the right side; one solution by extended Euclid; the solutions form a line (j0 + t·C/g, k0 − t·B/g); count the t with 1 ≤ j, k ≤ N by two inequalities (floor and ceil divisions).
- Techniques: 2.5
- Needs this topic because: counting solutions of a linear Diophantine equation inside a box.
- Tier reasoning: ABC G, difficulty about 2315, Phase 2 tier 4 (G problems are tier 4 or 5; the loop over one variable keeps it at the lower end).

## ac-arc221_a Two Arithmetic Progressions (tier 4, pattern crt, set reserved, for review)
- Budget: T ≤ 200, N ≤ 10^9, A, B, C, D ≤ 10^4, answer modulo 998244353.
- Idea: a linear combination of the two terms removes i, so gcd(A·i + B, C·i + D) divides Δ = |A·D − B·C| (the case Δ = 0 needs separate handling). Write gcd = Σ_{e | gcd} φ(e) (Euler's totient). Then the sum is Σ over divisors e of Δ of φ(e) · #{ i ≤ N : e | A·i + B and e | C·i + D }. The two conditions are linear congruences in i modulo e; solve each (extended Euclid) and merge them (CRT with a common modulus) into one residue class, then count its members up to N. Δ ≤ 10^8 has at most 768 divisors, so 200 cases are cheap.
- Techniques: 2.5, 2.1
- Needs this topic because: solving two linear congruences with a shared modulus and merging them into one class, per divisor.
- Tier reasoning: ARC A, difficulty about 1686, judged tier 4. A weak fit: the totient identity and the divisor sum are topic 2.1 work; the congruence solving is the part that needs 2.5.
