## cses-2189 Point Location Test (tier 1, pattern cross-sign, set practice)
- Budget: t ≤ 10^5 tests, so O(1) per test.
- Idea: cross = (x2 − x1)(y3 − y1) − (y2 − y1)(x3 − x1). Positive: LEFT; negative: RIGHT; zero: TOUCH. Each factor is at most 2·10^9, each product at most 4·10^18, the difference at most 8·10^18, below 9.22·10^18.
- Techniques: 2.4, 0.1
- Needs this topic because: Orientation of three points: Theorem 2.4.1.
- Tier reasoning: CSES introduction to the geometry section; tier 1.

## lc-minimum-lines-to-represent-a-line-chart Minimum Lines to Represent a Line Chart (tier 2, pattern cross-sign, set practice)
- Budget: n ≤ 10^5: sort O(n log n) then one pass.
- Idea: Sort by day. For i ≥ 2 the point i continues the line of points i−2, i−1 iff cross(p[i−2], p[i−1], p[i]) = 0. Answer = 0 for n = 1, else 1 + number of triples with a non-zero cross product.
- Techniques: 2.4, 1.1, 0.1
- Needs this topic because: Collinearity as cross = 0, with products near 10^18 (a double slope would fail).
- Tier reasoning: LeetCode Medium; tier 2.

## ac-abc266_c Convex Quadrilateral (tier 2, pattern cross-sign, set practice)
- Budget: Four points: O(1).
- Idea: For each i take cross(p[i], p[i+1], p[i+2]) with indices mod 4. The quadrilateral is convex iff all four are positive (counterclockwise order, no three collinear).
- Techniques: 2.4
- Needs this topic because: Turn direction at every corner.
- Tier reasoning: ABC C; tier 2.

## cf-227A Where do I Turn? (tier 1, pattern cross-sign, set practice) †

## cses-2190 Line Segment Intersection (tier 2, pattern cross-sign, set practice)
- Budget: t ≤ 10^5, O(1) per pair.
- Idea: Theorem 2.4.2: proper crossing (d1 d2 < 0 and d3 d4 < 0), or an end with cross 0 inside the bounding box of the other segment. Or the compact form: boxes overlap and both products of signs ≤ 0.
- Techniques: 2.4, 0.1
- Needs this topic because: Segment intersection with the degenerate cases.
- Tier reasoning: CSES geometry; tier 2.

## cses-2191 Polygon Area (tier 2, pattern cross-sign, set practice)
- Budget: n ≤ 1000: O(n).
- Idea: Shoelace sum S = Σ (x_i y_{i+1} − x_{i+1} y_i); the answer is |S|. Keep the sum in __int128.
- Techniques: 2.4, 0.1
- Needs this topic because: Area as a sum of cross products (Theorem 2.4.3).
- Tier reasoning: CSES geometry; tier 2.

## cses-2193 Polygon Lattice Points (tier 3, pattern cross-sign, set practice)
- Budget: n ≤ 10^5: O(n log) for the gcds.
- Idea: B = Σ gcd(|dx|, |dy|); 2A from the shoelace sum; I = (2A − B + 2) / 2 by Pick's theorem. Output I then B.
- Techniques: 2.4, 0.4
- Needs this topic because: Lattice count from area and gcd.
- Tier reasoning: CSES geometry; tier 3.

## cses-2192 Point in Polygon (tier 3, pattern cross-sign, set practice)
- Budget: n·m ≤ 10^6: O(n) per point.
- Idea: Theorem 2.4.4: boundary test with cross = 0 and the bounding box on every edge; then the half-open rule (a.y > q.y) != (b.y > q.y) and q to the left of the upward edge or the right of the downward edge; odd count means inside.
- Techniques: 2.4, 0.1
- Needs this topic because: Point in polygon with the boundary case.
- Tier reasoning: CSES geometry; tier 3.

## ac-abc296_g Polygon and Points (tier 4, pattern cross-sign, set practice)
- Budget: N, Q ≤ 2·10^5: O(log N) per query.
- Idea: Fan from p[0]: reject points outside the angle at p[0]; handle points on the lines of the first and last edge; binary search the last i with cross(p0, p[i], q) > 0; the sign of cross(p[i], p[i+1], q) decides.
- Techniques: 2.4, 1.4
- Needs this topic because: Orientation tests with a binary search (topic 1.4).
- Tier reasoning: ABC G; tier 4.

## cf-340B Maximal Area Quadrilateral (tier 4, pattern cross-sign, set practice) †
- Budget: n ≤ 300: O(n³) = 2.7·10^7.
- Idea: (recalled) For each pair (i, j): best positive cross and best negative cross over all other points; if both sides have a point, the quadrilateral area is (best positive + |best negative|) / 2. Work with twice the area as an integer until the end.
- Techniques: 2.4, 0.5
- Needs this topic because: Signed areas on both sides of a segment.
- Tier reasoning: rating 2100; tier 4.

## cses-2195 Convex Hull (tier 3, pattern sorted-sweep, set practice)
- Budget: n ≤ 2·10^5: sort O(n log n), then O(n).
- Idea: Andrew's monotone chain with pop on cross < 0 (keeps collinear boundary points), lower chain then upper chain, then sort and unique. The statement promises positive area.
- Techniques: 2.4, 1.1
- Needs this topic because: Hull by one sorted pass (Theorem 2.4.5).
- Tier reasoning: CSES geometry; tier 3.

## cf-166B Polygons (tier 4, pattern sorted-sweep, set practice) †
- Budget: n + m ≤ 1.2·10^5: sort and one pass.
- Idea: (recalled) Build the hull of A ∪ B with collinear points kept (pop on cross < 0). B is strictly inside A iff the hull has exactly n points and no point of B equals a point of A. Or: binary search each corner of B against A (template Convex polygon and queries).
- Techniques: 2.4, 1.1
- Needs this topic because: Hull as the test for containment.
- Tier reasoning: rating 2100; tier 4.

## cses-2194 Minimum Euclidean Distance (tier 3, pattern sorted-sweep, set practice)
- Budget: n ≤ 2·10^5: O(n log n).
- Idea: Sort by x; a set of (y, x) of the points less than r behind (r = floor(sqrt(best)) + 1); scan the y range [y − r, y + r]; at most a constant number of points are scanned (Theorem 2.4.6).
- Techniques: 2.4, 0.6
- Needs this topic because: Nearest pair by a sorted sweep.
- Tier reasoning: CSES geometry; tier 3.

## cf-552D Vanya and Triangles (tier 3, pattern cross-sign, set reserved, for checkpoint) †
- Budget: n ≤ 2000: O(n²) pairs or O(n² log n).
- Idea: (recalled) Total triples C(n, 3) minus collinear triples. For each point i, group the other points by the direction to it (dx, dy divided by gcd, sign fixed); a group of k points on one line through i gives C(k, 2) collinear triples with i in it; add these up over all i and divide by 3, because each collinear triple is counted from each of its three points.
- Techniques: 2.4, 0.4, 1.1
- Needs this topic because: Collinearity as direction equality (gcd) or cross = 0.
- Tier reasoning: rating 1900; tier 3.

## cf-429D Tricky Function (tier 4, pattern sorted-sweep, set reserved, for checkpoint) †
- Budget: n ≤ 10^5: O(n log n).
- Idea: (recalled) With prefix sums S the value is (i − j)² + (S_i − S_j)², the squared distance between the points (i, S_i) and (j, S_j): the closest pair of n points (template: Closest pair of the prefix sums).
- Techniques: 2.4, 1.2, 0.1
- Needs this topic because: Hidden closest pair.
- Tier reasoning: rating 2200; tier 4.

## ac-arc082_c ConvexScore (tier 4, pattern cross-sign, set reserved, for checkpoint)
- Budget: N ≤ 200: O(N³) collinear checks.
- Idea: Summing 2^(inside − |S|) over all convex subsets S counts every subset of points once, except the subsets that do not form a polygon of positive area: the empty set, a single point, and every set of two or more points that lie on one line. Answer = 2^N − 1 − N − Σ over lines (2^k − 1 − k) with k the number of points on the line, counted with cross = 0.
- Techniques: 2.4, 2.2
- Needs this topic because: Collinear sets counted with cross products and powers of 2.
- Tier reasoning: ARC, judgement; tier 4.

## cf-1163C1 Power Transmission (Easy Edition) (tier 3, pattern cross-sign, set reserved, for review) †
- Budget: n ≤ 50: about 1225 lines.
- Idea: (recalled) Write each line as a normalised triple (a, b, c) with gcd 1 and a fixed sign, take the distinct ones, and count pairs with a·b' − a'·b ≠ 0 (a cross product of directions): all pairs minus the pairs of parallel lines.
- Techniques: 2.4, 0.4, 0.6
- Needs this topic because: Lines as exact integer triples; parallel as cross = 0.
- Tier reasoning: rating 1900; tier 3.

## cf-1030D Vasya and Triangle (tier 3, pattern cross-sign, set reserved, for review) †
- Budget: O(log) with gcd.
- Idea: (recalled) Twice the area must be the integer 2nm/k, so k must divide 2nm. Take the triangle (0, 0), (x, 0), (0, y) with x·y = 2nm/k, built by dividing gcd parts of 2n and m by k so that x ≤ n and y ≤ m.
- Techniques: 2.4, 0.4
- Needs this topic because: Area as an integer twice the area.
- Tier reasoning: rating 1800; tier 3.

## lc-minimum-area-rectangle-ii Minimum Area Rectangle II (tier 3, pattern cross-sign, set reserved, for lookalike)
- Budget: n ≤ 50: all triples (50³) or all pairs as diagonals.
- Idea: For every triple (a, b, c) test that the angle at b is a right angle with a dot product, build the fourth corner d = a + c − b, test it is in the set, and take the area as |cross(a, b, c)|. Integer arithmetic only.
- Techniques: 2.4

- Tier reasoning: LeetCode Medium; tier 3.

## cses-3410 Maximum Manhattan Distances (tier 3, pattern no-geometry, set reserved, for drill)
- Budget: n ≤ 2·10^5: O(1) per addition.
- Idea: |dx| + |dy| = max(|(x+y) − (x'+y')|, |(x−y) − (x'−y')|), so keep the running maximum and minimum of x + y and of x − y; the answer is the larger of the two ranges.
- Techniques: 2.4, 1.2
- Needs this topic because: Looks like a farthest-pair question, but running extremes answer it.
- Tier reasoning: CSES; tier 3.
