## ac-abc248_e K-colinear Line (tier 4, pattern 0.5:enumerate-answer, set reserved, for review)
- Budget: N ≤ 300.
- Idea: If K = 1, Infinity. Otherwise every line with ≥ 2 points is fixed by its two lowest-index points: for each pair (i, j) not already on a counted line, count points on line ij (cross product) and count the line if ≥ K. O(N³).
- Techniques: 0.5, 0.4
- Needs this topic because: brute force over pairs with deduplication.
- Tier reasoning: ABC E.

## ac-abc176_e Bomber (tier 4, pattern 0.6:map-counting, set reserved, for review)
- Budget: H, W, M ≤ 3·10^5.
- Idea: Let R = max row count, C = max column count. Answer R + C − 1 if every (best row, best column) cell holds a target, else R + C. Check with a hash set of targets; stop early once a free cell is found (there are at most M targets to hit).
- Techniques: 0.6
- Needs this topic because: counting with maps plus a bounded check.
- Tier reasoning: ABC E.

## ac-abc268_f Best Concatenation (tier 5, pattern 1.1:custom-order, set reserved, for review)
- Budget: N ≤ 2·10^5, Σ|S| ≤ 2·10^5.
- Idea: Per string compute its internal score, x = number of X's and s = digit sum. Placing a before b gains x_a·s_b; sort by x_a·s_b > x_b·s_a (exchange argument), then sum cross terms with running totals. 64-bit.
- Techniques: 1.1
- Needs this topic because: a comparator from an exchange argument.
- Tier reasoning: ABC F.

## ac-abc410_f Balanced Rectangles (tier 5, pattern 1.2:prefix-2d, set reserved, for review)
- Budget: H·W ≤ 3·10^5.
- Idea: # = +1, . = −1. Transpose so H ≤ W (H ≤ √(HW)). For each pair of rows, column sums are prefix differences; count zero-sum column ranges with a prefix-sum counter array (offset index, reset by undoing). O(H²·W).
- Techniques: 1.2
- Needs this topic because: 2D prefix sums with the smaller dimension enumerated.
- Tier reasoning: ABC F.

## ac-abc389_e Square Price (tier 4, pattern 1.4:answer-search, set reserved, for review)
- Budget: N ≤ 2·10^5, M ≤ 10^18.
- Idea: The x-th unit of product i costs (2x − 1)·P_i. Binary search the largest marginal price T such that buying every unit with marginal cost ≤ T stays within M; then buy as many units costing exactly T + 1 as the leftover allows. Use 128-bit or capped arithmetic.
- Techniques: 1.4, 1.5
- Needs this topic because: binary search on a marginal-cost threshold.
- Tier reasoning: ABC E.

## lc-minimum-one-bit-operations-to-make-integers-zero Minimum One Bit Operations to Make Integers Zero (tier 4, pattern 1.7:high-bit-first, set reserved, for review)
- Budget: n ≤ 10^9.
- Idea: Clearing the highest bit k from 2^k takes 2^{k+1} − 1 steps, so f(n) = (2^{k+1} − 1) − f(n − 2^k) for the highest bit k (equivalently, the inverse Gray code of n).
- Techniques: 1.7
- Needs this topic because: decide from the highest bit down.
- Tier reasoning: LeetCode Hard.

## ac-abc136_e Max GCD (tier 4, pattern 2.1:trial-division, set reserved, for review)
- Budget: N ≤ 500, A_i ≤ 10^6, K ≤ 10^9.
- Idea: The sum S is invariant, so the answer divides S. For each divisor d (trial division), sort residues A_i mod d; lowering the smallest ones to 0 and raising the rest to d must balance at some split; the cost is the lowered sum. Take the largest d with cost ≤ K.
- Techniques: 2.1, 1.1
- Needs this topic because: enumerate divisors of an invariant.
- Tier reasoning: ABC E.

## lc-count-the-number-of-arrays-with-k-matching-adjacent-elements Count the Number of Arrays with K Matching Adjacent Elements (tier 4, pattern 2.2:fast-power, set reserved, for review)
- Budget: n, m ≤ 10^5, k < n.
- Idea: Choose which k of the n − 1 adjacent pairs are equal: C(n − 1, k). The first element has m choices and each of the other n − 1 − k boundaries m − 1. Answer C(n−1, k)·m·(m − 1)^{n−1−k} mod 10^9+7 with fast power and factorial inverses.
- Techniques: 2.2, 2.3
- Needs this topic because: counting formula evaluated with modular powers.
- Tier reasoning: LeetCode Hard.

## lc-number-of-ways-to-reorder-array-to-get-same-bst Number of Ways to Reorder Array to Get Same BST (tier 4, pattern 2.3:ncr-mod-p, set reserved, for review)

## ac-abc345_e Colorful Subsequence (tier 4, pattern 3.2:extra-small-state, set reserved, for exam)

- Techniques: 3.2

## ac-abc373_f Knapsack with Diminishing Values (tier 5, pattern 3.3:bounded, set reserved, for review)
