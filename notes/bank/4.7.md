## cf-475B Strongly Connected City (tier 2, pattern scc, set practice) †
- Budget: n, m ≤ 20 streets (recalled).
- Idea: (recalled) Build the directed graph on the n·m intersections. The city is strongly connected iff a search from every intersection (or from one in the graph and in its reverse) reaches all of them.
- Techniques: 4.7
- Needs this topic because: test strong connectivity.
- Tier reasoning: rating 1400.

## cses-1684 Giant Pizza (tier 4, pattern scc, set practice)
- Budget: n ≤ 10^5 members, m ≤ 10^5 toppings.
- Idea: 2-SAT: each wish (a ∨ b) adds implications ¬a → b and ¬b → a. Build SCCs of the implication graph; x and ¬x in one SCC means IMPOSSIBLE; otherwise pick x true iff comp(x) comes after comp(¬x) in topological order.
- Techniques: 4.7
- Needs this topic because: 2-SAT is solved by SCCs.
- Tier reasoning: CSES graph section, later.

## cf-1971H ±1 (tier 4, pattern scc, set practice) †
- Budget: n ≤ 500 columns (recalled).
- Idea: (recalled) Each grid entry is a_i or −a_i. The sorted middle of a column of three is 1 iff at least two entries are 1, i.e. every pair of entries in the column has at least one equal to 1: a 2-SAT clause per pair. Solve with SCCs.
- Techniques: 4.7
- Needs this topic because: translate "at least two of three" into 2-SAT clauses.
- Tier reasoning: rating 2100.

## cf-1239D Catowice City (tier 5, pattern condensation-reasoning, set practice) †

- Idea: (recalled) Edge i → j for "resident i knows cat j" (i ≠ j): a jury resident forces resident j into the jury. The jury must be closed under edges: take a sink SCC as jury, everyone else's cats as contestants. If the whole graph is one SCC, No.

- Tier reasoning: rating 2400.

## ac-arc111_d Orientation (tier 4, pattern scc, set reserved, for review)
- Budget: N ≤ 100.
- Idea: Reachable counts are equal exactly inside one SCC, and an edge between different SCCs points from the larger reach count to the smaller. So orient a → b when c_a > c_b (reverse if smaller). Edges with c_a = c_b must lie inside an SCC: DFS over those edges, orienting tree edges downward and back edges upward (each such component is bridgeless, as a solution is guaranteed).
- Techniques: 4.7
- Needs this topic because: reason about SCCs and the order of the condensation from given reach counts.
- Tier reasoning: ARC D, AtCoder Problems difficulty about 2060; judgement tier 4.

## ac-arc143_d Bridges (tier 5, pattern bridges, set practice)
- Budget: N, M ≤ 2·10^5.
- Idea: Choosing a character is choosing a direction for edge A_i–B_i in the graph on N vertices (vertex j "out" = j, "in" = j + N). DFS orientation (tree edges downward, back edges upward) makes every non-bridge edge part of a cycle, so only the original graph's bridges remain bridges. Print the characters given by the DFS directions.
- Techniques: 4.7
- Needs this topic because: the DFS orientation that keeps 2-edge-connected parts strongly connected.
- Tier reasoning: ARC D, AtCoder Problems difficulty about 2230; judgement tier 5.
