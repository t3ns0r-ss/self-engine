## ac-dp_h Grid 1 (tier 2, pattern grid-paths, set reserved, for lookalike)

## ac-dp_y Grid 2 (tier 4, pattern grid-paths, set reserved, for lookalike)
- Budget: H, W ≤ 10^5, N ≤ 3000 walls.
- Idea: Sort walls (and the target) by (r, c). f[i] = paths from start to wall i avoiding earlier walls = C(r+c−2, r−1) − Σ_{j before i} f[j]·C(path from j to i). Answer f[target].
- Techniques: 3.5, 2.3, 1.1
- Needs this topic because: look-alike partner of Grid 1: the grid is too large for a table, so DP runs over the walls with binomial path counts.
- Tier reasoning: EDP Y; tier 4 by judgement.
