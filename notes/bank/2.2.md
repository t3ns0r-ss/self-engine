## cses-1095 Exponentiation (tier 1, pattern fast-power, set practice)
- Budget: n ≤ 2·10^5 queries, b ≤ 10^9 → O(log b) each.
- Idea: Binary exponentiation: square the base and halve the exponent, multiplying into the result when the low bit is set; all mod 10^9 + 7 (0^0 = 1).
- Techniques: 2.2
- Needs this topic because: the basic fast power.
- Tier reasoning: first problem of CSES Mathematics.

## lc-minimum-non-zero-product-of-the-array-elements Minimum Non-Zero Product of the Array Elements (tier 4, pattern fast-power, set reserved, for review)
- Budget: p ≤ 60.
- Idea: Pair numbers into (1, 2^p − 2) as much as possible: the product is (2^p − 1)·(2^p − 2)^{2^{p−1} − 1} mod 10^9 + 7. Reduce 2^p − 2 mod p before the fast power; the exponent stays a 64-bit integer.
- Techniques: 2.2, 1.5

- Tier reasoning: LeetCode Medium with a pairing argument; counted as tier 4.

## ac-abc162_e Sum of gcd of Tuples (Hard) (tier 4, pattern fast-power, set practice)
- Budget: N, K ≤ 10^5.
- Idea: f(d) = number of tuples with gcd exactly d = ⌊K/d⌋^N − Σ_{k≥2} f(kd), computed for d from K down. Answer Σ d·f(d) mod p. Each power by fast exponentiation.
- Techniques: 2.2, 2.1
- Needs this topic because: K fast powers with exponent N.
- Tier reasoning: ABC E, difficulty about 1660.

## cses-1712 Exponentiation II (tier 3, pattern exponent-reduction, set practice)
- Budget: n ≤ 10^5 queries.
- Idea: a^{b^c} mod p: reduce the exponent b^c mod (p − 1) (Fermat), computing it by fast power, then a^{that} mod p. a ≡ 0 is fine since b^c ≥ 1 unless b = 0, which the reduced exponent handles (0^0 = 1 only when b^c = 0).
- Techniques: 2.2
- Needs this topic because: Fermat's little theorem shrinks a tower exponent.
- Tier reasoning: CSES Mathematics.

## cf-615D Multipliers (tier 5, pattern exponent-reduction, set practice) †
- Budget: m ≤ 2·10^5 primes (recalled).
- Idea: For n = Π p^{e}, the product of divisors is Π p^{e(e+1)/2 · D/(e+1)} where D is the number of divisors. Keep D mod (p − 1) as prefix and suffix products of (e + 1) over the other primes to avoid dividing; fast powers mod 10^9 + 7.
- Techniques: 2.2, 2.1
- Needs this topic because: exponents reduced mod p − 1.
- Tier reasoning: rating 2000, Phase 2 tier 5.

## cses-2182 Divisor Analysis (tier 4, pattern inverse-prime, set practice)
- Budget: k ≤ 10^5 prime powers, exponents ≤ 10^9.
- Idea: Count = Π (e + 1); sum = Π (p^{e+1} − 1)/(p − 1) with the division by the Fermat inverse; product = Π p^{e(e+1)/2 · (count of the others)} with exponents mod p − 1 (keep the divisor count mod p − 1 incrementally).
- Techniques: 2.2, 2.1
- Needs this topic because: inverses and exponent reduction together.
- Tier reasoning: CSES Mathematics, lower solve count.

## ac-abc298_d Writing a Numeral (tier 3, pattern inverse-prime, set practice)
- Budget: Q ≤ 6·10^5.
- Idea: Keep the digits in a queue and the value v mod p. Append x: v = 10v + x. Delete the front digit d when the length is L: v −= d·10^{L−1}; keep pow10 of the current length updated (multiply by 10 on append, by the inverse of 10 on delete).
- Techniques: 2.2, 0.6
- Needs this topic because: removing the leading digit needs 10^{L−1} mod p, maintained with the inverse of 10.
- Tier reasoning: ABC D.

## lc-fancy-sequence Fancy Sequence (tier 4, pattern inverse-prime, set practice)
- Budget: up to 10^5 calls, values ≤ 100.
- Idea: Keep one global map x → mul·x + add (mod 10^9 + 7). addAll and multAll update (mul, add). append(val) stores (val − add)·mul^(−1), so that applying the current map gives val; getIndex applies the current map to the stored value. mul is never a multiple of the prime, so the Fermat inverse exists.
- Techniques: 2.2
- Needs this topic because: undoing the global multiplication for later elements is a division modulo a prime.
- Tier reasoning: LeetCode Hard.

## lc-maximize-number-of-nice-divisors Maximize Number of Nice Divisors (tier 4, pattern fast-power, set reserved, for review)
- Budget: primeFactors ≤ 10^9.
- Idea: With exponents e_1, …, e_k summing to at most n, the number of nice divisors is e_1·…·e_k (Theorem 2.1.3 with every exponent at least 1). The product is largest with parts of size 3 (one or two 2s for the remainder): 3^(n/3), 4·3^((n−4)/3) or 2·3^((n−2)/3), by fast power.
- Techniques: 2.2, 2.1
- Needs this topic because: the exponent n/3 is up to 3·10^8.
- Tier reasoning: LeetCode Hard.

## lc-count-collisions-of-monkeys-on-a-polygon Count Collisions of Monkeys on a Polygon (tier 3, pattern fast-power, set reserved, for lookalike)
- Budget: n ≤ 10^9.

- Techniques: 2.2

## cf-963A Alternating Sum (tier 4, pattern inverse-prime, set reserved, for lookalike) †
- Budget: n ≤ 10^9, k ≤ 10^5 (recalled).
- Idea: The signs repeat with period k, so the sum is a geometric series over (n + 1)/k blocks with ratio q = (b/a)^k modulo 10^9 + 9 (prime). Compute the first block T directly; if q ≡ 1 the answer is T·blocks, otherwise T·(q^blocks − 1)/(q − 1) with the Fermat inverse.
- Techniques: 2.2
- Needs this topic because: division by a (in b/a) and by q − 1 modulo a prime, with the q ≡ 1 case separate.
- Tier reasoning: rating 1800.

## ac-arc167_b Product of Divisors (tier 3, pattern inverse-prime, set reserved, for review)
- Budget: A ≤ 10^12, B ≤ 10^18.

## ac-abc367_e Permute K times (tier 4, pattern fast-power, set reserved, for exam)
- Budget: N ≤ 2·10^5, K ≤ 10^18.
- Idea: Applying the operation K times maps position i to X^K(i), the K-th iterate of the function X. Compose the function with itself by squaring, as in binary exponentiation: keep X^(2^j) and apply it for every set bit of K. O(N log K).
- Techniques: 2.2
- Needs this topic because: binary exponentiation of a function instead of a number: K is far too large to apply step by step.
- Tier reasoning: ABC E, difficulty 1370; reserved for the Phase 2 exam.
