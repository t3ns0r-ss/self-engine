## ac-abc341_e Alternating String (tier 4, pattern point-range, set reserved, for lookalike)
- Budget: N, Q ≤ 5·10^5.
- Idea: Let d_i = 1 if S_i = S_{i+1}. Flipping [L, R] only changes d_{L−1} and d_R. Point-update tree (or Fenwick) on d; [L, R] is good iff the sum of d over [L, R − 1] is 0.
- Techniques: 5.3
- Needs this topic because: look-alike partner of the Lazy Segment Tree practice task: a range flip, but only two boundary values change, so no lazy propagation is needed.
- Tier reasoning: ABC E.
