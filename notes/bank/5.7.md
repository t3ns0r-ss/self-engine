## cses-1655 Maximum Xor Subarray (tier 3, pattern max-xor, set practice)
- Budget: n ≤ 2·10^5, values < 2^30.
- Idea: Subarray XOR = P_r XOR P_{l−1}. Insert prefix XORs (starting with 0) into a binary trie; for each new prefix take the opposite bit when possible from the top.
- Techniques: 5.7, 1.7
- Needs this topic because: maximum XOR pair via a binary trie.

## ac-abc281_f Xor Minimization (tier 4, pattern xor-split, set practice (ladder, card xor-split, rung 1))
- Budget: N ≤ 1.5·10^5, a_i < 2^30 (statement read 2026-11-15).
- Idea: Choose x to minimise the largest of a_i xor x. Split the numbers by the top digit: if both groups are non-empty, the answer is 2^b plus the better of the two sub-answers (x can fix the digit for one group only, and the other group keeps the digit 1); if only one group exists, x clears the digit and the answer is the sub-answer of that group. Recurse down the digits on sorted ranges (Theorem 5.7.3 splits the same way).
- Techniques: 5.7, 1.7
- Needs this topic because: the recursion by the highest differing digit, the same split as the XOR-MST.
- Tier reasoning: ABC F (difficulty 1714).

## ac-arc122_d XOR Game (tier 5, pattern xor-split, set practice (ladder, card xor-split, rung 2))
- Budget: N ≤ 2·10^5, A_i < 2^30 (statement read 2026-11-15).
- Idea: Bob pairs the 2N numbers so that the largest XOR over the pairs is as small as possible (Alice cannot do better against optimal play, since Bob answers every choice with its partner). Split by the top digit: if both groups have an even size, pair inside the groups and recurse; if both are odd, exactly one pair must cross, so the answer is the smallest XOR across the groups, found with a binary trie of one group.
- Techniques: 5.7, 1.7
- Needs this topic because: the split by the top digit and the cheapest edge across, as in the XOR-MST.
- Tier reasoning: ARC D (difficulty 2331); judgement.

## cf-888G Xor-MST (tier 4, pattern xor-split, set practice (ladder, card xor-split, rung 3)) †
- Budget: n ≤ 2·10^5, a_i < 2^30 (recalled).
- Idea: (recalled) A complete graph whose edge weight is a_i xor a_j; the weight of a cheapest spanning tree. Sort, split by the top digit recursively (Theorem 5.7.3): the tree is the two sub-trees plus the cheapest edge across, found with a trie of one half.
- Techniques: 5.7, 4.4, 1.7
- Needs this topic because: the XOR-MST itself; cut property from 4.4 and the trie from this topic.
- Tier reasoning: rating 2300.

## lc-maximum-subarray-xor-with-bounded-range Maximum Subarray XOR with Bounded Range (tier 4, pattern max-xor, set reserved, for review)
- Budget: n ≤ 4·10^4, values below 2^15.
- Idea: For each right end r, the left ends l with max − min ≤ k of nums[l..r] form a suffix that moves right as r grows (two pointers with monotonic deques for the max and the min). The XOR of the subarray is P[r+1] XOR P[l] for prefix XORs P; keep P[l] of the current window in a binary trie with counts (insert when l enters, delete when it leaves) and ask for the maximum XOR with P[r+1].
- Techniques: 5.7, 1.6, 1.3
- Needs this topic because: a binary trie with deletions over a sliding set of prefix XORs.
- Tier reasoning: LeetCode Hard.

## ac-abc308_g Minimum Xor Pair Query (tier 4, pattern max-xor, set reserved, for checkpoint)
- Budget: Q ≤ 3·10^5, x < 2^30 (statement read 2026-11-15).
- Idea: Add, erase, and ask for the smallest XOR of two numbers present. The smallest pair XOR is always between two neighbours in sorted order (Theorem 5.7.3, step 2: the top digit decides), so keep an ordered multiset of the numbers and a multiset of neighbour XORs; the same answer comes from a binary trie that stores the best value on every node and prefers the same digit.
- Techniques: 5.7, 1.7
- Needs this topic because: insertions and removals with a smallest-XOR question, a changing set as in the first card.
- Tier reasoning: ABC G (difficulty 2008).

## cf-1879D Sum of XOR Functions (tier 2, pattern xor-count, set reserved, for drill) †
- Budget: n ≤ 3·10^5, values below 2^30 (recalled).
- Idea: (recalled) Sum over all subarrays of (XOR of the subarray) · (its length), modulo 998244353. With prefix XORs P, the XOR of [l, r] is P[r] XOR P[l − 1]. For each bit b, the subarrays whose XOR has the bit set pair a prefix with bit 0 and one with bit 1; keep, for each bit value, the count and the sum of the indices, and add 2^b · Σ (r − l) over such pairs. O(n · 30).
- Techniques: 5.7, 1.7
- Needs this topic because: tempting because of XOR over pairs of prefixes, but each bit is counted on its own (topic 1.7); no trie is needed.
- Tier reasoning: rating 1700, tier 2.
