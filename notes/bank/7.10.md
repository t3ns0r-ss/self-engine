## ac-abc248_e K-colinear Line (tier 4, pattern 0.5:enumerate-answer, set reserved, for review)
- Budget: N ≤ 300.
- Idea: If K = 1, Infinity. Otherwise every line with ≥ 2 points is fixed by its two lowest-index points: for each pair (i, j) not already on a counted line, count points on line ij (cross product) and count the line if ≥ K. O(N³).
- Techniques: 0.5, 0.4
- Needs this topic because: brute force over pairs with deduplication.
- Tier reasoning: ABC E.

## ac-abc176_e Bomber (tier 4, pattern 0.6:map-counting, set reserved, for review)
- Budget: H, W, M ≤ 3·10^5.
- Idea: Let R = max row count, C = max column count. Answer R + C − 1 if every (best row, best column) cell holds a target, else R + C. Check with a hash set of targets; stop early once a free cell is found (there are at most M targets to hit).
- Techniques: 0.6
- Needs this topic because: counting with maps plus a bounded check.
- Tier reasoning: ABC E.

## ac-abc268_f Best Concatenation (tier 5, pattern 1.1:custom-order, set reserved, for review)
- Budget: N ≤ 2·10^5, Σ|S| ≤ 2·10^5.
- Idea: Per string compute its internal score, x = number of X's and s = digit sum. Placing a before b gains x_a·s_b; sort by x_a·s_b > x_b·s_a (exchange argument), then sum cross terms with running totals. 64-bit.
- Techniques: 1.1
- Needs this topic because: a comparator from an exchange argument.
- Tier reasoning: ABC F.

## cf-1665D GCD Guess (tier 3, pattern 1.8:equation-queries, set reserved, for review) †
- Budget: x ≤ 10^9 is hidden, at most 30 queries "? a b" (1 ≤ a, b ≤ 10^9, a ≠ b) that answer gcd(x + a, x + b) (recalled).
- Idea: (recalled) Learn x one bit at a time from the lowest. - Techniques: 1.8, 1.7
- Needs this topic because: Every reply settles one new unknown (a bit), so the budget of 30 matches the number of unknowns.

## cf-568C New Language (tier 5, pattern 4.8:two-sat, set reserved, for review) †
- Budget: n ≤ 200 positions, the alphabet is the first l ≤ 26 letters, m ≤ 4·n rules (recalled).
- Idea: (recalled) Every letter of the alphabet is a vowel or a consonant (given), and every rule says: if the letter at position i is of kind a, then the letter at position j is of kind b. Find the smallest word that is not smaller than the given string s and follows all rules. Each position has two possible kinds, so the rules are clauses of two statements and a fixed prefix only forces some of them: 2-SAT by strongly connected components (Theorem 4.8.7) decides whether a prefix can be completed. ## cf-1720D2 Xor-Subsequence (hard version) (tier 4, pattern 5.7:xor-count, set reserved, for review) †
- Budget: n ≤ 3·10^5, a_i < 2^30 (recalled).
- Idea: (recalled) Longest subsequence of indices b_1 < b_2 < … such that a_{b_k} xor b_{k+1} < a_{b_{k+1}} xor b_k. For indices i < j the test is (a_i xor j) < (a_j xor i). The two sides xored together give (a_i xor i) xor (a_j xor j), so they first differ at the highest bit where u_i = a_i xor i and u_j = a_j xor j differ, say bit b; and a_i xor j has a 0 there exactly when bit b of a_i equals bit b of j. Keep a binary trie over the numbers u_i from the highest bit down; every node stores, for each of the two values of bit b of a_i (b is the depth of the node below), the largest dp value of the elements passing through it. For j walk down the trie along u_j; at each step the other child (the one where u differs) is a whole branch that diverges here, take from it the stored maximum for the value a bit of a_i that equals the bit of j, and the same walk inserts j afterwards. O(n log A).
- Techniques: 5.7, 3.3, 1.7
- Needs this topic because: A trie where the branches that already decide the comparison are used whole, with stored values (the idea of counting below a bound with stored subtree data, here a maximum of dp values).

## ac-arc107_f Sum of Abs (tier 5, pattern 7.9:flow-cut, set reserved, for review)
- Budget: N, M ≤ 300, A_i up to 10^6, |B_i| up to 10^6.
- Idea: The score of a component is |sum of B|, the larger of the sum and its negative, so give every kept vertex a sign, and require that two kept vertices joined by an edge have the same sign; the best signs then give each component its absolute value. Every vertex has three states: kept with plus, kept with minus, deleted. The profit of a choice is Σ s_i B_i − Σ A_i over the deleted vertices; write it as Σ|B_i| minus a cost, where the cost of a vertex is |B_i| − B_i for plus, |B_i| + B_i for minus and |B_i| + A_i for deleted. The three states are the cuts of a chain: source → p_v (capacity cost of minus) → q_v (capacity cost of deleted) → sink (capacity cost of plus), with an edge q_v → p_v of infinite capacity so that only the three states can occur (p_v on the sink side means minus, p_v on the source side and q_v on the sink side means deleted, both on the source side means plus). For every edge u–v add infinite edges q_u → p_v and q_v → p_u: they are cut exactly when one vertex is plus and its neighbour minus. The answer is Σ|B_i| minus the minimum cut (Theorem 7.9.2). The gadget was checked against a brute force over all 3^n assignments on 400 random small graphs.
- Techniques: 7.9, 4.1
- Needs this topic because: Choosing one of three states for every item with a penalty for each forbidden pair: a minimum cut over a chain per item.
- Tier reasoning: ARC problem (difficulty 3130), judgement tier 5; statement read on 2026-11-16.
