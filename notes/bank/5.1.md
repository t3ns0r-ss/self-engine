## cses-1647 Static Range Minimum Queries (tier 2, pattern static-min, set practice)
- Budget: n, q ≤ 2·10^5.
- Idea: Sparse table st[j][i] = min of a[i .. i + 2^j − 1]. Query [a, b]: k = ⌊log2(b − a + 1)⌋, min(st[k][a], st[k][b − 2^k + 1]).
- Techniques: 5.1
- Needs this topic because: the sparse-table template.
- Tier reasoning: first CSES range-query problem with min.

## cf-1706E Qpwoeirut and Vertices (tier 4, pattern static-min, set reserved, for checkpoint) †
- Budget: n, m, q ≤ 2·10^5 (recalled).
- Idea: (recalled) Edges are added in input order; a query (l, r) asks for the smallest k such that the first k edges join all vertices l..r. Let t_i be the smallest k joining i and i + 1. The answer is the maximum of t_i over i in [l, r − 1] (0 when l = r). To get every t_i, merge components with a union structure that keeps member lists, small into large: when two components merge at time k, for each member x of the smaller one check whether x − 1 or x + 1 lies in the larger one, and if so set that t to k. Then a sparse table of maximum answers each query in O(1).
- Techniques: 5.1, 4.4
- Needs this topic because: range maximum over a static array of connection times, with many queries.
- Tier reasoning: rating 2300, tier 4 for the phase 5 band 1800–2100; needs a union structure plus the sparse table.

## lc-minimum-stability-factor-of-array Minimum Stability Factor of Array (tier 4, pattern idempotent-op, set reserved, for checkpoint)
- Budget: n ≤ 10^5, values ≤ 10^9, maxC ≤ n.
- Idea: Binary search the answer L (the longest stable subarray allowed, 0..n). L is feasible if the stable windows of length L + 1 can be destroyed with at most maxC changes. Greedy sweep: at position i, if gcd(nums[i..i+L]) ≥ 2 (O(1) with a gcd sparse table), change the last element of that window to 1 (or any value coprime with the neighbours), count one change and jump to i + L + 1; otherwise i + 1. Feasibility is monotone in L. L = 0 means every element ≥ 2 must be changed.
- Techniques: 5.1, 2.1, 1.4, 1.5
- Needs this topic because: range gcd of an arbitrary window inside a binary search, O(1) per window.
- Tier reasoning: LeetCode Hard; binary search on the answer, greedy cover and an idempotent table in one problem.

## cf-675E Trains and Statistic (tier 4, pattern static-min, set reserved, for review) †
- Budget: n ≤ 10^5 (recalled).
- Idea: (recalled) From station i a ticket reaches any station in [i + 1, a_i]. Let dp[i] be the sum over j > i of the minimum number of tickets from i to j. Choose m in [i + 1, a_i] with the largest a_m (argmax by sparse table). Then every j in (i, a_i] costs 1, and every j > a_i costs 1 + the cost from m, which gives dp[i] = dp[m] − (a_i − m) + (n − i). Process i from n − 1 down to 1 and print the sum of dp (64-bit).
- Techniques: 5.1, 3.2
- Needs this topic because: argmax over arbitrary ranges inside a right-to-left dp.
- Tier reasoning: rating 2300, tier 4; the greedy choice plus the dp formula take care.

## cf-1454F Array Partition (tier 4, pattern search-over-ranges, set reserved, for review) †
- Budget: n ≤ 2·10^5 over all tests (recalled).
- Idea: (recalled) Split the array into three non-empty parts with max(first) = min(second) = max(third). For each end i of the first part, let P = prefix maximum. Binary search the end j of the second part. Let m(j) = min a[i+1..j] (sparse table) and s(j) = suffix maximum from j + 1. Both fall as j grows. If m(j) < P go left; if m(j) > P go right; if m(j) = P compare s(j): s < P go left, s > P go right, equal means answer found. O(n log n).
- Techniques: 5.1, 1.4, 1.2
- Needs this topic because: range minimum of the middle part inside a binary search for every split.
- Tier reasoning: rating 2100, tier 4.

## lc-find-subarray-with-bitwise-or-closest-to-k Find Subarray With Bitwise OR Closest to K (tier 4, pattern idempotent-op, set reserved, for review)

## lc-maximum-total-subarray-value-ii Maximum Total Subarray Value II (tier 4, pattern static-min, set reserved, for lookalike)
- Budget: n ≤ 5·10^4, k ≤ min(10^5, n(n+1)/2).
- Idea: The k chosen subarrays must be distinct. The value max − min never decreases when a subarray grows, so the best k are found like a k-way merge: start a max-heap with [0, n − 1], pop the best (l, r), push (l + 1, r) and (l, r − 1) if not seen yet (hash set of pairs). Each value is max − min from two sparse tables in O(1). O((n log n) + k log k).
- Techniques: 5.1, 0.6
- Needs this topic because: each heap entry needs the max and min of an arbitrary range at once.
- Tier reasoning: LeetCode Hard; look-alike partner of the Medium version I.

## lc-count-stable-subarrays Count Stable Subarrays (tier 4, pattern search-over-ranges, set reserved, for drill)
- Budget: n, q ≤ 10^5.
- Idea: Stable means non-decreasing. Cut the array into maximal non-decreasing runs; let end[i] be the last index of the run containing i, and c[i] = i − start(i) + 1 the number of stable subarrays ending at i, with prefix sums C of c. For a query [l, r]: e = end[l]. If r ≤ e the answer is len(len + 1)/2 for len = r − l + 1; else the first run contributes len1(len1 + 1)/2 with len1 = e − l + 1, plus C[r] − C[e]. O(n + q); no range table is needed.
- Techniques: 1.2
- Needs this topic because: queries over ranges of a static array; runs and prefix sums answer them.
- Tier reasoning: LeetCode Hard label but a short solution; tier 4 as the higher of the two readings.
