Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## ac-dp_q Flowers (tier 3, pattern prefix-max-transition, set practice)
- Budget: N ≤ 2·10^5, heights a permutation.
- Idea: dp[i] = a_i + max dp[j] over earlier j with h_j < h_i. A Fenwick tree of prefix maxima indexed by height gives each transition in O(log N). 64-bit.
- Techniques: 7.3, 5.2
- Needs this topic because: the canonical prefix-max transition.
- Tier reasoning: Educational DP Contest Q; judgement tier 3.

## cf-1667B Optimal Partition (tier 3, pattern prefix-max-transition, set practice) †
- Budget: Σ n ≤ 5·10^5 (recalled).
- Idea: (recalled) dp[i] = max over j < i of dp[j] + sign(p_i − p_j)·(i − j) for prefix sums p. Keep three max-structures over compressed prefix values: dp[j] − j (for p_j < p_i), dp[j] (equal), dp[j] + j (greater).
- Techniques: 7.3, 5.2, 1.2
- Needs this topic because: split the transition by sign and query each part by prefix.
- Tier reasoning: rating 2100.

## cf-1197E Culture Code (tier 3, pattern prefix-max-transition, set practice) †
- Budget: n ≤ 2·10^5 (recalled).
- Idea: (recalled) Sort dolls by out size. dp[i] = (min extra space, count) for a maximal chain ending at doll i: best over dolls j with out_j ≤ in_i of extra_j − out_j + in_i, kept in a tree of (min, count) over sorted outs; chains that cannot be extended are the answers.
- Techniques: 7.3, 5.3, 1.1
- Needs this topic because: a (min, count) prefix query feeds the DP.
- Tier reasoning: rating 2300.

## lc-maximum-balanced-subsequence-sum Maximum Balanced Subsequence Sum (tier 4, pattern prefix-max-transition, set practice)
- Budget: n ≤ 10^5.
- Idea: Balanced means nums[i] − i is non-decreasing. dp[i] = nums[i] + max(0, max dp[j] with key_j ≤ key_i), via a Fenwick max tree over compressed keys. If all values are negative, return the maximum element.
- Techniques: 7.3, 5.2
- Needs this topic because: rewrite the condition as a key order, then prefix max.
- Tier reasoning: LeetCode Hard.

## lc-maximum-profit-in-job-scheduling Maximum Profit in Job Scheduling (tier 4, pattern prefix-max-transition, set reserved, for review)
- Budget: ≤ 5·10^4 jobs.
- Idea: Sort jobs by end time. best[i] = max(best[i − 1], profit_i + best[last job ending ≤ start_i]) with binary search; the prefix-best array plays the role of the tree.
- Techniques: 7.3, 1.4
- Needs this topic because: prefix-maximum transition over sorted times.
- Tier reasoning: LeetCode Hard.

## lc-length-of-the-longest-increasing-path Length of the Longest Increasing Path (tier 4, pattern prefix-max-transition, set practice)
- Budget: n ≤ 10^5 points.
- Idea: Sort by x (ties by y descending) and compute the LIS ending at each point with a Fenwick max over compressed y; do the same from the right. Answer = ending + starting − 1 at point k.
- Techniques: 7.3, 3.4, 5.2
- Needs this topic because: LIS lengths through a fixed element.
- Tier reasoning: LeetCode Hard.

## lc-jump-game-vi Jump Game VI (tier 3, pattern window-transition, set practice)
- Budget: n ≤ 10^5, k ≤ 10^5.
- Idea: dp[i] = nums[i] + max dp[i − k..i − 1]. A monotonic deque (or a segment tree over indices) gives the window maximum.
- Techniques: 7.3, 1.6
- Needs this topic because: window maximum feeding a DP.
- Tier reasoning: LeetCode Medium.

## lc-constrained-subsequence-sum Constrained Subsequence Sum (tier 4, pattern window-transition, set practice)
- Budget: n ≤ 10^5.
- Idea: dp[i] = nums[i] + max(0, max dp[i − k..i − 1]); window max by deque or segment tree; answer max dp.
- Techniques: 7.3, 1.6
- Needs this topic because: window maximum with the option to start fresh.
- Tier reasoning: LeetCode Hard.

## ac-abc339_e Smooth Subsequence (tier 4, pattern window-transition, set practice)
- Budget: N, D, A_i ≤ 5·10^5.
- Idea: dp at value A_i = 1 + max over values in [A_i − D, A_i + D] of the best length so far. Segment tree over values with point chmax and range max.
- Techniques: 7.3, 5.3
- Needs this topic because: the predecessor set is a range of values.
- Tier reasoning: ABC E.

## lc-longest-increasing-subsequence-ii Longest Increasing Subsequence II (tier 4, pattern window-transition, set reserved, for checkpoint)
- Budget: n ≤ 10^5, values and k ≤ 10^5.
- Idea: dp at value x = 1 + max over values in [x − k, x − 1]; segment tree over values with range max and point update.
- Techniques: 7.3, 5.3
- Needs this topic because: value-window maximum.
- Tier reasoning: LeetCode Hard.

## lc-delivering-boxes-from-storage-to-ports Delivering Boxes from Storage to Ports (tier 4, pattern window-transition, set practice)
- Budget: ≤ 10^5 boxes.
- Idea: dp[i] = min over j in the feasible window (box count ≤ maxBoxes, weight ≤ maxWeight) of dp[j] + trips(j+1..i), where trips = 2 + port changes = 2 + diff[i] − diff[j + 1]. Keep dp[j] − diff[j + 1] in a monotonic deque over the sliding window.
- Techniques: 7.3, 1.6, 1.3
- Needs this topic because: separate the transition cost, then a window minimum.
- Tier reasoning: LeetCode Hard.

## cses-1748 Increasing Subsequence II (tier 3, pattern counting-with-tree, set practice)
- Budget: n ≤ 2·10^5.
- Idea: cnt[i] = 1 + Σ cnt[j] over earlier j with x_j < x_i: a Fenwick tree of sums over compressed values (mod 10^9+7). Answer Σ cnt.
- Techniques: 7.3, 5.2
- Needs this topic because: counting increasing subsequences with prefix sums of a DP.
- Tier reasoning: CSES DP section.

## cf-597C Subsequences (tier 2, pattern counting-with-tree, set practice) †
- Budget: n ≤ 10^5, k ≤ 10 (recalled).
- Idea: (recalled) dp[len][i] = number of increasing subsequences of length len ending at i = Σ dp[len − 1][j] over a_j < a_i: one Fenwick tree per length. Answer Σ dp[k + 1][i] (64-bit).
- Techniques: 7.3, 5.2
- Needs this topic because: a Fenwick tree per DP layer.
- Tier reasoning: rating 1900.

## cf-833B The Bakery (tier 3, pattern range-update-transition, set practice) †
- Budget: n ≤ 3.5·10^4, k ≤ 50 (recalled).
- Idea: (recalled) dp[k][i] = max over j of dp[k − 1][j] + distinct(j + 1..i). For each layer, keep a lazy tree over j; moving i adds 1 to j in [last[a_i], i − 1] (positions where a_i is new); query the prefix max.
- Techniques: 7.3, 5.3
- Needs this topic because: a new element raises a range of states by one.
- Tier reasoning: rating 2200.

## cf-1557D Ezzat and Grid (tier 3, pattern range-update-transition, set practice) †
- Budget: n, m ≤ 3·10^5, columns ≤ 10^9 (recalled).
- Idea: (recalled) Keep the longest chain of rows ending at row i: 1 + max over earlier rows sharing a covered column. Over compressed columns, a lazy max tree storing (length, row): query the max over row i's segments, then assign-max that value onto the same segments. Rebuild the kept rows from parents.
- Techniques: 7.3, 5.3, 1.1
- Needs this topic because: range chmax updates and range max queries drive the DP.
- Tier reasoning: rating 2200.

## cf-1799D2 Hot Start Up (hard version) (tier 3, pattern range-update-transition, set reserved, for review) †
- Budget: Σ n, Σ k ≤ 3·10^5 (recalled).
- Idea: (recalled) State = the last program on the other CPU. Running a_i on the CPU that just ran a_{i−1} adds the same cost to every state (a global lazy add); the state "other CPU last ran a_{i−1}" gets min(global min + cold_{a_i}, dp[a_i] + hot_{a_i}). Keep the global add as an offset.
- Techniques: 7.3
- Needs this topic because: an "add to all states" transition handled lazily.
- Tier reasoning: rating 2100.

## cf-115E Linear Kingdom Races (tier 4, pattern range-update-transition, set practice) †
- Budget: n, m ≤ 2·10^5 (recalled).
- Idea: (recalled) dp[i] = best profit up to road i with road i unrepaired. Over j (last unrepaired road), sweeping i subtracts the repair cost of road i from all j < i and adds each race ending at i to j < its start (range adds); dp[i] = max over j + current values.
- Techniques: 7.3, 5.3
- Needs this topic because: each new element changes a range of earlier states.
- Tier reasoning: rating 2400.

## ac-dp_w Intervals (tier 5, pattern range-update-transition, set practice)
- Budget: N, M ≤ 2·10^5.
- Idea: dp over the position j of the last 1. At position i, set dp[i] = max over all earlier + 0; for each interval ending at i, add a to every j in [l, i]. Lazy segment tree with range add and global max. 64-bit.
- Techniques: 7.3, 5.3
- Needs this topic because: interval rewards as range additions on DP states.
- Tier reasoning: Educational DP Contest W; judgement tier 5.

## ac-abc397_f Variety Split Hard (tier 5, pattern range-update-transition, set practice)
- Budget: N ≤ 3·10^5.
- Idea: Sweep the second cut j. Keep, over the first cut i, f(i) = distinct(1..i) + distinct(i + 1..j): when A_j is added, add 1 to i in [last(A_j), j − 1]. Answer = max over j of (max over i < j of f(i)) + distinct(j + 1..N).
- Techniques: 7.3, 5.3
- Needs this topic because: range additions on split points while sweeping.
- Tier reasoning: ABC F.
