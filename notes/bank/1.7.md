## lc-missing-number Missing Number (tier 1, pattern xor-identities, set practice)
- Budget: n ≤ 10^4.
- Idea: XOR of 0..n XOR all elements leaves the missing number (pairs cancel).
- Techniques: 1.7
- Needs this topic because: x ⊕ x = 0 and order does not matter.
- Tier reasoning: LeetCode Easy.

## cf-1421A XORwice (tier 1, pattern xor-identities, set practice) †

- Idea: (a ⊕ x) + (b ⊕ x) ≥ a ⊕ b for every x, with equality at x = a & b; print a ⊕ b.
- Techniques: 1.7
- Needs this topic because: bitwise reasoning per bit.
- Tier reasoning: rating 800.

## lc-find-the-original-array-of-prefix-xor Find The Original Array of Prefix Xor (tier 2, pattern xor-identities, set practice)

- Tier reasoning: LeetCode Medium, short.
