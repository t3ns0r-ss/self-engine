## ac-abc326_f Robot Rotation (tier 5, pattern size-band, set practice)
- Budget: N ≤ 80.
- Idea: Moves alternate between x and y axes; the x-moves (A_2, A_4, ...) and y-moves (A_1, A_3, ...) each get a free sign, independently. Each axis has ≤ 40 signed terms: meet in the middle per axis (map of half-sums to masks). Rebuild the L/R string from the chosen signs and current heading.
- Techniques: 3.9, 0.6
- Needs this topic because: two independent 40-term sign problems, each solved by meet in the middle.
- Tier reasoning: ABC F (difficulty about 1870).

## cf-1105E Helping Hiasat (tier 5, pattern size-band, set practice) †
- Budget: n up to 10^5 events, m up to 40 friends (recalled).
- Idea: Two friends conflict when both want the same name between the same two "change" events. The answer is the largest set of friends with no conflict: a maximum independent set on a graph of m ≤ 40 vertices. Split the vertices into two halves of 20: for each subset of the first half that is independent, find the largest independent subset of the second half that avoids its neighbours, using a table "best independent subset inside each mask" built by a small DP over the second half. (recalled)
- Techniques: 3.9
- Needs this topic because: 2^40 subsets are too many; 2^20 per half is fine, and the halves interact only through a lookup.
- Tier reasoning: rating 2200, above the 3.9 band: tier 5.

## cf-585D Lizard Era: Beginning (tier 5, pattern size-band, set practice) †
- Budget: n ≤ 25 quests, each changes three attitudes by given amounts (recalled).
- Idea: Each quest sends two of three companions on it: 3 choices, so 3^25 is too many. Split into halves of 12 and 13, enumerate 3^12 and 3^13 choices, key each by the differences of the three totals, and match the two halves through a map (the left key needs the negated right key); keep the largest common total. (recalled)
- Techniques: 3.9
- Needs this topic because: 3^25 against 2 · 3^13: the band is read from the base 3, not 2.
- Tier reasoning: rating 2300: tier 5.

## cf-1569E Playoff Restoration (tier 5, pattern size-band, set practice) †
- Budget: k ≤ 5, so 2^k = 32 teams (recalled).
- Idea: A playoff of 32 teams has 31 games, 2^31 results. Split the bracket into its two halves of 16 teams, 15 games each, enumerate 2^15 results per half, compute the winner and the sum of (place · team) for each half, and match the halves by hash of the sum. (recalled)
- Techniques: 3.9
- Needs this topic because: 2^31 results against 2 · 2^15 per half.
- Tier reasoning: rating 2600: tier 5.

## ac-abc184_f Programming Contest (tier 5, pattern sorted-merge, set practice)
- Budget: N ≤ 40, T ≤ 10^9.
- Idea: Subset sums of both halves; sort one; for each s ≤ T in the other, upper_bound(T − s) − 1 gives the best partner. Answer the maximum total.
- Techniques: 3.9, 1.1, 1.4
- Needs this topic because: a 0/1 knapsack whose capacity is too large for a table, but N is small.
- Tier reasoning: ABC F (difficulty about 1420).

## cf-912E Prime Gift (tier 5, pattern sorted-merge, set practice) †
- Budget: 16 primes, k up to 10^18, all numbers up to 10^18 (recalled).
- Idea: Split the primes into two groups so that each group generates about 10^6 numbers up to 10^18; sort both lists. Binary search on the answer x: count pairs (a, b) with a · b ≤ x by two pointers over the sorted lists, and take the smallest x with at least k pairs. (recalled)
- Techniques: 3.9, 1.3, 1.4
- Needs this topic because: the product of a left and a right number is a monotone merge test, so two pointers replace a binary search per element.
- Tier reasoning: rating 2400: tier 5.

## cf-1257F Make Them Similar (tier 5, pattern sorted-merge, set practice) †
- Budget: n ≤ 100 numbers below 2^30 (recalled).
- Idea: Find x with the same number of set bits in a_i xor x for every i. Split x into its low 15 and high 15 bits. For each of the 2^15 low halves record the vector of bit-count differences between a_1 and every other a_i (hash it); for each high half do the same with the negated vector and look it up. (recalled)
- Techniques: 3.9, 0.6
- Needs this topic because: 2^30 choices of x are too many; each half has 2^15, and the halves are matched by an exact key in a hash map.
- Tier reasoning: rating 2400: tier 5.

## ac-abc402_f Path to Integer (tier 5, pattern grid-path-split, set practice)
- Budget: N ≤ 20, M ≤ 10^9.
- Idea: Split at the anti-diagonal. Forward half: values of the prefix digits times 10^{remaining length} mod M per diagonal cell; backward half: suffix values mod M per cell. Per cell, sort one list and for each x find the largest y < M − x, also try the largest y overall.
- Techniques: 3.9, 1.1, 1.4, 0.4
- Needs this topic because: meet in the middle with a modular maximum.
- Tier reasoning: ABC F (difficulty about 1650).

## ac-abc271_f XOR on Grid Path (tier 5, pattern grid-path-split, set practice)
- Budget: N ≤ 20.
- Idea: Same split as CF 1006F with k = 0: forward XOR maps per anti-diagonal cell (i + j = N − 1, 0-based), backward walks from (N−1, N−1) look up the matching value; count the meeting cell exactly once.
- Techniques: 3.9, 1.7, 0.6
- Needs this topic because: meet in the middle on grid paths.
- Tier reasoning: ABC F (difficulty about 1670).

## cf-1006F Xor-Paths (tier 4, pattern grid-path-split, set practice) †
- Budget: n, m ≤ 20 (recalled).
- Idea: Walk from (1,1) to the anti-diagonal i + j = (n + m)/2, storing per cell a map xor → count; walk back from (n,m) to the same diagonal and look up value ⊕ k (excluding the meeting cell once). (recalled)
- Techniques: 3.9, 1.7, 0.6
- Needs this topic because: paths have 2^38 choices; splitting at the middle diagonal gives 2·2^19.
- Tier reasoning: rating 2100.

## cses-1628 Meet in the Middle (tier 3, pattern size-band, set reserved, for checkpoint)
- Budget: n ≤ 40, x ≤ 10^9.
- Idea: Enumerate subset sums of each half; sort one list; for each sum s in the other add the count of x − s (equal_range).
- Techniques: 3.9, 1.1, 1.4
- Needs this topic because: the textbook meet-in-the-middle count.
- Tier reasoning: CSES; tier 3 by judgement.

## lc-split-array-with-same-average Split Array With Same Average (tier 4, pattern size-band, set reserved, for checkpoint)
- Budget: n ≤ 30, values ≤ 10^4.
- Idea: Replace each a_i by b_i = n·a_i − S (S = total); equal averages ⇔ a non-empty proper subset of b sums to 0. Split into halves of 15; list (sum, size) for every subset of each half; for each left subset look up the negated sum in a set of right sums, excluding the case where both parts are empty and the case where both are full.
- Techniques: 3.9, 0.6
- Needs this topic because: 2^30 is too many, 2^15 per half fits; combining by an exact-sum lookup.
- Tier reasoning: LeetCode Hard; the transformation plus the empty/full exclusions make it review 3 level.

## cf-888E Maximum Subsequence (tier 3, pattern sorted-merge, set reserved, for checkpoint) †
- Budget: n ≤ 35, m ≤ 10^9 (recalled).
- Idea: Subset sums mod m of each half; sort one list. For each a, the best partner is the largest b < m − a (binary search), or else the largest b overall (sum wraps). (recalled)
- Techniques: 3.9, 1.1, 1.4, 0.4
- Needs this topic because: meet in the middle with a modular objective.
- Tier reasoning: rating 1800.

## cf-525E Anya and Cubes (tier 4, pattern size-band, set reserved, for review) †
- Budget: n ≤ 25, k ≤ n, S ≤ 10^16 (recalled; spot-check on the page).
- Idea: Each cube is skipped, taken, or taken with a factorial sticker (only values ≤ 18 can carry a factorial without exceeding S). Split into halves; for each half list (sum, stickers used) over 3^(n/2) choices, pruning sums above S; store the right half in a map from (sum, stickers) to count; for each left entry add the counts of right entries with sum S − x and at most k − used stickers (prefix counts over the sticker number).
- Techniques: 3.9, 0.6
- Needs this topic because: 3^25 is too many, 3^13 per half fits; combining by exact sum.
- Tier reasoning: Codeforces 2100, above the Phase 3 band: tier 4.

## lc-partition-array-into-two-arrays-to-minimize-sum-difference Partition Array Into Two Arrays to Minimize Sum Difference (tier 4, pattern sorted-merge, set reserved, for review)
- Budget: 2n ≤ 30.
- Idea: Split into halves of n. For each half, group subset sums by how many elements went to the first array. For k taken from the left, need n − k from the right; sort that group and binary-search total/2 − s.
- Techniques: 3.9, 1.1, 1.4
- Needs this topic because: meet in the middle with an extra count dimension.
- Tier reasoning: LeetCode Hard; the grouping by count is the extra step.

## cses-1642 Sum of Four Values (tier 3, pattern sorted-merge, set reserved, for review)
- Budget: n ≤ 1000, values up to 10^9.
- Idea: Four chosen positions split into two pairs. Store the sums of all pairs (up to 5 · 10^5) in a map from sum to the pair, or sort them; for each pair (i, j) look up x minus its sum and check that the four positions differ. For the distinctness, process the pairs by increasing second index and insert after the lookup.
- Techniques: 3.9, 1.1, 1.4, 0.6
- Needs this topic because: n^4 is 10^12, while n^2 pair sums and one lookup each is 10^6 steps.
- Tier reasoning: CSES, a standard pairs problem: tier 3.

## lc-closest-subsequence-sum Closest Subsequence Sum (tier 4, pattern sorted-merge, set reserved, for lookalike)
- Budget: n ≤ 40.
- Idea: Split in two halves of ≤ 20; list all subset sums of each; sort one list; for each sum s in the other, binary-search goal − s and check the neighbours.
- Techniques: 3.9, 1.1, 1.4
- Needs this topic because: 2^40 is too many; 2·2^20 with sorting is fine.
- Tier reasoning: LeetCode Hard.

## lc-target-sum Target Sum (tier 2, pattern size-band, set reserved, for lookalike)
- Budget: n ≤ 20.
- Idea: Try every sign pattern (2^20 ≈ 10^6) by recursion or bitmask and count those that reach target.
- Techniques: 0.5
- Needs this topic because: look-alike partner: same "pick signs or a subset to hit a target" shape as Closest Subsequence Sum, but n ≤ 20 makes plain brute force enough.
- Tier reasoning: LeetCode Medium; tier 2 so the pair sits at the same level as its partner's recognition step.

## lc-4sum-ii 4Sum II (tier 2, pattern sorted-merge, set reserved, for lookalike)
- Budget: n ≤ 200, values up to 2^28 in absolute value.
- Idea: n^4 is 1.6 · 10^9, too much. Count the sums A[i] + B[j] in a map (n^2 = 40000 entries); for each C[k] + D[l] add the count of its negative.
- Techniques: 3.9, 1.1, 1.4, 0.6
- Needs this topic because: the quadruples split into two pairs, and the pairs meet in one lookup.
- Tier reasoning: LeetCode Medium. Look-alike partner: lc-count-special-quadruplets (n ≤ 50, plain loops).

## lc-count-special-quadruplets Count Special Quadruplets (tier 2, pattern size-band, set reserved, for lookalike)
- Budget: n ≤ 50, values up to 100.
- Idea: Four indices a < b < c < d with nums[a] + nums[b] + nums[c] = nums[d]. n^4 / 24 is about 2.6 · 10^5 quadruples, so four nested loops are enough (a count table on d makes it n^3). Splitting into halves would add work for nothing.
- Techniques: 0.5
- Needs this topic because: it is the partner of lc-4sum-ii; the same sum shape, but n ≤ 50 makes the plain search the right answer.
- Tier reasoning: LeetCode Easy, but the index order needs care: tier 2.
