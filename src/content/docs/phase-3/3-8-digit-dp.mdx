## 1. Why this topic exists

Here is a small problem. How many integers $x$ with $1 \le x \le N$, where $N = 10^{18}$, have a digit sum that is a multiple of 4?

Checking every $x$ ([topic 0.5](../../phase-0/0-5-brute-force/)) is $10^{18}$ steps. A formula ([topic 2.3](../../phase-2/2-3-combinatorics/)) works for "all numbers with exactly 18 digits", where every digit is free, but $N$ is an arbitrary number: below $N = 734\,519$ the allowed digits depend on the digits already chosen.

The key idea: write $x$ with as many digits as $N$ (with leading zeros) and compare it with $N$ from the most significant digit. Either $x = N$, or there is a first position where $x$ has a smaller digit than $N$; before it, $x$ copies $N$, and after it, every digit is free. So a walk along the digits of $N$ needs to remember only two things: whether the prefix still equals $N$'s prefix (a **tight** flag), and whatever small summary the property needs (here, the digit sum modulo 4). That is $19 \cdot 2 \cdot 4$ states with 10 digits each: a few thousand steps instead of $10^{18}$. This is **digit DP**.

### What this topic does not cover

- Counting numbers (or strings) up to $N$ that contain a given word, which needs an automaton of the word as the state: string algorithms come in Phase 6.
- Finding the $k$-th number with a property by walking down the digits with counts: it uses the same tables, and appears here only in exercises.

## 3. Definitions

- The **decimal digits** of $N$ are $d_1 d_2 \dots d_L$, with $d_1$ the most significant. Every $x$ with $0 \le x \le N$ is written with exactly $L$ digits, using leading zeros. Example: for $N = 25$, $x = 7$ is written "07".
- A prefix of $x$ is **tight** if it equals the prefix of $N$ of the same length; then the next digit of $x$ can be at most the next digit of $N$. Once a digit is smaller than $N$'s, the prefix is **free** for good.
- A **leading zero** is a zero before the first non-zero digit; it is padding, not a digit of the number. The **started** flag says whether a non-zero digit has appeared.
- $F(N)$ denotes the number of $x$ in $[0, N]$ with the property.

## 4. Theory and proofs

### 4.1 The tight walk

**Theorem 3.8.1 (counting up to N).** Suppose whether $x$ has the property can be decided by reading its digits from left to right while keeping a state $s$ from a small set, updated as $s \leftarrow \delta(s, c)$ for each digit $c$. Let $\text{cnt}(i, t, s)$ be the number of ways to choose the digits at positions $i + 1..L$ so that the whole number has the property, given that the first $i$ digits led to state $s$ and the tight flag $t$. Then
$$\text{cnt}(i, t, s) = \sum_{c = 0}^{u} \text{cnt}\left(i + 1, \ t \wedge (c = d_{i+1}), \ \delta(s, c)\right), \qquad u = \begin{cases} d_{i+1} & \text{if } t,\\ 9 & \text{otherwise,} \end{cases}$$
with $\text{cnt}(L, t, s) = 1$ if $s$ is accepting and 0 otherwise. Then $F(N) = \text{cnt}(0, \text{true}, s_0)$. Time $O(L \cdot 2 \cdot |S| \cdot 10)$.

*Proof.* The numbers $0..N$ written with $L$ digits are exactly the digit strings that are not larger than $N$'s digit string. A string with a tight prefix can continue with a digit up to $d_{i+1}$ (a larger digit would make it larger than $N$), and the prefix stays tight only if the digit equals $d_{i+1}$; a free prefix can continue with any digit. So the recurrence lists every valid continuation once, split by the next digit (Theorem 3.5.1), and the state $s$ carries everything the property needs (Theorem 3.5.2). When the flag is false, the count does not depend on $N$ any more, so memoising $\text{cnt}(i, \text{false}, s)$ is safe; the tight states form a single path and need no memo. $\square$

:::note[This proof needs]
1. The property is decided by a left-to-right state with few values: a digit sum, a remainder, the previous digit, a count of non-zero digits, a mask of digits used.
2. Positions are counted from the most significant digit, so "smaller than $N$" is decided at the first difference.
3. $L$ is the number of digits of $N$ (18 for values below $10^{18}$; it can be $10^4$ if $N$ is given as a string).
:::

Example: $N = 25$, property "digit sum is a multiple of 4", state = digit sum mod 4. The first digit is 0, 1 (free) or 2 (tight):

| first digit | second digit allowed | numbers with the property | count |
|---|---|---|---|
| 0 (free) | 0–9 | 00, 04, 08 | 3 |
| 1 (free) | 0–9 | 13, 17 | 2 |
| 2 (tight) | 0–5 | 22 | 1 |

$F(25) = 6$: the numbers $0, 4, 8, 13, 17, 22$.

### 4.2 Ranges

**Theorem 3.8.2 (ranges).** The number of $x$ in $[A, B]$ with the property is $F(B) - F(A - 1)$ (with $F(-1) = 0$). When $A$ is given as a digit string too long for an integer, use $F(B) - F(A) + [A \text{ has the property}]$ instead of computing $A - 1$.

*Proof.* $[0, B]$ is the disjoint union of $[0, A - 1]$ and $[A, B]$, so the counts subtract; and $F(A - 1) = F(A) - [A \text{ has the property}]$. Modulo a prime, subtract as in Theorem 3.5.3. $\square$

:::note[This proof needs]
1. $F$ counts from 0 (or from 1, consistently in both terms).
2. Modulo $p$, add $p$ before taking the remainder of the difference.
:::

Example: in $[10, 25]$, the digit sums divisible by 4 belong to $13, 17, 22$: $F(25) - F(9) = 6 - 3 = 3$.

### 4.3 Leading zeros and neighbouring digits

Padding with leading zeros is harmless when the property ignores zeros (a digit sum, a remainder of the value). It is wrong when zeros matter: with the rule "no two equal neighbouring digits", the number 5 written as "005" would be rejected because of "00", although 5 has no neighbours at all.

**Theorem 3.8.3 (the started flag).** Add a flag $z$ to the state: $z$ is false while only zeros have been read. A zero read while $z$ is false keeps $z$ false and does not update the rest of the state; the first non-zero digit sets $z$ true. Then the recurrence of Theorem 3.8.1 counts every number $0..N$ once, with the property applied to its digits without padding.

*Proof.* Each number has one $L$-digit representation, so it is counted once. Its leading zeros leave the state as it was before any digit, so the property sees exactly the digits of the number from its first non-zero digit. The number 0 is the string of all zeros, with $z$ false at the end; count it or not as the problem requires. $\square$

:::note[This proof needs]
1. The rules (neighbours differ, digits non-decreasing, number of distinct digits) refer to the digits of the number itself, not its padding.
2. Check 0 separately: many problems count positive integers only.
:::

Example: among $1..100$ there are 90 numbers whose neighbouring digits all differ (9 one-digit numbers and 81 two-digit numbers; 100 fails). Without the started flag, the padded strings "001", …, "009" contain "00" and are rejected, and the count drops to 81.

### 4.4 Totals over a range

**Theorem 3.8.4 (count and total together).** Let each state return a pair (count, total), where count is the number of valid completions and total is the sum of a quantity $g$ over them. If $g$ is additive over digits (the digit sum, the number of times a digit appears), then putting digit $c$ in front of completions with pair $(n, T)$ contributes $(n, \ T + g(c) \cdot n)$. For the sum of the values themselves, a digit $c$ at a position with weight $10^k$ contributes $(n, \ T + c \cdot 10^k \cdot n)$.

*Proof.* Each of the $n$ completions gains $g(c)$ from the new digit, and the rest of its quantity is already in $T$. Summing over the digits allowed at the position adds up disjoint groups, as in Theorem 3.8.1. $\square$

:::note[This proof needs]
1. The quantity is a sum over digit positions (or a value built digit by digit), so it splits as "this digit" plus "the rest".
2. Both parts of the pair are computed from the same states; modulo a prime, reduce both.
:::

Example: the digit sums of $0..25$ add up to 127. By first digit: 0 gives $(10, 45)$, 1 gives $(10, 10 + 45) = (10, 55)$, and 2 (tight, second digit 0–5) gives $(6, 2 \cdot 6 + 15) = (6, 27)$; $45 + 55 + 27 = 127$.
