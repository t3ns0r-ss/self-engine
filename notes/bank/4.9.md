## ac-abc410_d XOR Shortest Walk (tier 3, pattern state-graph, set practice)
- Budget: N, M ≤ 1000 and every weight below 2^10, so at most 1000 · 1024 ≈ 10^6 states and about 10^6 moves.
- Idea: A walk may repeat edges, so the xor so far matters and the vertex alone is not enough. A state is (vertex v, xor x so far) with x < 1024; start at (1, 0); an edge v to w of weight c leads from (v, x) to (w, x xor c). One queue (or stack) search marks the reachable states; the answer is the smallest x with (N, x) marked, or -1.
- Techniques: 4.9, 4.1
- Needs this topic because: the state is the vertex plus a value that the rules do not hide, and the number of values is small.
- Tier reasoning: ABC D (difficulty 1048).

## ac-abc244_f Shortest Good Path (tier 4, pattern mask-search, set practice)
- Budget: N ≤ 17, so N · 2^N ≈ 2.2 · 10^6 states and about 3.5 · 10^7 moves.
- Idea: Only the parity of the number of visits to each vertex matters. A state is (mask of parities, last vertex). Start every state (1 << v, v) at distance 1 (a path with one vertex has length 1), and for the mask 0 the answer is 0 (the empty path). A move to a neighbour w goes to (mask xor (1 << w), w) at distance + 1. For every mask the answer is the smallest distance over the last vertex; the output is the sum over all 2^N masks.
- Techniques: 4.9, 4.1, 1.7
- Needs this topic because: the set is kept as a bitmask next to the place, and all starts enter the queue together.
- Tier reasoning: ABC F (difficulty 1661).

## ac-abc301_e Pac-Takahashi (tier 4, pattern mask-search, set practice)
- Budget: H, W ≤ 300, at most 18 candies, T ≤ 2 · 10^6.
- Idea: Walking between the at most 20 special cells (S, G, candies) is a grid search from each of them (20 searches of 9 · 10^4 cells). Then a table best[mask][last] is the fewest steps from S that visit exactly the candies of mask and end at candy last; 2^18 · 18 · 18 ≈ 8.5 · 10^7 steps. The answer is the largest popcount(mask) with best[mask][last] + dist(last, G) ≤ T, or -1 if even dist(S, G) > T.
- Techniques: 4.9, 4.1, 3.7
- Needs this topic because: the state is a place plus the set of visited candies, searched on the graph of distances.
- Tier reasoning: ABC E (difficulty 1673).

## ac-abc394_e Palindromic Shortest Path (tier 4, pattern state-graph, set reserved, for checkpoint)
- Budget: N ≤ 100, so N^2 = 10^4 states of the form (left end, right end), and each state tries at most N^2 pairs of edges: about 10^8 in the worst case.
- Idea: Build the palindrome from the middle outwards. A state (a, b) means "a walk from a to b whose labels form a palindrome". Start with (i, i) at length 0 and with (i, j) at length 1 for every edge i to j. From (a, b) take an edge c to a and an edge b to d with the same letter, which gives (c, d) at length + 2. Put the length-0 states into the queue first and the length-1 states after them, then run an ordinary queue-based search in which every move adds 2 (the queue stays sorted by length); the answer for (i, j) is the stored length of the state (i, j), or -1.
- Techniques: 4.9, 4.1
- Needs this topic because: the node is a pair of positions that grows from both ends, and no single position describes the search.
- Tier reasoning: ABC E (difficulty 1403).
