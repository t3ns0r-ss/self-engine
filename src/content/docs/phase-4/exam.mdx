This exam is deliberately mixed. Every problem below involves a graph, and a graph is the only thing the statements share: one problem is about states of a walk, one about dependencies, one about cheap routes, one about groups that merge, one about a tree, one about a tree with many questions, and one about what stays connected. The question is always the same: **which question am I asking of the graph?** The 7 problems come from all seven Phase 4 topics, in an order that has nothing to do with the course, and nothing on the page names their topic until you have finished.

**How to take it.**

1. Set aside 4 hours without interruptions. The timer keeps running if you reload the page.
2. Read every problem first, then solve them in the order you prefer. Use only what you would use in a contest: your own code and the C++ reference.
3. For each problem, note the first tool you tried. If it was the wrong one, that is a *Recognition miss*, even if you later solved the problem.
4. When the time is up (or you are done), mark what you solved within the time and where you had a Recognition miss.

**Pass rule.** At least 60% of the problems solved in time (5 of 7), and no Recognition miss on a solved problem. If you do not pass, the remediation map lists the topic, card and lesson section behind each problem: reread those, upsolve the problems, and sit the exam again after a few days.
