# Bank notes: topic 3.7

Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## ac-dp_o Matching (tier 3, pattern assignment-mask, set practice)
- Budget: N ≤ 21.
- Idea: dp[mask] = ways to pair the first popcount(mask) men with the women in mask; man popcount(mask) − 1 takes a woman in mask. O(2^N·N). mod 10^9+7.
- Techniques: 3.7, 1.7
- Needs this topic because: the assignment-by-mask template; the row index comes from the popcount.
- Tier reasoning: EDP O.

## lc-minimum-xor-sum-of-two-arrays Minimum XOR Sum of Two Arrays (tier 3, pattern assignment-mask, set practice)
- Budget: n ≤ 14.
- Idea: dp[mask] = min XOR sum when nums1[0..k) (k = popcount) are matched to the nums2 indices in mask.
- Techniques: 3.7, 1.7
- Needs this topic because: assignment DP minimising a cost.
- Tier reasoning: LeetCode Hard, but the template applies directly.

## lc-maximize-score-after-n-operations Maximize Score After N Operations (tier 3, pattern assignment-mask, set practice)
- Budget: 2n ≤ 14.
- Idea: dp[mask] over used elements; the operation index is popcount/2 + 1; choose the next pair inside the complement and add i·gcd. Precompute gcds.
- Techniques: 3.7, 2.1
- Needs this topic because: assigning pairs in order with a mask.
- Tier reasoning: LeetCode Hard.

## lc-maximum-and-sum-of-array Maximum AND Sum of Array (tier 4, pattern assignment-mask, set reserved, for review)
- Budget: n ≤ 2·numSlots ≤ 18.
- Idea: Duplicate each slot into two positions (2·numSlots ≤ 18 bits). dp[mask] over filled positions; number i = popcount(mask) goes into a free position p, gaining nums[i] & (p/2 + 1).
- Techniques: 3.7, 1.7
- Needs this topic because: capacity 2 handled by doubling the slots.
- Tier reasoning: LeetCode Hard.

## lc-number-of-ways-to-wear-different-hats-to-each-other Number of Ways to Wear Different Hats to Each Other (tier 4, pattern assignment-mask, set reserved, for exam)
- Budget: n ≤ 10 people, 40 hats.
- Idea: Mask over people (not hats): process hats 1..40; each hat goes to nobody or to one person who likes it and has none yet. mod 10^9+7.
- Techniques: 3.7
- Needs this topic because: the mask must go over the smaller side.
- Tier reasoning: LeetCode Hard.

## lc-can-i-win Can I Win (tier 3, pattern assignment-mask, set reserved, for drill)

## ac-abc318_d General Weighted Max Matching (tier 3, pattern assignment-mask, set practice)
- Budget: N ≤ 16.

## ac-abc142_e Get Everything (tier 4, pattern assignment-mask, set practice)
- Budget: N ≤ 12 boxes, M ≤ 1000 keys.
- Idea: Each key is a mask of boxes. dp[mask] = min cost to open mask; for each key, dp[mask | key] = min(dp[mask] + a). O(2^N·M).
- Techniques: 3.7
- Needs this topic because: knapsack whose "weight" is a set and combines by OR.
- Tier reasoning: ABC E (difficulty about 1400).

- Techniques: 3.7

- Tier reasoning: LeetCode Hard.

## ac-abc199_e Permutation (tier 5, pattern assignment-mask, set practice)
- Budget: N ≤ 18, M ≤ 100.

- Techniques: 3.7
- Needs this topic because: assignment DP with constraints checked on the prefix.

## cf-895C Square Subsets (tier 4, pattern assignment-mask, set practice) †

## cf-1238E Keyboard Purchase (tier 5, pattern assignment-mask, set practice) †

## ac-dp_u Grouping (tier 4, pattern submask-mask, set practice)
- Budget: N ≤ 16.
- Idea: score[mask] for a single group (precompute in O(2^N·N) by adding one element). best[mask] = max over non-empty submasks s containing the lowest bit of score[s] + best[mask ^ s]. O(3^N).
- Techniques: 3.7
- Needs this topic because: the submask-enumeration template.
- Tier reasoning: EDP U.

## lc-minimum-incompatibility Minimum Incompatibility (tier 4, pattern submask-mask, set practice)
- Budget: n ≤ 16, k divides n.
- Idea: For every mask of size n/k with distinct values, cost[mask] = max − min. dp[mask] = min over valid submasks s of dp[mask ^ s] + cost[s] (fix the lowest unused element in s to avoid repeats).
- Techniques: 3.7
- Needs this topic because: partition into equal-size groups via submasks.
- Tier reasoning: LeetCode Hard.

- Techniques: 3.7
- Needs this topic because: submask transitions where choices interact.
- Tier reasoning: LeetCode Hard.

## ac-abc332_e Lucky bag (tier 5, pattern submask-mask, set practice)
- Budget: D ≤ N ≤ 15.
- Idea: Minimise Σ x_i² (the mean is fixed). sq[mask] = (sum of mask)². dp[d][mask] = min over submasks s of dp[d−1][mask ^ s] + sq[s]. O(D·3^N). V = dp[D][all]/D − mean².
- Techniques: 3.7
- Needs this topic because: submask DP with a group count.
- Tier reasoning: ABC E (difficulty about 1880); tier 5 by the contest-letter rule.
