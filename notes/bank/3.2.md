## ac-dp_a Frog 1 (tier 1, pattern linear-state, set practice)
- Budget: N ≤ 10^5.
- Idea: dp[i] = min(dp[i−1] + |h_i − h_{i−1}|, dp[i−2] + |h_i − h_{i−2}|).
- Techniques: 3.2
- Needs this topic because: the first state-and-transition example.
- Tier reasoning: EDP A, the entry problem.

## ac-dp_b Frog 2 (tier 1, pattern linear-state, set practice)
- Budget: N ≤ 10^5, K ≤ 100.
- Idea: dp[i] = min over 1 ≤ j ≤ K of dp[i−j] + |h_i − h_{i−j}|; O(NK).
- Techniques: 3.2
- Needs this topic because: a transition over the last K states.
- Tier reasoning: EDP B.
