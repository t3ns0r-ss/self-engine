- Query conventions: old templates use 1-based "P[r] - P[l - 1]" and rectangle queries "x1 y1 x2 y2"; current uses 0-indexed "P[R] - P[L-1]" with shift and 2D queries "? L R U D" (columns first, line ~452).
- Numbers: old motivation uses n = q = 2*10^5 (4*10^10 steps, about 400 s); current uses 10^5 (10^10 steps, "about 100 seconds", line ~68). Not a conflict in method, only in the example size.
