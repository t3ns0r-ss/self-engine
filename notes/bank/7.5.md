# Bank notes: topic 7.5

Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## cses-1730 Nim Game I (tier 2, pattern nim-sum, set reserved, for lookalike)
- Budget: Σ n ≤ 2·10^5 heaps.
- Idea: Plain Nim: the first player wins iff the XOR of all heap sizes is non-zero.
- Techniques: 7.5, 1.7
- Needs this topic because: look-alike partner of Nim Game II: any number of sticks may be taken, so the Grundy value of a heap is its size.
- Tier reasoning: first CSES game problem.

## cses-1098 Nim Game II (tier 2, pattern grundy-pattern, set reserved, for lookalike)
- Budget: Σ n ≤ 2·10^5 heaps.
- Idea: With moves of 1, 2 or 3 sticks, the Grundy value of a heap of size x is x mod 4. The first player wins iff the XOR of (x mod 4) is non-zero.
- Techniques: 7.5, 1.7
- Needs this topic because: look-alike partner of Nim Game I: restricted moves change each heap's Grundy value, so XOR the pattern values, not the sizes.
- Tier reasoning: CSES mathematics section.

## lc-nim-game Nim Game (tier 1, pattern grundy-pattern, set practice)
- Budget: n ≤ 2^31 − 1.
- Idea: Taking 1–3 stones: positions that are multiples of 4 are losing; answer n % 4 != 0.
- Techniques: 7.5
- Needs this topic because: the simplest periodic pattern.
- Tier reasoning: LeetCode Easy.

## lc-divisor-game Divisor Game (tier 1, pattern grundy-pattern, set practice)
- Budget: n ≤ 1000.
- Idea: Alice wins iff n is even: from an even n, take x = 1 to give an odd number; from odd n every divisor is odd, giving an even number. (Or DP over n.)
- Techniques: 7.5, 0.4
- Needs this topic because: a parity pattern proved by induction.
- Tier reasoning: LeetCode Easy.

## cf-1194D 1-2-K Game (tier 1, pattern grundy-pattern, set practice) †
- Budget: n, k ≤ 10^9, T ≤ 100 (recalled).
- Idea: (recalled) If k is not a multiple of 3, Bob wins iff n % 3 = 0. Otherwise let r = n % (k + 1): if r = k Alice wins, else Bob wins iff r % 3 = 0.
- Techniques: 7.5
- Needs this topic because: find the pattern by brute force, then prove it.
- Tier reasoning: rating 1700.

## cf-1537D Deleting Divisors (tier 1, pattern grundy-pattern, set practice) †
- Budget: n ≤ 10^9 (recalled).
- Idea: (recalled) Odd n loses. Even n that is not a power of two wins (move to an odd losing number). n = 2^k wins iff k is even.
- Techniques: 7.5, 2.1
- Needs this topic because: classify positions by parity and powers of two.
- Tier reasoning: rating 1700.

## cses-2208 Another Game (tier 3, pattern grundy-pattern, set practice)
- Budget: Σ n ≤ 2·10^5.
- Idea: The first player wins iff some heap has an odd size (a move can always restore "all even" for the second player otherwise).
- Techniques: 7.5
- Needs this topic because: an invariant-based pattern instead of Grundy computation.
- Tier reasoning: CSES mathematics section.

## cses-2207 Grundy's Game (tier 4, pattern grundy-pattern, set practice)
- Budget: n ≤ 10^6, t ≤ 10^5 tests.
- Idea: Splitting a heap into two unequal parts: compute Grundy values by mex over splits for n up to about 2000; it is known (and verifiable offline) that for larger n the value is never 0, so the first player wins.
- Techniques: 7.5
- Needs this topic because: compute Grundy values, then rely on an observed pattern.
- Tier reasoning: CSES mathematics section, later.

## cf-2004E Not a Nim Problem (tier 3, pattern grundy-pattern, set practice) †
- Budget: values ≤ 10^7 (recalled).
- Idea: (recalled) Taking y with gcd(x, y) = 1. Grundy(1) = 1, even numbers 0, odd primes their index among primes (3 → 2, 5 → 3, …), odd composites the Grundy value of their smallest prime factor. Sieve, then XOR.
- Techniques: 7.5, 2.1
- Needs this topic because: Grundy values found by tabulating, then proved.
- Tier reasoning: rating 2100.

## cf-255E Furlo and Rublo and Game (tier 3, pattern grundy-pattern, set reserved, for review) †
- Budget: values ≤ 7.7·10^11 (recalled).
- Idea: (recalled) From x you may move to y in [⌈x^{1/4}⌉, ⌊√x⌋]. Grundy values are constant on a few long intervals; compute them for x up to about 10^6 by sliding counts, derive the interval table for larger x, then XOR.
- Techniques: 7.5, 1.4
- Needs this topic because: Grundy values grouped into intervals.
- Tier reasoning: rating 2200.

## cf-15C Industrial Nim (tier 2, pattern nim-sum, set practice) †
- Budget: n ≤ 10^5 quarries (recalled).
- Idea: (recalled) Each quarry is a run of consecutive heap sizes x, x + 1, …, x + m − 1. XOR them with the formula for XOR of 0..k (k mod 4 cases); total XOR non-zero means "tolik" wins.
- Techniques: 7.5, 1.7
- Needs this topic because: Nim sum with a fast XOR of ranges.
- Tier reasoning: rating 2000.

## cses-1099 Stair Game (tier 3, pattern nim-sum, set practice)
- Budget: Σ n ≤ 2·10^5.
- Idea: Moving balls from an even-indexed stair (1-indexed) to an odd one is Nim on the even stairs; moves from odd stairs can be mirrored. First player wins iff XOR of p_2, p_4, … is non-zero.
- Techniques: 7.5, 1.7
- Needs this topic because: reduce to Nim on part of the position.
- Tier reasoning: CSES mathematics section.

## lc-chalkboard-xor-game Chalkboard XOR Game (tier 4, pattern nim-sum, set practice)
- Budget: n ≤ 1000.
- Idea: Alice wins iff the XOR is already 0 or n is even (with an even count and non-zero XOR she can always remove a number keeping the XOR non-zero).
- Techniques: 7.5, 1.7
- Needs this topic because: an XOR invariant argument.
- Tier reasoning: LeetCode Hard.

## cf-786A Berzerk (tier 2, pattern win-lose, set practice) †
- Budget: n ≤ 7000 (recalled).
- Idea: (recalled) Retrograde analysis: the black hole (position 1) is losing for the player to move. BFS backwards: a position is winning if some move leads to a losing one; losing once all moves lead to winning ones (count down a degree counter). Remaining states are loops.
- Techniques: 7.5, 4.1
- Needs this topic because: win/lose/draw on a cyclic game graph.
- Tier reasoning: rating 2000.
