## lc-rectangle-area-ii Rectangle Area II (tier 4, pattern cover-sweep, set practice)
- Budget: ≤ 200 rectangles.
- Idea: Sweep x; a tree over compressed y stores cover counts (range add ±1) and covered length (non-zero parts). Area += covered length · Δx, mod 10^9+7. (n ≤ 200 also allows O(n²) compression.)
- Techniques: 5.4, 5.3, 1.1
- Needs this topic because: union area by sweep with cover counts.
- Tier reasoning: LeetCode Hard.

## ac-abc360_f InterSections (tier 4, pattern cover-sweep, set practice)
- Budget: N ≤ 10^5, coordinates ≤ 10^9, so about 2·10^5 sweep positions with a tree over the compressed l values.
- Idea: For a fixed r, the interval i crosses [l, r] when L_i < l < R_i < r (counts for l in (L_i, R_i) once r > R_i) or l < L_i < r < R_i (counts for l < L_i while L_i < r < R_i). Sweep r upward; at the events of each interval add 1 to the matching range of l. Range add, global maximum, leftmost position of the maximum (Theorem 5.4.3); the best (l, r) is the first strict improvement with the smallest r and the leftmost l. The candidates for l and r are the values L_i and R_i with the neighbours ±1, so compress those.
- Techniques: 5.4, 5.3, 1.1
- Needs this topic because: sweep, range add, maximum with its position, ties for the smallest pair.
- Tier reasoning: ABC F (difficulty 2563).

## cf-610D Vika and Segments (tier 5, pattern cover-sweep, set practice) †
- Budget: n ≤ 10^5, coordinates up to 10^9 (recalled).
- Idea: (recalled) The painted cells are the union of horizontal and vertical segments. Merge overlapping segments on the same line (sort and merge: a 1D covered length, which is Theorem 5.4.2 with a single gap row). The answer is the total merged length minus the number of cells where a merged horizontal and a merged vertical segment cross, counted with a Fenwick tree over y (Theorem 5.4.4).
- Techniques: 5.4, 5.2, 1.1
- Needs this topic because: covered length plus a crossing count in one sweep.
- Tier reasoning: rating 2300.

## cf-1221F Choose a Square (tier 5, pattern cover-sweep, set practice) †
- Budget: n ≤ 5·10^5 points (recalled).
- Idea: (recalled) A square has its corners on the line y = x and covers the points with a ≤ x, y ≤ b; it is paid by the points inside (with costs) minus its side. Sweep b upward; a point (x, y, cost) counts for every a ≤ min(x, y) once b ≥ max(x, y), a range add on a. Query: the maximum of (value of a) + a - b with its position (Theorem 5.4.3 with a second term per position).
- Techniques: 5.4, 5.3, 1.1
- Needs this topic because: range add, maximum and its position in one sweep.
- Tier reasoning: rating 2400.

## cses-1740 Intersection Points (tier 3, pattern sweep-count, set practice)
- Budget: n ≤ 10^5, coordinates ≤ 10^6.
- Idea: Sweep x. A horizontal segment is inserted at its left end and removed after its right end; a vertical segment asks for the number of live horizontals with y in its range (Fenwick tree over y). The statement promises no endpoint is a crossing, so ties do not matter there; with closed segments the order is open, ask, close.
- Techniques: 5.4, 5.2, 1.1
- Needs this topic because: segment crossings counted with a Fenwick tree during a sweep.
- Tier reasoning: CSES Advanced-level.

## cses-2169 Nested Ranges Count (tier 3, pattern sweep-count, set practice)
- Budget: n ≤ 2·10^5, endpoints ≤ 10^9.
- Idea: Contained ranges: sort by left end descending (equal left: smaller right first); insert each right end into a Fenwick tree over the compressed right ends after counting the earlier ones with right end ≤ r. Containing ranges: sort by left ascending (equal left: larger right first) and count earlier right ends ≥ r. The two tie rules are the point of the problem.
- Techniques: 5.4, 5.2, 1.1
- Needs this topic because: dominance counting with ties on one coordinate.
- Tier reasoning: CSES Sorting and Searching (rated above the others there).

## cf-524E Rooks and Rectangles (tier 5, pattern sweep-count, set practice) †
- Budget: n·m up to 10^10 cells, k and q ≤ 2·10^5 (recalled).
- Idea: (recalled) A rectangle is fully attacked when every row has a rook inside the rectangle or every column has one. Sweep the right edge x; a tree over rows holds the latest column of a rook in each row (a maximum per row); a query asks for the minimum of that over the rows of the rectangle and compares with the left edge. The same for columns by swapping the axes. The tree holds an aggregate other than a count.
- Techniques: 5.4, 5.3, 1.1
- Needs this topic because: the same sweep with a different value in the tree.
- Tier reasoning: rating 2400.

## cf-1190D Tokitsukaze and Strange Rectangle (tier 3, pattern sweep-count, set reserved, for checkpoint) †
- Budget: n ≤ 2·10^5 points, coordinates ≤ 10^9 (recalled).
- Idea: (recalled in outline, not checked against the page) Count the different sets of points that can be cut out by a rectangle whose lower side is a given horizontal line and whose top is open. Sweep y from the top; the points of the same y form one group; for each group sorted by x, a Fenwick tree over the compressed x of the points above counts the x values on each side of every point, and the number of new sets is a product of those counts. Ties in y are one group, so the group is inserted after it has been counted.
- Techniques: 5.4, 5.2, 1.1
- Needs this topic because: a counting sweep whose ties are a row.
- Tier reasoning: rating 2000.

## ac-typical90_q Crossing Segments（★7） (tier 4, pattern sweep-count, set reserved, for checkpoint)
- Budget: N, M ≤ 3·10^5.
- Idea: Two chords cross (ends not shared) when L_s < L_t < R_s < R_t. Sort the chords by L; take the chords of equal L as one group, ask each chord of the group for the number of earlier chords with R in the open range (L_t, R_t) (Fenwick tree over R), then insert the group. Ties in L are not crossings, so ask before inserting.
- Techniques: 5.4, 5.2, 1.1
- Needs this topic because: counting with the tie rule "ask the whole group, then insert it".
- Tier reasoning: Typical 90, star rating 7.

## lc-perfect-rectangle Perfect Rectangle (tier 4, pattern cover-sweep, set reserved, for review)
- Budget: ≤ 2·10^4 rectangles, coordinates within ±10^5.
- Idea: The rectangles form an exact cover of a rectangle when the sum of their areas equals the area of the union and the union equals its bounding box. The union area is Theorem 5.4.1 with the counted-cover tree; compare with the bounding box and with the sum of the areas. (The usual solution counts corners in a hash set; the sweep is an alternative.)
- Techniques: 5.4, 5.3, 1.1
- Needs this topic because: union area compared with the sum of areas.
- Tier reasoning: LeetCode Hard.

## lc-count-number-of-rectangles-containing-each-point Count Number of Rectangles Containing Each Point (tier 3, pattern sweep-count, set reserved, for review)
- Budget: ≤ 5·10^4 rectangles and points, heights ≤ 100.
- Idea: A rectangle (l, h) at the origin contains the point (x, y) when l ≥ x and h ≥ y. Sort rectangles by l and points by x, sweep x downward, add the heights to a Fenwick tree (height ≤ 100) and count the heights ≥ y. Ties: a rectangle with l = x counts, so add before asking.
- Techniques: 5.4, 5.2, 1.1
- Needs this topic because: dominance counting offline with the tie rule "add equal values first".
- Tier reasoning: LeetCode Medium.

## ac-abc136_f Enclosed Points (tier 4, pattern sweep-count, set reserved, for review)
- Budget: N ≤ 2·10^5, modulus 998244353.
- Idea: The coordinates are distinct. For a point i, let a, b, c, d be the numbers of points in its four quadrants (counted with a Fenwick sweep over x and y ranks). The subsets T whose rectangle contains point i number 2^N minus the subsets that avoid it, which is computed from the four quadrant counts and powers of 2 modulo p (inclusion–exclusion over the four sides); the sum over i is the answer.
- Techniques: 5.4, 5.2, 2.2, 1.1
- Needs this topic because: four quadrant counts for every point by a sweep.
- Tier reasoning: ABC F (difficulty 2334).

## lc-separate-squares-ii Separate Squares II (tier 4, pattern cover-sweep, set reserved, for lookalike)
- Budget: ≤ 5·10^4 squares, coordinates ≤ 10^9.
- Idea: Sweep along y with events at the bottom and top of each square and the counted-cover tree over compressed x; the covered x-length is constant between events, so the union area below y is piecewise linear. Take the total, find the strip where half of it is reached and solve the linear equation inside the strip (a division in floating point).
- Techniques: 5.4, 5.3, 1.4
- Needs this topic because: union area as a function of the sweep position.
- Tier reasoning: LeetCode Hard.
