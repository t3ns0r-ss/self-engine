## lc-k-th-smallest-in-lexicographical-order K-th Smallest in Lexicographical Order (tier 4, pattern prefix-tree, set reserved, for review)
- Budget: n up to 10^9, k ≤ n.
- Idea: The numbers 1..n written in decimal form a trie with the digits as edges, never built. For a prefix p, count the numbers in [1, n] that start with p by levels: at each level add min(n + 1, upper) − lower for the interval of numbers of that length starting with p. Walk from the empty prefix: if k exceeds the count of prefix p, skip to p + 1 and subtract; otherwise go down to p·10 and subtract 1. About 10·10 steps.
- Techniques: 6.3
- Needs this topic because: counts of prefixes without building the tree; the node count of a trie as a number of numbers.
- Tier reasoning: LeetCode Hard.

## lc-longest-common-prefix-of-k-strings-after-removal Longest Common Prefix of K Strings After Removal (tier 4, pattern counted-trie, set practice (ladder, card counted-trie, rung 3))
- Budget: Σ |words[i]| ≤ 10^5.
- Idea: Insert all words into a trie with pass counts. For the whole array the best common prefix of k strings is the deepest node with count ≥ k. Removing the word i lowers the counts along its own path by 1; only nodes on that path can drop below k. Precompute, for the deepest node with count ≥ k overall and with count ≥ k + 1 (and a prefix maximum of depths over the sorted nodes), so that each removal is answered from the path of word i in O(its length).
- Techniques: 6.3
- Needs this topic because: counts per node and a query that changes only one root-to-node path.
- Tier reasoning: LeetCode Hard.

## lc-partition-string Partition String (tier 2, pattern dictionary-split, set reserved, for drill)

## lc-delete-duplicate-folders-in-system Delete Duplicate Folders in System (tier 4, pattern prefix-tree, set reserved, for lookalike)
- Budget: up to 2·10^4 paths of up to 500 folder names, total length of names up to 2·10^5.
- Idea: The paths form a trie whose edges carry folder names (children in a map, sorted by name). A post-order walk gives each node a text that lists its children's names and texts; two folders are identical exactly when these texts are equal, and only non-empty ones (with at least one child) count. Count each text in a map, mark every node whose text occurs at least twice, and print the paths that stay (a marked node removes its whole subtree).
- Techniques: 6.3, 0.6
- Needs this topic because: the file system as a trie of folder names; the identical subtrees are found by serialising nodes bottom-up.
- Tier reasoning: LeetCode Hard.
