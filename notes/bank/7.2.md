## ac-dp_g Longest Path (tier 2, pattern longest-path, set practice)
- Budget: N, M ≤ 10^5, DAG.
- Idea: Topological order (Kahn); dp[v] = max over edges u → v of dp[u] + 1; answer max dp. Or memoised DFS.
- Techniques: 7.2
- Needs this topic because: longest path in a DAG.
- Tier reasoning: Educational DP Contest G; judgement tier 2.

## cses-1680 Longest Flight Route (tier 2, pattern longest-path, set practice)
- Budget: n ≤ 10^5, m ≤ 2·10^5, DAG.
- Idea: In topological order, dp[v] = max dp[u] + 1 over reachable predecessors u (only from city 1); keep parents; print the path to n or IMPOSSIBLE.
- Techniques: 7.2
- Needs this topic because: longest path with reconstruction.
- Tier reasoning: CSES graph section.

## lc-maximum-number-of-jumps-to-reach-the-last-index Maximum Number of Jumps to Reach the Last Index (tier 2, pattern longest-path, set reserved, for drill)
- Budget: n ≤ 1000.
- Idea: Edges go forward only (i < j with |nums[j] − nums[i]| ≤ target): a DAG in index order. dp[j] = max dp[i] + 1 over valid i; −1 if unreachable.
- Techniques: 7.2
- Needs this topic because: index order is a topological order.
- Tier reasoning: LeetCode Medium.

## cf-1679D Toss a Coin to Your Graph... (tier 2, pattern longest-path, set practice) †
- Budget: n, m ≤ 2·10^5, k ≤ 10^18 (recalled).
- Idea: (recalled) Binary search the answer x: keep vertices with a_i ≤ x. If they contain a cycle, any length works; else the longest path (in vertices) must be ≥ k.
- Techniques: 7.2, 1.4, 4.2
- Needs this topic because: longest path inside a feasibility check.
- Tier reasoning: rating 1900.

## cf-1674G Remove Directed Edges (tier 3, pattern longest-path, set practice) †

- Idea: (recalled) An edge u → v can join a cute set's path only if outdeg(u) ≥ 2 and indeg(v) ≥ 2 (each vertex can lose one in- and one out-edge). Answer = longest path (in vertices) using only such edges.

- Tier reasoning: rating 2000.

- Techniques: 7.2

- Tier reasoning: LeetCode Hard.

## lc-jump-game-v Jump Game V (tier 4, pattern longest-path, set reserved, for review)
- Budget: n ≤ 1000, d ≤ n.
- Idea: Jumps go to strictly lower bars, so heights order the DAG. Process indices by increasing height: dp[i] = 1 + max dp[j] over j reachable within d without a bar ≥ arr[i] in between.
- Techniques: 7.2
- Needs this topic because: sort by a key that every edge decreases.
- Tier reasoning: LeetCode Hard.

## lc-maximum-strictly-increasing-cells-in-a-matrix Maximum Strictly Increasing Cells in a Matrix (tier 4, pattern longest-path, set practice)
- Budget: m·n ≤ 10^5.
- Idea: Process cells by increasing value; dp(cell) = 1 + max(rowBest[r], colBest[c]). For equal values, compute all dp first, then update row and column bests.
- Techniques: 7.2, 1.1
- Needs this topic because: DAG DP with aggregated predecessors per row/column.
- Tier reasoning: LeetCode Hard.

## lc-number-of-restricted-paths-from-first-to-last-node Number of Restricted Paths From First to Last Node (tier 3, pattern count-paths, set practice)
- Budget: n ≤ 2·10^4, edges ≤ 4·10^4.
- Idea: Dijkstra from n. Allowed moves go to strictly smaller distance, a DAG. Process nodes by increasing distance: ways[v] = Σ ways[u] over neighbours with smaller distance; ways[n] = 1.
- Techniques: 7.2, 4.3
- Needs this topic because: a DAG defined by distances, then counting.
- Tier reasoning: LeetCode Medium.

## lc-count-all-possible-routes Count All Possible Routes (tier 4, pattern state-dag, set practice)
- Budget: ≤ 100 locations, fuel ≤ 200.
- Idea: Every move costs positive fuel, so (city, fuel) states form a DAG. dp[city][fuel] = [city = finish] + Σ dp[next][fuel − cost]; mod 10^9+7.
- Techniques: 7.2
- Needs this topic because: a decreasing resource makes the state graph acyclic.
- Tier reasoning: LeetCode Hard.

- Techniques: 7.2, 0.6

## lc-minimum-number-of-days-to-eat-n-oranges Minimum Number of Days to Eat N Oranges (tier 4, pattern state-dag, set practice)
- Budget: n ≤ 2·10^9.
- Idea: Only divisions matter: f(n) = 1 + min(n mod 2 + f(n/2), n mod 3 + f(n/3)), f(0) = 0, f(1) = 1, memoised in a hash map (O(log² n) states).
- Techniques: 7.2, 0.6
- Needs this topic because: the reachable state DAG is tiny once single steps are folded in.
- Tier reasoning: LeetCode Hard.
