## Goal

Phase 0 builds the habits every later phase relies on: writing C++ that reads input fast and never overflows, estimating the running time of an idea from the constraints before coding it, implementing a described process exactly, reasoning with remainders and divisibility, trying every candidate when the input is small, and choosing the right standard container. By the end you should solve AtCoder Beginner Contest (ABC) problems A–C reliably and many D problems, and Codeforces problems rated about **800–1000**, the target band of this phase.

## Topics

Work through them in order; each lesson lists what it uses from the earlier ones.

| topic | what it gives you |
|---|---|
| [0.1 C++ for CP](0-1-cpp-for-cp/) | Input and output, `long long` and overflow, integer division and rounding, test cases. |
| [0.2 Complexity analysis](0-2-complexity/) | The step budget, reading constraints, closed forms, amortised and harmonic loop counts. |
| [0.3 Implementation and simulation](0-3-implementation/) | Simulating a process, repeating states, grids, one-pass string scans, case analysis. |
| [0.4 Parity, divisibility, GCD, modular arithmetic](0-4-elementary-math/) | Remainders in C++, counting multiples, parity invariants, Euclid, LCM, arithmetic modulo $m$. |
| [0.5 Brute force](0-5-brute-force/) | Nested loops, subsets as bitmasks, all orders with `next_permutation`, recursion, enumerating the answer. |
| [0.6 STL toolbox](0-6-stl-toolbox/) | `set`, `map`, `multiset`, `priority_queue`, `stack`, `queue`, `deque`, and what each operation costs. |

## Time

Plan on **15 to 20 hours per topic**: about 3 hours to read the lesson and redo its proofs and templates, 10 to 15 hours for the ladder of 19–20 problems, and 2 hours for the drill and the checkpoint. With the reviews spread over the following two months, Phase 0 takes roughly **100 to 120 hours**. If the early ladder rungs of a topic feel easy, move quickly; the struggle budget on each problem tells you when to open a hint.

## The Phase 0 exam

After the six checkpoints, take the [Phase 0 exam](exam/): 7 problems in **3 hours**, one or two from each topic, in a mixed order with the topics hidden. Contests never say which tool a problem needs, so the exam checks recognition as much as solving. You pass by solving at least 60% of the problems in time (5 of 7) with no Recognition miss on a solved problem, that is, without first trying a wrong tool on a problem you then solved. After the exam, a remediation map shows for each problem the topic, the card, and the lesson section to reread.
