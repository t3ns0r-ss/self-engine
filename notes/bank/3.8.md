# Bank notes: topic 3.8

Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## ac-dp_s Digit Sum (tier 3, pattern digit-sum-state, set practice)
- Budget: K < 10^10000, D ≤ 100.
- Idea: Walk K's digits with state (tight, digit sum mod D). Count numbers in [0, K] with sum ≡ 0, then subtract 1 for zero. mod 10^9+7.
- Techniques: 3.8
- Needs this topic because: the digit DP template with a remainder.
- Tier reasoning: EDP S.

## cses-2220 Counting Numbers (tier 3, pattern neighbour-digits, set practice)
- Budget: 0 ≤ a ≤ b ≤ 10^18.
- Idea: f(x) = numbers in [0, x] with no two equal adjacent digits; state (position, previous digit, tight, started). Answer f(b) − f(a − 1), with a = 0 handled separately.
- Techniques: 3.8
- Needs this topic because: neighbour constraint and leading zeros.
- Tier reasoning: CSES.

## ac-abc387_c Snake Numbers (tier 2, pattern count-up-to-n, set practice)
- Budget: 10 ≤ L ≤ R ≤ 10^18.
- Idea: f(x) = Snake numbers ≤ x. For lengths shorter than x: Σ over top digit t of t^{len−1}. For x's own length, walk the digits under the rule "every later digit < top digit", adding counts when going below x's digit. Answer f(R) − f(L − 1).
- Techniques: 3.8
- Needs this topic because: f(R) − f(L − 1) with a property fixed by the first digit.
- Tier reasoning: ABC C (difficulty about 1250).

## ac-abc154_e Almost Everywhere Zero (tier 4, pattern count-up-to-n, set practice)
- Budget: N < 10^100, K ≤ 3.
- Idea: State (position, non-zero digits used ≤ K, tight). Count numbers in [1, N] with exactly K non-zero digits.
- Techniques: 3.8
- Needs this topic because: digit DP with a small counter.
- Tier reasoning: ABC E (difficulty about 1300).

## ac-abc336_e Digit Sum Divisible (tier 4, pattern digit-sum-state, set practice)
- Budget: N ≤ 10^14.
- Idea: Fix the target digit sum s (1..126). For each s, digit DP with state (sum so far ≤ s, value mod s, tight); count those with sum = s and value ≡ 0. Total about 126 · 15 · 126 · 126 · 10 steps.
- Techniques: 3.8
- Needs this topic because: fix the modulus outside, then a digit DP with two remainders.
- Tier reasoning: ABC E (difficulty about 1540).

## ac-abc208_e Digit Products (tier 5, pattern count-up-to-n, set practice)
- Budget: N ≤ 10^18, K ≤ 10^9.
- Idea: Digit DP where the state is the product so far; only products of digits 1–9 (form 2^a3^b5^c7^d) occur, so a map per position stays small. Track "started" (leading zeros) and tight; a zero digit after starting makes the product 0.
- Techniques: 3.8, 0.6
- Needs this topic because: a large-looking state that is sparse, stored in a map.
- Tier reasoning: ABC E (difficulty about 2020); tier 5 by the contest-letter rule.

## ac-abc129_e Sum Equals Xor (tier 4, pattern count-up-to-n, set reserved, for checkpoint)
- Budget: |L| ≤ 10^5 bits.
- Idea: a + b = a XOR b means no shared 1-bits. Walk L's bits with tight/loose states: on a 1-bit, (1,0) and (0,1) keep tight (2 ways), (0,0) goes loose; loose bits have 3 choices. mod 10^9+7.
- Techniques: 3.8, 1.7
- Needs this topic because: digit DP in base 2 with a pair of numbers.
- Tier reasoning: ABC E (difficulty about 1550).

## lc-numbers-at-most-n-given-digit-set Numbers At Most N Given Digit Set (tier 3, pattern count-up-to-n, set practice)
- Budget: n ≤ 10^9, ≤ 9 digits.
- Idea: Shorter lengths: Σ |D|^len. Same length: walk n's digits; add (digits below n's digit)·|D|^{remaining}; continue only if n's digit is in D; count n itself if all matched.
- Techniques: 3.8
- Needs this topic because: the tight walk without a DP table.
- Tier reasoning: LeetCode Hard.

## lc-number-of-digit-one Number of Digit One (tier 3, pattern digit-aggregate, set practice)
- Budget: n ≤ 10^9.
- Idea: For each position with weight p: ones = (n / (10p))·p + min(max(n % (10p) − p + 1, 0), p). Or digit DP returning (count, ones).
- Techniques: 3.8
- Needs this topic because: summing a digit quantity over [1, n].
- Tier reasoning: LeetCode Hard.

## lc-count-numbers-with-unique-digits Count Numbers with Unique Digits (tier 2, pattern count-up-to-n, set reserved, for lookalike)
- Budget: n ≤ 8.
- Idea: For each length L ≤ n: 9·9·8·…(L − 1 factors after the first); plus 1 for zero. Pure counting, no bound to follow.
- Techniques: 2.3
- Needs this topic because: look-alike partner of Count Special Integers: the range is all numbers below 10^n, so a product formula suffices.
- Tier reasoning: LeetCode Medium.

## lc-count-special-integers Count Special Integers (tier 4, pattern count-up-to-n, set reserved, for lookalike)
- Budget: n ≤ 2·10^9.
- Idea: Lengths shorter than n by the product formula; then walk n's digits with a mask of used digits, adding permutations of the remaining digits for each smaller choice; stop when a digit repeats.
- Techniques: 3.8, 2.3
- Needs this topic because: look-alike partner of Count Numbers with Unique Digits: an arbitrary upper bound n requires the tight digit walk.
- Tier reasoning: LeetCode Hard.

## lc-numbers-with-repeated-digits Numbers With Repeated Digits (tier 4, pattern count-up-to-n, set reserved, for review)
- Budget: n ≤ 10^9.
- Idea: Count numbers in [1, n] with all distinct digits (mask DP or permutations along the tight walk); answer n − that.
- Techniques: 3.8, 2.3
- Needs this topic because: complement plus a digit walk with a used-digit mask.
- Tier reasoning: LeetCode Hard.

## lc-count-of-integers Count of Integers (tier 4, pattern digit-sum-state, set practice)
- Budget: num ≤ 10^22 as strings, digit sums ≤ 400.
- Idea: f(x) = numbers in [0, x] with digit sum in [min_sum, max_sum]; state (position, sum, tight). Answer f(num2) − f(num1) + [num1 is good] (avoids decrementing a string). mod 10^9+7.
- Techniques: 3.8
- Needs this topic because: range on both the value and the digit sum.
- Tier reasoning: LeetCode Hard.

## lc-number-of-beautiful-integers-in-the-range Number of Beautiful Integers in the Range (tier 4, pattern digit-sum-state, set reserved, for review)
- Budget: high ≤ 10^9, k ≤ 20.
- Idea: State (position, even count − odd count, value mod k, tight, started). Count f(high) − f(low − 1).

## lc-count-the-number-of-powerful-integers Count the Number of Powerful Integers (tier 4, pattern count-up-to-n, set reserved, for exam)
- Budget: finish ≤ 10^15, limit ≤ 9.
- Idea: f(x): numbers ≤ x ending in s with all digits ≤ limit. The free prefix has (limit + 1)^{len} choices; walk x's prefix digits under the limit, then compare the suffix of x with s for the tight case. Answer f(finish) − f(start − 1).
- Techniques: 3.8
- Needs this topic because: a fixed suffix makes the tight case end in a string comparison.
- Tier reasoning: LeetCode Hard.

## lc-non-negative-integers-without-consecutive-ones Non-negative Integers without Consecutive Ones (tier 3, pattern neighbour-digits, set practice)
- Budget: n ≤ 10^9.
- Idea: fib[k] = binary strings of length k without "11". Walk n's bits from the top: at each 1-bit add fib[remaining]; stop if two 1-bits are adjacent in n; add 1 for n itself if valid.
- Techniques: 3.8
- Needs this topic because: neighbour constraint in base 2.
- Tier reasoning: LeetCode Hard.

## cf-914C Travelling Salesman and Special Numbers (tier 3, pattern count-up-to-n, set reserved, for checkpoint) †
- Budget: n < 2^1000, k ≤ 1000 (recalled).
- Idea: Steps from x depend only on popcount(x) after one step; precompute steps for 1..1000. For each popcount c with steps[c] = k − 1, count numbers ≤ n with popcount c (walk bits, add C(remaining, c − used)). Handle k = 0 and k = 1 specially. (recalled)
- Techniques: 3.8, 2.3
- Needs this topic because: count numbers ≤ n in base 2 by popcount.
- Tier reasoning: rating 1800.

## ac-abc317_f Nim (tier 5, pattern digit-sum-state, set practice)
- Budget: N ≤ 10^18, A_i ≤ 10.
- Idea: Binary digit DP from the top bit over three numbers at once: state (X_1 mod A_1, X_2 mod A_2, X_3 mod A_3, three tight flags); each bit chooses (b1, b2, b3) with even XOR. Subtract triples with a zero. mod 998244353.
- Techniques: 3.8, 1.7

- Tier reasoning: ABC F (difficulty about 2070).
