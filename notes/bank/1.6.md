## lc-next-greater-element-i Next Greater Element I (tier 1, pattern nearest-greater, set practice)
- Budget: lengths ≤ 1000 (O(n) intended).
- Idea: Scan nums2 with a decreasing stack; when x arrives, pop every smaller value v and record next[v] = x. Answer queries from the map.
- Techniques: 1.6, 0.6
- Needs this topic because: the monotonic stack finds every next-greater in one pass.
- Tier reasoning: LeetCode Easy.

## ac-abc372_d Buildings (tier 3, pattern nearest-greater, set practice)
- Budget: N ≤ 2·10^5.
- Idea: The j counted for i are the left-to-right maxima of H_{i+1..N}. Scan i from N − 1 down to 1: push H_{i+1} after popping every shorter building on the stack (they are hidden behind it); c_i is the stack size (c_N = 0).

- Tier reasoning: ABC D.

## cf-280B Maximum Xor Secondary (tier 5, pattern nearest-greater, set practice) †
- Budget: n ≤ 10^5, distinct values (recalled).
- Idea: For every pair where one is the maximum and the other the second maximum of some subarray, the two are adjacent in a monotonic stack. Push values with a decreasing stack, and at each push/pop compare max ⊕ second for the pair (top, new). Answer the largest XOR.
- Techniques: 1.6
- Needs this topic because: only O(n) candidate pairs, found by the stack.
- Tier reasoning: rating 1800, Phase 1 tier 5.
