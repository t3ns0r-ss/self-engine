## lc-sum-of-all-odd-length-subarrays Sum of All Odd Length Subarrays (tier 1, pattern contribution-total, set practice)
- Budget: n ≤ 100 (O(n) possible).
- Idea: arr[i] lies in (i + 1)(n − i) subarrays; ⌈that / 2⌉ of them have odd length. Sum arr[i] times that count.
- Techniques: 2.4
- Needs this topic because: summing per element instead of per subarray.
- Tier reasoning: LeetCode Easy.

## ac-abc353_d Another Sigma Problem (tier 3, pattern contribution-total, set practice)
- Budget: N ≤ 2·10^5.
- Idea: f(A_i, A_j) = A_i·10^{len(A_j)} + A_j. A_j appears as the right part (j − 1) times; A_i is multiplied by Σ_{j > i} 10^{len(A_j)}, a suffix sum. All mod 998244353.
- Techniques: 2.4, 0.4
- Needs this topic because: splitting the double sum into per-element contributions.
- Tier reasoning: ABC D.

## ac-abc371_e I Hate Sigma Problems (tier 3, pattern contribution-total, set practice)
- Budget: N ≤ 2·10^5.
- Idea: Each distinct value in [l, r] is counted once, by its first occurrence in the range. Position i with previous equal at p contributes (i − p)·(N − i + 1). long long.
- Techniques: 2.4, 0.6
- Needs this topic because: counting, per element, the ranges where it is the representative.
- Tier reasoning: ABC E (difficulty about 980); tier 3 by judgement.

## ac-abc151_e Max-Min Sums (tier 4, pattern contribution-total, set reserved, for checkpoint)
- Budget: N ≤ 10^5.
- Idea: Sort. A_i (0-based) is the maximum of C(i, K − 1) chosen sets and the minimum of C(N − 1 − i, K − 1). Answer Σ A_i·(C(i, K−1) − C(N−1−i, K−1)) mod p (normalise negatives).
- Techniques: 2.4, 2.3, 1.1
- Needs this topic because: Σ f = Σ max − Σ min, each by contribution.
- Tier reasoning: ABC E, difficulty about 1340.

## lc-sum-of-subsequence-widths Sum of Subsequence Widths (tier 4, pattern contribution-total, set practice)
- Budget: n ≤ 10^5.
- Idea: Sort; nums[i] is the maximum of 2^i subsequences and the minimum of 2^{n−1−i}. Answer Σ nums[i]·(2^i − 2^{n−1−i}) mod p with precomputed powers.
- Techniques: 2.4, 2.2, 1.1
- Needs this topic because: contribution as max minus contribution as min.
- Tier reasoning: LeetCode Hard.

## ac-abc127_e Cell Distance (tier 5, pattern contribution-total, set practice)
- Budget: N·M ≤ 2·10^5.
- Idea: Each pair of cells contributes its Manhattan distance times C(NM − 2, K − 2). Σ over pairs of |x1 − x2| = M²·Σ_{d=1}^{N−1} d·(N − d), similarly for columns.
- Techniques: 2.4, 2.3
- Needs this topic because: summing over pairs instead of over placements.
- Tier reasoning: ABC E, difficulty about 1940.

## ac-abc150_e Change a Little Bit (tier 5, pattern contribution-total, set practice)
- Budget: N ≤ 2·10^5.
- Idea: For a fixed pair, fix positions in decreasing cost order (exchange argument), so with C sorted ascending, C_i is paid with multiplier 1 + (number of differing positions j < i). Over all differing sets containing i that totals 2^{N−1} + i·2^{N−2}, and S has 2^N choices. Answer Σ C_i·2^N·(2^{N−1} + i·2^{N−2}) mod 10^9 + 7 (for N = 1 the i·2^{N−2} term is 0).
- Techniques: 2.4, 2.2, 1.5, 1.1
- Needs this topic because: total over all pairs by each cost's contribution.
- Tier reasoning: ABC E, difficulty about 1850.

## ac-abc297_f Minimum Bounding Box 2 (tier 5, pattern contribution-total, set practice)
- Budget: H, W ≤ 1000, K ≤ HW.
- Idea: Expected area = Σ over rectangles of area × P(bounding box is exactly it). The count of K-subsets with bounding box exactly an h×w rectangle follows from inclusion–exclusion over removing each side (16 terms of C(cells, K)); multiply by the number of positions.
- Techniques: 2.4, 2.3, 2.2
- Needs this topic because: summing contributions of each possible box.
- Tier reasoning: ABC F, difficulty about 1990.

## cf-1009E Intercity Travelling (tier 5, pattern contribution-total, set practice) †
- Budget: n ≤ 10^6 (recalled).
- Idea: The distance cost a_i is paid at position j when the last rest before j is i positions back; summing over all 2^{n−1} rest patterns, a_i's multiplier is 2^{n−i} + (n − i)·2^{n−i−1} (for i < n), and 1 for i = n. Answer Σ a_i·multiplier mod 998244353.
- Techniques: 2.4, 2.2
- Needs this topic because: counting over all patterns by each term's contribution.
- Tier reasoning: rating 2000, Phase 2 tier 5.

## ac-abc326_e Revenge of "The Salary of AtCoder Inc." (tier 4, pattern indicator-linearity, set practice)
- Budget: N ≤ 3·10^5.
- Idea: E[salary] = Σ_y A_y·P(y is ever paid). The probability that y is paid is (1/N)·(1 + 1/N)^{y−1} (each smaller value either appears or not before y). Sum mod p with inverses.
- Techniques: 2.4, 2.2
- Needs this topic because: linearity of expectation over "y is paid" indicators.
- Tier reasoning: ABC E, difficulty about 1360.

## cf-235B Let's Play Osu! (tier 5, pattern indicator-linearity, set practice) †
- Budget: n ≤ 10^5 (recalled).
- Idea: Score = Σ (run length)² = Σ over clicks of (2·(length of run ending before it) + 1) for O clicks. By linearity: E = Σ p_i·(2·E[len_{i−1}] + 1), with E[len_i] = p_i·(E[len_{i−1}] + 1).
- Techniques: 2.4
- Needs this topic because: rewriting a square into a linear sum of indicators.
- Tier reasoning: rating 2000, Phase 2 tier 5.

## cf-453A Little Pony and Expected Maximum (tier 3, pattern tail-sum, set practice) †

## ac-abc411_e E [max] (tier 4, pattern tail-sum, set reserved, for checkpoint)
- Budget: N ≤ 10^5 dice with 6 faces.
- Idea: Sort all 6N face values. P(max ≤ x) = Π_i (c_i(x)/6), where c_i(x) counts die i's faces ≤ x; update it as x sweeps the sorted values, tracking how many dice still have c_i = 0. E = Σ x·(P(≤ x) − P(< x)), all mod p with inverses.
- Techniques: 2.4, 2.2, 1.1
- Needs this topic because: the maximum's distribution from a product of per-die probabilities.
- Tier reasoning: ABC E, difficulty about 1400.

## ac-abc295_e Kth Number (tier 5, pattern tail-sum, set practice)
- Budget: N, M ≤ 2000.
- Idea: E[A_K] = Σ_{x=1}^{M} P(A_K ≥ x). A_K ≥ x iff fewer than K elements are < x: with c fixed elements < x and z zeros each < x with probability (x − 1)/M, sum the binomial probabilities over how many zeros fall below.
- Techniques: 2.4, 2.3, 2.2
- Needs this topic because: tail sum with a binomial distribution per threshold.
- Tier reasoning: ABC E, difficulty above 2100.

## ac-abc360_e Random Swaps of Balls (tier 4, pattern indicator-linearity, set practice)
- Budget: N < p, K ≤ 10^5.
- Idea: Track q = P(black ball at position 1). One step: q' = q·(1 − 2(N−1)/N²) + (1 − q)·(2/N²), all as modular fractions. By symmetry the other positions are equally likely, so E[x] = q + (1 − q)·(N + 2)/2 mod p.
- Techniques: 2.4, 2.2
- Needs this topic because: the answer is an expected position, a sum of probabilities times positions (linearity); the probabilities are modular fractions from 2.2. Moved here from 2.2 in M4: 2.2 does not teach expectation.
- Tier reasoning: ABC E, difficulty about 1250.
