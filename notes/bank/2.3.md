## lc-kth-smallest-amount-with-single-denomination-combination Kth Smallest Amount With Single Denomination Combination (tier 4, pattern include-exclude, set practice)

## lc-find-nth-smallest-integer-with-k-one-bits Find Nth Smallest Integer With K One Bits (tier 4, pattern ncr-mod-p, set reserved, for review)
- Budget: answer < 2^50, so 50 bit positions and a table of binomial coefficients up to C(50, 25) ≈ 1.3·10^14, which fits in 64 bits.
- Idea: Build the answer from the highest bit down. With r ones still to place in the lower i bits, the numbers that keep this bit 0 number C(i, r). If n is larger than that count, put a 1 in this bit and subtract the count from n; otherwise leave it 0. This is the combinatorial number system.
- Techniques: 2.3, 1.7
- Needs this topic because: counting the numbers with exactly r ones among i bits as a binomial coefficient, then choosing bits greedily; listing the numbers is impossible for n up to 2^50.
- Tier reasoning: LeetCode Hard by label; the construction is short once the counts are binomials.
