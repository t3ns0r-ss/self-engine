## lc-repeated-dna-sequences Repeated DNA Sequences (tier 2, pattern distinct-by-hash, set reserved, for lookalike)
- Budget: length ≤ 10^5, fixed length 10.
- Idea: Encode each length-10 window in 20 bits (2 bits per letter) with a rolling update; count windows in a hash map and report those seen twice.
- Techniques: 6.1
- Needs this topic because: look-alike partner of Longest Duplicate Substring: the length is fixed, so a set of window codes suffices, with no search over lengths.
- Tier reasoning: LeetCode Medium.

## lc-longest-duplicate-substring Longest Duplicate Substring (tier 4, pattern hash-length-search, set reserved, for lookalike)
- Budget: length ≤ 3·10^4.
- Idea: If a duplicate of length L exists, one of length L − 1 does. Binary search L; check with rolling hashes of all windows in a hash set (two moduli or a 64-bit modulus).
- Techniques: 6.1, 1.4
- Needs this topic because: look-alike partner of Repeated DNA Sequences: the length is unknown, so binary search over lengths with hash checks.
- Tier reasoning: LeetCode Hard.

## lc-smallest-unique-subarray Smallest Unique Subarray (tier 4, pattern hash-length-search, set practice)
- Budget: n ≤ 10^5, values ≤ 10^5.
- Idea: If a window of length L occurs only once, every longer window containing it occurs only once (a second copy of the longer window would contain a second copy of the shorter one). So the property is monotone in L, and the whole array is always unique. Binary search the smallest L for which some window hash occurs exactly once (count hashes in a sorted array or a hash map).
- Techniques: 6.1, 1.4
- Needs this topic because: binary search over the length with window hashes; comparing windows directly is O(n) each.
- Tier reasoning: LeetCode Hard.

## lc-maximum-product-of-the-length-of-two-palindromic-substrings Maximum Product of the Length of Two Palindromic Substrings (tier 4, pattern palindrome-hash, set reserved, for review)
- Budget: length ≤ 10^5: O(n²) = 10^10 is too slow.
- Idea: For each centre c, binary search the largest radius r with s[c−r..c+r] a palindrome (forward hash equals reverse hash; a smaller radius also works, so the search is valid). A palindrome centred at c covers the ends c..c+r. For each end e, the longest palindrome ending at e comes from the smallest centre whose range covers e: assign ends to centres in increasing c with a 'next unassigned end' pointer structure (DSU). Prefix maxima give the best palindrome ending by e; the same on the reversed string gives the best starting after e; the answer is the best product over the split point. (Manacher's algorithm is the standard O(n) way to get the radii.)
- Techniques: 6.1, 4.4
- Needs this topic because: palindrome test in O(1) inside a search over the radius for every centre.
- Tier reasoning: LeetCode Hard.

## ac-abc343_g Compress Strings (tier 4, pattern substring-compare, set reserved, for review)
- Budget: N ≤ 20, total length ≤ 2·10^5.
- Idea: Delete every string that occurs inside another (slide a window hash of the right length over the longer string; remove duplicates once). For each ordered pair (i, j) find the longest overlap k with the suffix of S_i of length k equal to the prefix of S_j (compare hashes for every k up to the shorter length; total about 20 · Σ|S|). Then it is the shortest superstring: bitmask DP over the set of used strings and the last string, dp[mask][last] = longest total overlap saved.
- Techniques: 6.1, 3.7
- Needs this topic because: O(1) suffix-prefix and containment tests by hash; the overlaps are the only input to the mask DP.
- Tier reasoning: ABC G, difficulty 2114.

## ac-abc250_e Prefix Equality (tier 3, pattern distinct-by-hash, set reserved, for drill)
- Budget: N, Q ≤ 2·10^5.

## ac-abc158_e Divisible Substring (tier 3, pattern substring-compare, set reserved, for drill)
