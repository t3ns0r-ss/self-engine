# Bank notes: topic 2.2

Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## cses-1095 Exponentiation (tier 1, pattern fast-power, set practice)
- Budget: n ≤ 2·10^5 queries, b ≤ 10^9 → O(log b) each.
- Idea: Binary exponentiation: square the base and halve the exponent, multiplying into the result when the low bit is set; all mod 10^9 + 7 (0^0 = 1).
- Techniques: 2.2
- Needs this topic because: the basic fast power.
- Tier reasoning: first problem of CSES Mathematics.

## lc-powx-n Pow(x, n) (tier 2, pattern fast-power, set practice)
- Budget: |n| ≤ 2^31.
- Idea: Binary exponentiation on doubles; for negative n use 1/x and −n (as a 64-bit value to handle −2^31).
- Techniques: 2.2
- Needs this topic because: fast power with the sign edge case.
- Tier reasoning: LeetCode Medium.

## lc-count-good-numbers Count Good Numbers (tier 2, pattern fast-power, set practice)
- Budget: n ≤ 10^15.
- Idea: Even positions have 5 choices, odd positions 4: answer 5^{⌈n/2⌉}·4^{⌊n/2⌋} mod 10^9 + 7 by fast power.
- Techniques: 2.2
- Needs this topic because: huge exponents.
- Tier reasoning: LeetCode Medium.

## cf-1236B Alice and the List of Presents (tier 3, pattern fast-power, set practice) †
- Budget: n, m ≤ 10^9 (recalled).
- Idea: Each kind independently goes to any non-empty subset of the m boxes: (2^m − 1)^n mod 10^9 + 7, two fast powers.
- Techniques: 2.2
- Needs this topic because: exponents up to 10^9.
- Tier reasoning: rating 1500, Phase 2 tier 3.

## lc-minimum-non-zero-product-of-the-array-elements Minimum Non-Zero Product of the Array Elements (tier 4, pattern fast-power, set practice)
- Budget: p ≤ 60.
- Idea: Pair numbers into (1, 2^p − 2) as much as possible: the product is (2^p − 1)·(2^p − 2)^{2^{p−1} − 1} mod 10^9 + 7. Reduce 2^p − 2 mod p before the fast power; the exponent stays a 64-bit integer.
- Techniques: 2.2, 1.5
- Needs this topic because: an exponent near 2^59.
- Tier reasoning: LeetCode Medium with a pairing argument; counted as tier 4.

## ac-abc293_e Geometric Progression (tier 4, pattern fast-power, set practice)
- Budget: X ≤ 10^12, M ≤ 10^9 not necessarily prime (no inverse of A − 1).
- Idea: Divide and conquer: S(2k) = S(k)·(1 + A^k), S(k + 1) = 1 + A·S(k), with A^k by fast power (or track the pair (S(k), A^k) through the bits of X).
- Techniques: 2.2
- Needs this topic because: the repeated-squaring idea applied to a sum when division is unavailable.
- Tier reasoning: ABC E, difficulty about 1450.

## ac-abc162_e Sum of gcd of Tuples (Hard) (tier 4, pattern fast-power, set practice)
- Budget: N, K ≤ 10^5.
- Idea: f(d) = number of tuples with gcd exactly d = ⌊K/d⌋^N − Σ_{k≥2} f(kd), computed for d from K down. Answer Σ d·f(d) mod p. Each power by fast exponentiation.
- Techniques: 2.2, 2.1
- Needs this topic because: K fast powers with exponent N.
- Tier reasoning: ABC E, difficulty about 1660.

## cses-1712 Exponentiation II (tier 3, pattern exponent-reduction, set practice)
- Budget: n ≤ 10^5 queries.
- Idea: a^{b^c} mod p: reduce the exponent b^c mod (p − 1) (Fermat), computing it by fast power, then a^{that} mod p. a ≡ 0 is fine since b^c ≥ 1 unless b = 0, which the reduced exponent handles (0^0 = 1 only when b^c = 0).
- Techniques: 2.2
- Needs this topic because: Fermat's little theorem shrinks a tower exponent.
- Tier reasoning: CSES Mathematics.

## lc-super-pow Super Pow (tier 3, pattern exponent-reduction, set practice)
- Budget: exponent with up to 2000 digits, modulus 1337 (not prime).
- Idea: Process the digits: a^{10e + d} = (a^e)^{10}·a^d; keep the running result mod 1337 (Horner on the exponent with fast power at each step).
- Techniques: 2.2
- Needs this topic because: handling a huge exponent without a prime modulus.
- Tier reasoning: LeetCode Medium.

## cf-615D Multipliers (tier 5, pattern exponent-reduction, set practice) †
- Budget: m ≤ 2·10^5 primes (recalled).
- Idea: For n = Π p^{e}, the product of divisors is Π p^{e(e+1)/2 · D/(e+1)} where D is the number of divisors. Keep D mod (p − 1) as prefix and suffix products of (e + 1) over the other primes to avoid dividing; fast powers mod 10^9 + 7.
- Techniques: 2.2, 2.1
- Needs this topic because: exponents reduced mod p − 1.
- Tier reasoning: rating 2000, Phase 2 tier 5.

## cses-2182 Divisor Analysis (tier 4, pattern inverse-prime, set practice)
- Budget: k ≤ 10^5 prime powers, exponents ≤ 10^9.
- Idea: Count = Π (e + 1); sum = Π (p^{e+1} − 1)/(p − 1) with the division by the Fermat inverse; product = Π p^{e(e+1)/2 · (count of the others)} with exponents mod p − 1 (keep the divisor count mod p − 1 incrementally).
- Techniques: 2.2, 2.1
- Needs this topic because: inverses and exponent reduction together.
- Tier reasoning: CSES Mathematics, lower solve count.

## ac-abc298_d Writing a Numeral (tier 3, pattern inverse-prime, set practice)
- Budget: Q ≤ 6·10^5.
- Idea: Keep the digits in a queue and the value v mod p. Append x: v = 10v + x. Delete the front digit d when the length is L: v −= d·10^{L−1}; keep pow10 of the current length updated (multiply by 10 on append, by the inverse of 10 on delete).
- Techniques: 2.2, 0.6
- Needs this topic because: removing the leading digit needs 10^{L−1} mod p, maintained with the inverse of 10.
- Tier reasoning: ABC D.

## ac-abc152_e Flatten (tier 4, pattern inverse-prime, set practice)
- Budget: N ≤ 10^4, A_i ≤ 10^6.
- Idea: The common value is L = lcm(A). Factorise every A_i (SPF) and keep the maximum exponent per prime; L mod p from those exponents. Answer Σ L·inv(A_i) mod p.
- Techniques: 2.2, 2.1
- Needs this topic because: L is astronomically large, so each L / A_i becomes L·A_i^{−1} mod p.
- Tier reasoning: ABC E, difficulty about 1350.

## cf-1279D Santa's Bot (tier 4, pattern fraction-output, set practice) †
- Budget: n kids, total items ≤ 10^6 (recalled).
- Idea: P(valid) = Σ over kids x, items y in x's list of (1/n)·(1/k_x)·(cnt[y]/n). Accumulate modulo 998244353 with modular inverses of n and k_x.
- Techniques: 2.2, 0.6
- Needs this topic because: probabilities output as P·Q^{−1} mod p.
- Tier reasoning: rating 1700, Phase 2 tier 4 (boundary, higher tier).

## ac-abc357_d 88888888 (tier 3, pattern inverse-prime, set reserved, for checkpoint)
- Budget: N ≤ 10^18.
- Idea: With d digits in N, V_N = (N mod p)·(1 + 10^d + 10^{2d} + … + 10^{(N−1)d}) = (N mod p)·(10^{dN} − 1)/(10^d − 1). Compute with fast power and the Fermat inverse of 10^d − 1 (non-zero mod p).
- Techniques: 2.2, 0.4
- Needs this topic because: a geometric series divided by a modular inverse.
- Tier reasoning: ABC D.

## ac-abc228_e Integer Sequence Fair (tier 4, pattern exponent-reduction, set reserved, for checkpoint)
- Budget: N, K, M ≤ 10^18.
- Idea: Answer M^{K^N} mod p with p = 998244353. If M mod p = 0, answer 0. Otherwise reduce the exponent: e = K^N mod (p − 1) (fast power), answer M^e mod p.
- Techniques: 2.2
- Needs this topic because: exponent reduction, with the zero-base exception.
- Tier reasoning: ABC E, difficulty about 1580.
