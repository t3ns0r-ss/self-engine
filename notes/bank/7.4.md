## cf-1526C2 Potions (Hard Version) (tier 1, pattern deadline-heap, set practice) †
- Budget: n ≤ 2·10^5 (recalled).
- Idea: (recalled) Drink potions left to right, pushing each into a min-heap; when health goes negative, undo the most negative potion taken. The heap size is the answer.
- Techniques: 7.4, 0.6
- Needs this topic because: fix infeasibility by dropping the worst chosen item.
- Tier reasoning: rating 1600.

## lc-furthest-building-you-can-reach Furthest Building You Can Reach (tier 3, pattern deadline-heap, set practice)
- Budget: n ≤ 10^5.
- Idea: Keep the climbs covered by ladders in a min-heap of size ≤ ladders; when it overflows, pay the smallest climb with bricks. Stop when bricks go negative.
- Techniques: 7.4, 0.6
- Needs this topic because: assign the expensive tool to the largest items seen so far.
- Tier reasoning: LeetCode Medium.

## cf-1271D Portals (tier 3, pattern deadline-heap, set practice) †
- Budget: n, m ≤ 5000 (recalled).
- Idea: (recalled) Defend each castle from the latest castle that can reach it (portals or itself). Greedily defend everything, then, scanning castles, when warriors are insufficient remove the cheapest defended castle among those whose latest point has passed (min-heap); −1 if impossible.
- Techniques: 7.4, 1.1
- Needs this topic because: tentative choices undone with a min-heap.
- Tier reasoning: rating 2100.

## ac-abc407_e Most Valuable Parentheses (tier 4, pattern deadline-heap, set practice)
- Budget: Σ N ≤ 2·10^5.
- Idea: A valid sequence needs at least k '(' among the first 2k − 1 positions. Scan positions, pushing values into a max-heap; at each odd position pop the largest to be '('. Sum the popped values.
- Techniques: 7.4, 0.6
- Needs this topic because: prefix-feasibility constraints satisfied by greedy picks from a heap.
- Tier reasoning: ABC E.

## ac-abc249_f Ignore Operations (tier 5, pattern deadline-heap, set practice)
- Budget: N ≤ 2·10^5, K ≤ N.
- Idea: Scan from the end. A type-1 operation at position i fixes y; everything later must ignore the type-1s after it. Keep the sum of later type-2 values; ignore the most negative ones with a bounded max-heap (size = remaining skips). Candidate = y + kept sum.
- Techniques: 7.4, 0.6
- Needs this topic because: keep the K worst items out with a bounded heap.
- Tier reasoning: ABC F.

## cf-865D Buy Low Sell High (tier 3, pattern regret, set practice) †
- Budget: n ≤ 3·10^5 (recalled).
- Idea: (recalled) Min-heap of prices. For price p, if the minimum m < p, gain p − m, pop m and push p twice (one copy lets a later sale replace this one: buying at m and selling later instead). Otherwise push p.
- Techniques: 7.4, 0.6
- Needs this topic because: the regret trick of reinserting to allow undoing a choice.
- Tier reasoning: rating 2400.

## lc-minimum-number-of-refueling-stops Minimum Number of Refueling Stops (tier 4, pattern regret, set practice)
- Budget: ≤ 500 stations.
- Idea: Drive while possible, pushing passed stations' fuel into a max-heap. When stuck, retroactively refuel at the best passed station (pop max, count++). −1 if the heap is empty.
- Techniques: 7.4, 0.6
- Needs this topic because: decide past choices only when needed.
- Tier reasoning: LeetCode Hard.

## cf-3D Least Cost Bracket Sequence (tier 4, pattern regret, set practice) †
- Budget: length ≤ 5·10^4 (recalled).
- Idea: (recalled) Start by making every '?' a ')'. Scan; push (a_i − b_i, i) for each '?'; when the balance becomes negative, flip the '?' with the smallest a − b to '(' (balance += 2). If impossible, −1.
- Techniques: 7.4, 0.6
- Needs this topic because: change earlier choices at minimal extra cost when forced.
- Tier reasoning: rating 2600.
