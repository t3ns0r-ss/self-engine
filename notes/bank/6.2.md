## lc-find-the-index-of-the-first-occurrence-in-a-string Find the Index of the First Occurrence in a String (tier 1, pattern pattern-occurrences, set practice)
- Budget: lengths ≤ 10^4.
- Idea: Prefix function of needle + '#' + haystack; the first position where it equals |needle| ends the first match. (Brute force also passes here.)
- Techniques: 6.2
- Needs this topic because: the KMP matching template.
- Tier reasoning: LeetCode Easy.

- Idea: goal is a rotation of s iff lengths match and goal occurs in s + s (KMP or any search).
- Techniques: 6.2
- Needs this topic because: rotations as substrings of the doubled string.
- Tier reasoning: LeetCode Easy.

## lc-find-beautiful-indices-in-the-given-array-i Find Beautiful Indices in the Given Array I (tier 2, pattern pattern-occurrences, set reserved, for lookalike)
- Budget: |s| ≤ 10^5, |a|, |b| ≤ 10.
- Idea: Patterns are at most 10 long, so find occurrences of a and b by direct comparison; then two pointers (or binary search) over the sorted occurrence lists for |i − j| ≤ k.
- Techniques: 6.2, 1.3
- Needs this topic because: look-alike partner of version II: short patterns allow direct matching.
- Tier reasoning: LeetCode Medium.

## lc-find-beautiful-indices-in-the-given-array-ii Find Beautiful Indices in the Given Array II (tier 4, pattern pattern-occurrences, set reserved, for lookalike)
- Budget: |s|, |a|, |b| ≤ 5·10^5.
- Idea: Find all occurrences of a and of b with KMP (or Z); then for each occurrence i of a, check with a pointer or binary search for an occurrence j of b with |i − j| ≤ k.
- Techniques: 6.2, 1.3
- Needs this topic because: look-alike partner of version I: long patterns need a linear matcher.
- Tier reasoning: LeetCode Hard.

## lc-shortest-matching-substring Shortest Matching Substring (tier 4, pattern pattern-occurrences, set practice)
- Budget: |s|, |p| ≤ 10^5, p has exactly two '*'.
- Idea: Split p into three parts A, B, C. Find all occurrences of each with KMP. For each occurrence of B, take the nearest A ending before it and the nearest C starting after it (binary search); minimise the total span. Empty parts match everywhere.
- Techniques: 6.2, 1.4
- Needs this topic because: several occurrence lists combined.
- Tier reasoning: LeetCode Hard.

## cf-25E Test (tier 4, pattern pattern-occurrences, set practice) †
- Budget: lengths ≤ 10^5 (recalled).
- Idea: (recalled) Try all 6 orders of the three strings. Merge greedily: if one string already contains the next, skip it; otherwise append it after the longest overlap (prefix function of next + '#' + current). Take the shortest result.
- Techniques: 6.2, 0.5
- Needs this topic because: containment and overlap both from the prefix function.
- Tier reasoning: rating 2200.

## ac-abc150_f Xor Shift (tier 5, pattern pattern-occurrences, set practice)
- Budget: N ≤ 2·10^5.
- Idea: XOR with x cancels in differences: let a'_i = a_i XOR a_{i+1} (cyclic) and b'_i similarly. Shift k works iff b' occurs in a' + a' at k. Find matches with KMP; x = a_k XOR b_0.
- Techniques: 6.2, 1.7
- Needs this topic because: matching on a derived sequence that removes the unknown.
- Tier reasoning: ABC F.

## ac-abc135_f Strings of Eternity (tier 5, pattern pattern-occurrences, set practice)
- Budget: |s|, |t| ≤ 5·10^5.
- Idea: Repeat s until it is at least |t| + |s| long; mark positions i (mod |s|) where t occurs (KMP). Edges i → (i + |t|) mod |s| form a functional graph; a cycle means −1, otherwise the answer is the longest path.
- Techniques: 6.2, 4.2
- Needs this topic because: occurrence positions turned into a graph.
- Tier reasoning: ABC F.

## cses-1112 Required Substring (tier 4, pattern pattern-occurrences, set reserved, for review)
- Budget: n ≤ 1000, m ≤ 100.
- Idea: Count strings that avoid the pattern with a DP over the KMP automaton state (0..m − 1): next[state][letter] from the prefix function. Answer = 26^n − avoiding count, mod 10^9+7.
- Techniques: 6.2, 3.2
- Needs this topic because: the prefix function builds a matching automaton for a DP.
- Tier reasoning: CSES string section.

## cf-1721E Prefix Function Queries (tier 4, pattern pattern-occurrences, set reserved, for exam) †
- Budget: |s| ≤ 10^6, queries with |t| ≤ 10 (recalled).
- Idea: (recalled) Precompute the KMP automaton aut[i][c] for prefixes of s. For each query, extend from s's last prefix value using the automaton for the first |s| states and plain prefix-function steps for the new ones; only 10 new positions per query.
- Techniques: 6.2
- Needs this topic because: the automaton avoids repeated fallback chains.
- Tier reasoning: rating 2200.

## cf-808G Anthem of Berland (tier 4, pattern pattern-occurrences, set practice) †
- Budget: |s| · |t| ≤ 10^7 (recalled).
- Idea: (recalled) DP over positions of s with the KMP automaton state of t: dp[i][j] = max occurrences so far; '?' tries all 26 letters; reaching state |t| adds 1 and falls back to π(|t|).
- Techniques: 6.2, 3.2
- Needs this topic because: DP over prefix-function states.
- Tier reasoning: rating 2300.

## lc-repeated-substring-pattern Repeated Substring Pattern (tier 1, pattern period-border, set practice)
- Budget: length ≤ 10^4.
- Idea: Let p = n − π(n − 1). The string is a repetition iff π(n − 1) > 0 and n is divisible by p.
- Techniques: 6.2
- Needs this topic because: the smallest period from the last prefix-function value.
- Tier reasoning: LeetCode Easy.

## cf-535D Tavas and Malekas (tier 3, pattern z-compare, set practice) †
- Budget: n ≤ 10^6 (recalled).
- Idea: (recalled) Consecutive occurrences y_i < y_{i+1} overlapping by d = |p| − (y_{i+1} − y_i) > 0 are consistent iff Z_p[y_{i+1} − y_i] ≥ d. If all are, the answer is 26^(free positions) mod 10^9+7; otherwise 0.
- Techniques: 6.2, 2.2
- Needs this topic because: overlap consistency via the Z-array.
- Tier reasoning: rating 1900.

## cf-1968G2 Division + LCP (hard version) (tier 4, pattern z-compare, set practice) †
- Budget: Σ n ≤ 2·10^5 (recalled).
- Idea: (recalled) For a fixed LCP length L, the number of pieces f(L) is the greedy count of non-overlapping positions with Z ≥ L (at most n/L of them, found by jumping). For each k, the answer is the largest L with f(L) ≥ k; total work is a harmonic sum over L.
- Techniques: 6.2, 1.4
- Needs this topic because: Z-array reused for every length.
- Tier reasoning: rating 2200.
