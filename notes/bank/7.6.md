## lc-fibonacci-number Fibonacci Number (tier 2, pattern linear-recurrence, set reserved, for lookalike)
- Budget: n ≤ 30.
- Idea: Iterate F(i) = F(i − 1) + F(i − 2) with two variables.
- Techniques: 3.2
- Needs this topic because: look-alike partner of CSES Fibonacci Numbers: n ≤ 30, so a plain loop suffices.
- Tier reasoning: LeetCode Easy.

## cses-1722 Fibonacci Numbers (tier 2, pattern linear-recurrence, set reserved, for lookalike)
- Budget: n ≤ 10^18.
- Idea: [[1, 1], [1, 0]]^n gives F(n) in its off-diagonal entry; fast matrix power mod 10^9+7.
- Techniques: 7.6, 2.2
- Needs this topic because: look-alike partner of LeetCode Fibonacci Number: n up to 10^18 needs O(log n) matrix powers.
- Tier reasoning: CSES mathematics section.

## lc-total-characters-in-string-after-transformations-i Total Characters in String After Transformations I (tier 2, pattern linear-recurrence, set reserved, for lookalike)
- Budget: |s| ≤ 10^5, t ≤ 10^5.
- Idea: Keep counts of the 26 letters and simulate t steps ('z' becomes "ab"), O(26·t). Sum mod 10^9+7.
- Techniques: 3.2
- Needs this topic because: look-alike partner of version II: t ≤ 10^5, so step-by-step simulation of counts is fast enough.
- Tier reasoning: LeetCode Medium.

## lc-total-characters-in-string-after-transformations-ii Total Characters in String After Transformations II (tier 4, pattern linear-recurrence, set reserved, for lookalike)
- Budget: |s| ≤ 10^5, t ≤ 10^9.
- Idea: One step is a fixed 26×26 linear map on letter counts (letter i contributes to the next nums[i] letters cyclically). Raise it to the t-th power and apply to the initial counts.
- Techniques: 7.6, 2.2
- Needs this topic because: look-alike partner of version I: t up to 10^9 requires a matrix power.
- Tier reasoning: LeetCode Hard.

## lc-n-th-tribonacci-number N-th Tribonacci Number (tier 1, pattern linear-recurrence, set practice)
- Budget: n ≤ 37.

- Tier reasoning: LeetCode Easy.

## cf-551D GukiZ and Binary Operations (tier 3, pattern linear-recurrence, set practice) †
- Budget: n ≤ 10^18, k < 2^63, l ≤ 64 (recalled).
- Idea: (recalled) Bits are independent. For a bit that must be 0, arrays with no two adjacent ones: F(n + 2) (Fibonacci via matrix); for a bit that must be 1, 2^n − F(n + 2). Multiply over l bits mod m; 0 if k has bits ≥ l.
- Techniques: 7.6, 1.7
- Needs this topic because: Fibonacci counts at huge n inside a product.
- Tier reasoning: rating 2100.

## lc-number-of-ways-to-paint-n-3-grid Number of Ways to Paint N × 3 Grid (tier 3, pattern linear-recurrence, set reserved, for drill)
- Budget: n ≤ 5000.
- Idea: Rows are type ABA (6 ways) or ABC (6 ways). Next row counts: aba' = 3·aba + 2·abc, abc' = 2·aba + 2·abc. Iterate (or power the 2×2 matrix).
- Techniques: 7.6, 3.5
- Needs this topic because: a two-state linear transition.
- Tier reasoning: LeetCode Hard.

## lc-string-transformation String Transformation (tier 4, pattern linear-recurrence, set practice)
- Budget: n ≤ 5·10^5, k ≤ 10^15.
- Idea: Each operation is a rotation by a non-zero amount. Count rotations of s equal to t (KMP on s + s). Ways to be at total rotation 0 / non-zero after k steps follow a 2-state linear recurrence; combine with the counts. mod 10^9+7.
- Techniques: 7.6, 6.2
- Needs this topic because: a 2×2 recurrence raised to a huge power.
- Tier reasoning: LeetCode Hard.
