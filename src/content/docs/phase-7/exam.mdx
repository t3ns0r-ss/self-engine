This exam is deliberately mixed. The problems below come from all seven tools of Phase 7 and from one earlier phase, in an order that has nothing to do with the course, and nothing on the page names their topic until you have finished. Some are plain applications of one tool. Some need two ideas at once: a DP together with a range structure, or a recurrence together with a counting argument. The question is the one the whole phase trains: **what is the structure of this problem, and which tool, or which two tools together, makes it cheap?**

**How to take it.**

1. Set aside 4 hours without interruptions. The timer keeps running if you reload the page.
2. Read every problem first, then solve them in the order you prefer. Use only what you would use in a contest: your own code and the C++ reference.
3. For each problem, write the three lines of the routine (budget, candidate tools, property checked) before you start coding, and note the first tool you tried. If it was the wrong one, that is a *Recognition miss*, even if you later solved the problem.
4. When the time is up (or you are done), mark what you solved within the time and where you had a Recognition miss.

**Pass rule.** At least 60% of the problems solved in time (5 of 8), and no Recognition miss on a solved problem. If you do not pass, the remediation map lists the topic, card and lesson section behind each problem: reread those, upsolve the problems, and sit the exam again after a few days.
