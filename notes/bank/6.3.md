## lc-implement-trie-prefix-tree Implement Trie (Prefix Tree) (tier 2, pattern prefix-tree, set reserved, for drill)
- Budget: lengths ≤ 2000, ≤ 3·10^4 calls.
- Idea: Nodes with 26 children and an end flag. insert walks and creates; search needs the end flag; startsWith only needs the path.
- Techniques: 6.3
- Needs this topic because: the trie template.
- Tier reasoning: LeetCode Medium, very standard.

## lc-replace-words Replace Words (tier 2, pattern prefix-tree, set reserved, for later_drill)
- Budget: dictionary ≤ 1000 roots, sentence ≤ 10^6 characters.
- Idea: Insert roots into a trie; for each word walk the trie and stop at the first end flag (shortest root); replace if found.
- Techniques: 6.3
- Needs this topic because: shortest dictionary prefix by one trie walk.
- Tier reasoning: LeetCode Medium.

## lc-longest-word-in-dictionary Longest Word in Dictionary (tier 2, pattern prefix-tree, set reserved, for later_drill)
- Budget: ≤ 1000 words of length ≤ 30.
- Idea: Insert all words; DFS from the root moving only into children that end a word; the deepest reached (lexicographically smallest on ties) is the answer.
- Techniques: 6.3
- Needs this topic because: traversing a trie by end flags.
- Tier reasoning: LeetCode Medium.

## lc-map-sum-pairs Map Sum Pairs (tier 2, pattern prefix-tree, set reserved, for drill)
- Budget: keys ≤ 50 characters, ≤ 50 calls.
- Idea: Each trie node stores the sum of values below it. On insert, add (new − old value of the key, from a map) along the path; sum(prefix) reads the node.
- Techniques: 6.3, 0.6
- Needs this topic because: aggregates stored on trie nodes.
- Tier reasoning: LeetCode Medium.

## cf-1792D Fixed Prefix Permutations (tier 2, pattern prefix-tree, set practice) †
- Budget: Σ n·m ≤ 2·10^5, m ≤ 10 (recalled).
- Idea: (recalled) Beauty of a_i · a_j = longest k with a_j[a_i[t]] = t for t ≤ k, i.e. a_j's inverse has a_i as prefix. Insert the inverse of every permutation into a trie and walk each a_i.
- Techniques: 6.3
- Needs this topic because: rewrite the condition as a common prefix.
- Tier reasoning: rating 1700.

## cf-1902E Collapsing Strings (tier 3, pattern prefix-tree, set practice) †
- Budget: Σ |s_i| ≤ 10^6 (recalled).
- Idea: (recalled) |C(a, b)| = |a| + |b| − 2·LCP(reverse a, b). Sum all |a| + |b| terms directly; subtract 2·Σ LCPs: insert all strings into a trie with pass counts, and for each reversed string add the pass counts along its walk. 64-bit.
- Techniques: 6.3
- Needs this topic because: sum of LCPs via pass counts.
- Tier reasoning: rating 1900.

## lc-count-prefix-and-suffix-pairs-ii Count Prefix and Suffix Pairs II (tier 4, pattern prefix-tree, set practice)
- Budget: n ≤ 10^5, Σ lengths ≤ 5·10^5.
- Idea: words[i] is both prefix and suffix of words[j] iff it is a prefix of the pair sequence ((s[0], s[n−1]), (s[1], s[n−2]), …). Trie over character pairs (map children) with end counts; for each j, sum end counts along its walk, then insert it.

## lc-palindrome-pairs Palindrome Pairs (tier 5, pattern prefix-tree, set practice)
- Budget: ≤ 5000 words of length ≤ 300.
- Idea: Insert reversed words into a trie, marking at each node the words whose remaining part (below the node) is a palindrome. For each word, walk it: at end nodes check that the rest of the word is a palindrome; at the walk's end add the marked list.
- Techniques: 6.3, 6.1
- Needs this topic because: trie of reversed words with palindrome bookkeeping.
- Tier reasoning: LeetCode Hard with several cases; tier 5.

## cses-1731 Word Combinations (tier 3, pattern dictionary-split, set practice)
- Budget: n ≤ 5000, k ≤ 10^5 words, total length ≤ 10^6.
- Idea: dp[i] = ways to split s[i..]. From each i walk the trie along s; at each word end j add dp[j + 1]. mod 10^9+7.
- Techniques: 6.3, 3.2
- Needs this topic because: one trie walk lists all words starting at a position.
- Tier reasoning: CSES string section.
