## cf-1984D "a" String Problem (tier 3, pattern z-compare, set reserved, for checkpoint) †
- Budget: |s| ≤ 2·10^5 per test, total ≤ 3·10^5 (recalled).
- Idea: (recalled) Count strings t ≠ "a" such that s can be cut into pieces each equal to t or to "a", with at least one piece equal to t. If s is all a's, the answer is |s| − 1. ## cf-494B Obsessive String (tier 3, pattern pattern-occurrences, set reserved, for review) †
- Budget: |s|, |t| ≤ 10^5 (recalled).
- Idea: (recalled) Count the ways to choose k ≥ 1 non-overlapping substrings of s, in order, each containing t. Find all occurrences of t by the prefix function. Let f[i] = the number of ways where the last chosen substring ends at i; a last substring [l..i] contains t exactly when l ≤ the start of the latest occurrence ending at or before i. Then f[i] is a sum of f over earlier ends plus a count of left ends, found with prefix sums of f and of prefix sums. The answer is the sum of all f[i]. O(|s| + |t|).
- Techniques: 6.2, 3.2
- Needs this topic because: occurrences of t in s in linear time, then a prefix-sum DP.
- Tier reasoning: rating 2000.

## cf-1120C Compress String (tier 3, pattern z-compare, set reserved, for review) †
- Budget: |s| ≤ 5000 (recalled).
- Idea: (recalled) Build the string left to right: appending one letter costs a, appending a substring that already occurs in the part built so far costs b. dp[i] = min(dp[i − 1] + a, dp[j] + b for the j < i with s[j..i) occurring inside s[0..j)). If a block of length L occurs earlier then so do all its shorter prefixes, so for each j only the longest such length matters: it is the largest value of min(z[k], j − k') over the Z-function of s[j..], computed for each j in O(n). O(n²) in all.
- Techniques: 6.2, 3.2
- Needs this topic because: the longest prefix of each suffix that occurs inside the part before it: the Z-function of each suffix.
- Tier reasoning: rating 2100.

## cf-825F String Compression (tier 4, pattern period-border, set reserved, for review) †
- Budget: |s| ≤ 8000 (recalled).
- Idea: (recalled) Write the string as a concatenation of pieces, each a block repeated c times and written as the number c followed by the block; minimise the total length. For each start i compute the prefix function of s[i..]. - Techniques: 6.2, 3.2
