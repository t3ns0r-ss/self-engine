## cses-1730 Nim Game I (tier 2, pattern nim-sum, set reserved, for lookalike)
- Budget: Σ n ≤ 2·10^5 heaps.
- Idea: Plain Nim: the first player wins iff the XOR of all heap sizes is non-zero.
- Techniques: 7.5, 1.7
- Needs this topic because: look-alike partner of Nim Game II: any number of sticks may be taken, so the Grundy value of a heap is its size.
- Tier reasoning: first CSES game problem.

## cses-1098 Nim Game II (tier 2, pattern grundy-pattern, set reserved, for lookalike)
- Budget: Σ n ≤ 2·10^5 heaps.
- Idea: With moves of 1, 2 or 3 sticks, the Grundy value of a heap of size x is x mod 4. The first player wins iff the XOR of (x mod 4) is non-zero.
- Techniques: 7.5, 1.7
- Needs this topic because: look-alike partner of Nim Game I: restricted moves change each heap's Grundy value, so XOR the pattern values, not the sizes.
- Tier reasoning: CSES mathematics section.

## cf-603C Lieges of Legendre (tier 3, pattern grundy-pattern, set reserved, for review) †
- Budget: n up to 10^5 piles, sizes and k up to 10^9 (recalled).
- Idea: (recalled) A move removes one cow from a pile, or, if the pile has an even size 2x, replaces it by k piles of x cows; the last mover wins. Grundy values from brute force: for even k, g(1) = 1, g(2) = 2, odd n ≥ 3 give 0 and even n ≥ 4 give 1; for odd k, odd n ≥ 5 give 0 and the even n are found by g(n) = mex{g(n − 1), g(n / 2)} (depth log n). - Techniques: 7.5, 1.7

- Tier reasoning: rating 2200.

## cf-850C Arpa and a game with Mojtaba (tier 3, pattern grundy-sum, set reserved, for review) †
- Budget: n up to 100, numbers up to 10^9 (recalled).
- Idea: (recalled) A move picks a prime power p^k and divides every number divisible by p^k by p^k. For each prime p the game is independent: the state is the set (bitmask) of exponents of p that are still present, and a move with k clears or shifts the exponents ≥ k; compute its Grundy value by memoised search over the masks (exponents up to 30). The first player wins iff the XOR over the primes is non-zero.
- Techniques: 7.5, 2.1
- Needs this topic because: independent games, one for each prime, with Grundy values taken over bitmasks of exponents.
- Tier reasoning: rating 2200.

## cf-1383B GameGame (tier 2, pattern nim-sum, set practice) †

## cf-78C Beaver Game (tier 3, pattern grundy-sum, set reserved, for review) †
- Budget: n up to 10^9 logs, length m up to 10^9, k up to m (recalled).
- Idea: (recalled) n logs of the same length m; a move cuts a log into t ≥ 2 equal parts of integer length at least k; the player who cannot move loses. If n is even the second player copies; if n is odd the first player wins exactly when the game with one log is a win. One log of length m is a win if some divisor split gives a losing position: t even gives xor 0 (losing for the next), t odd needs the parts of length m / t to be a losing log. Recursion over divisors up to sqrt(m).
- Techniques: 7.5, 2.1
- Needs this topic because: independent equal games: only the parity of n and one game matter.
- Tier reasoning: rating 2000.

## cf-731E Funny Game (tier 3, pattern win-lose, set reserved, for review) †
- Budget: n up to 200000 (recalled).
- Idea: (recalled) A move takes the k ≥ 2 leftmost numbers, replaces them by their sum and scores the sum; the game ends with one number; the score difference of the first player minus the second under optimal play. With prefix sums, dp[i] = the best difference when the leftmost i numbers are merged: dp[i] = max(dp[i + 1], prefix[i] − dp[i + 1]) from the right; the answer is dp[2].
- Techniques: 7.5, 3.2, 1.2

- Tier reasoning: rating 2200.
