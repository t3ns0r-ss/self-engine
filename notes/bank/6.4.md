## cses-2105 Distinct Substrings (tier 3, pattern distinct-substrings, set practice)
- Budget: n ≤ 10^5.
- Idea: Build the suffix array and Kasai's LCP array. Distinct substrings = n(n + 1)/2 − Σ LCP (64-bit).
- Techniques: 6.4
- Needs this topic because: each suffix adds the prefixes not shared with its predecessor.
- Tier reasoning: CSES string section.

## cses-2108 Substring Order I (tier 4, pattern distinct-substrings, set practice)
- Budget: n ≤ 10^5, k ≤ n(n + 1)/2.
- Idea: In suffix-array order, suffix sa[i] contributes the new substrings of lengths lcp[i] + 1 .. n − sa[i], in increasing order. Walk until the running count reaches k and print the right prefix.
- Techniques: 6.4
- Needs this topic because: the sorted order of distinct substrings comes from SA + LCP.
- Tier reasoning: CSES string section, later.

## cses-2110 Substring Distribution (tier 4, pattern distinct-substrings, set practice)
- Budget: n ≤ 10^5.
- Idea: Suffix sa[i] contributes one new distinct substring of each length in [lcp[i] + 1, n − sa[i]]; add 1 on that range with a difference array, then prefix-sum.
- Techniques: 6.4, 1.2
- Needs this topic because: distinct substrings grouped by length.
- Tier reasoning: CSES string section, later.

## cf-123D String (tier 4, pattern distinct-substrings, set practice) †
- Budget: |s| ≤ 10^5 (recalled).
- Idea: (recalled) Sum over distinct substrings of occ·(occ + 1)/2. A substring's occurrences are a maximal run of suffixes with LCP ≥ its length; process the LCP array as a histogram with a monotonic stack (or DSU in decreasing LCP order), adding contributions per height range. 64-bit.
- Techniques: 6.4, 1.6
- Needs this topic because: occurrence counts of all substrings from the LCP array.
- Tier reasoning: rating 2300.

## cf-873F Forbidden Indices (tier 5, pattern distinct-substrings, set practice) †
- Budget: n ≤ 2·10^5 (recalled).
- Idea: (recalled) Reverse the string so "ends at an allowed index" becomes "starts at an allowed index". Over the suffix array, merge adjacent suffixes in decreasing LCP order with DSU, tracking allowed-start counts; maximise length · count (and single suffixes with full length).
- Techniques: 6.4, 4.4
- Needs this topic because: substring frequencies via LCP merging.
- Tier reasoning: rating 2400.

## cses-2102 Finding Patterns (tier 3, pattern occurrences-by-order, set practice)

- Idea: Suffixes starting with the pattern are consecutive in the suffix array; binary search for the first such suffix, comparing the pattern with the suffix directly (O(m log n)).
- Techniques: 6.4, 1.4

## lc-last-substring-in-lexicographical-order Last Substring in Lexicographical Order (tier 4, pattern sorted-suffixes, set practice)
- Budget: length ≤ 4·10^5.
- Idea: The answer is the largest suffix. Build the suffix array and print the last one; or use the two-candidate linear scan (i, j, k) that skips compared blocks.
- Techniques: 6.4
- Needs this topic because: the largest substring is a suffix, compared by suffix order.
- Tier reasoning: LeetCode Hard.

## cses-3225 Inverse Suffix Array (tier 4, pattern sorted-suffixes, set practice)
- Budget: n ≤ 10^5.
- Idea: Let rank be the inverse permutation. Walking the given order, s[sa[i]] = s[sa[i − 1]] is allowed iff rank[sa[i − 1] + 1] < rank[sa[i] + 1] (treating the end as smallest); otherwise move to the next letter. Fail if more than 26 letters are needed.
- Techniques: 6.4
- Needs this topic because: what ordering suffixes implies about adjacent characters.
- Tier reasoning: CSES string section, later.

## cses-1113 String Transform (tier 4, pattern sorted-suffixes, set practice)
- Budget: n ≤ 10^6.
- Idea: Inverse Burrows–Wheeler: stably sorting the last column gives the first column; the k-th occurrence of a letter in both columns is the same character. Follow this mapping from '#' to rebuild the string.
- Techniques: 6.4, 1.1
- Needs this topic because: the transform is defined by sorted rotations (sorted suffixes with '#').
- Tier reasoning: CSES string section.

## ac-abc272_f Two Strings (tier 5, pattern sorted-suffixes, set practice)
- Budget: N ≤ 2·10^5.
- Idea: Rotations of S and T are length-N windows of S + S and T + T. Build the suffix array of S + S + '$' + T + T + '~'-style separators so rotation comparisons follow suffix order; count pairs (i, j) with S's rotation ≤ T's rotation by a sweep in SA order (64-bit).
- Techniques: 6.4
- Needs this topic because: compare rotations through one suffix array.
- Tier reasoning: ABC F.

## cf-427D Match & Catch (tier 4, pattern common-substring, set practice) †
- Budget: |s1|, |s2| ≤ 5000 (recalled).
- Idea: (recalled) Suffix array of s1 + '#' + s2. For adjacent suffixes from different strings with lcp[i] > max(lcp[i − 1], lcp[i + 1]), a substring of length max(lcp[i − 1], lcp[i + 1]) + 1 occurs exactly once in each; take the minimum, or −1.
- Techniques: 6.4
- Needs this topic because: uniqueness read from neighbouring LCP values.
- Tier reasoning: rating 2200.

## ac-abc213_f Common Prefixes (tier 5, pattern common-substring, set practice)
- Budget: N ≤ 10^6.
- Idea: For each i, Σ_j LCP(suffix i, suffix j) = sum over SA neighbours of running minima of LCP. Compute left-to-right and right-to-left sums with a monotonic stack, then add N − i for j = i. 64-bit.
- Techniques: 6.4, 1.6
- Needs this topic because: LCP of any two suffixes = minimum of adjacent LCPs between them.
- Tier reasoning: ABC F.
