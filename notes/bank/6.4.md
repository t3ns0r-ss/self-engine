## cses-2105 Distinct Substrings (tier 3, pattern distinct-substrings, set reserved, for drill)
- Budget: n ≤ 10^5.
- Idea: Build the suffix array and Kasai's LCP array. Distinct substrings = n(n + 1)/2 − Σ LCP (64-bit).
- Techniques: 6.4
- Needs this topic because: each suffix adds the prefixes not shared with its predecessor.
- Tier reasoning: CSES string section.

## cses-2108 Substring Order I (tier 4, pattern distinct-substrings, set practice)
- Budget: n ≤ 10^5, k ≤ n(n + 1)/2.
- Idea: In suffix-array order, suffix sa[i] contributes the new substrings of lengths lcp[i] + 1 .. n − sa[i], in increasing order. Walk until the running count reaches k and print the right prefix.
- Techniques: 6.4
- Needs this topic because: the sorted order of distinct substrings comes from SA + LCP.
- Tier reasoning: CSES string section, later.

## cses-2110 Substring Distribution (tier 4, pattern distinct-substrings, set practice)

- Techniques: 6.4, 1.2

- Tier reasoning: CSES string section, later.

## cses-3225 Inverse Suffix Array (tier 4, pattern sorted-suffixes, set practice)
- Budget: n ≤ 10^5.
- Idea: Let rank be the inverse permutation. Walking the given order, s[sa[i]] = s[sa[i − 1]] is allowed iff rank[sa[i − 1] + 1] < rank[sa[i] + 1] (treating the end as smallest); otherwise move to the next letter. Fail if more than 26 letters are needed.
- Techniques: 6.4
- Needs this topic because: what ordering suffixes implies about adjacent characters.
- Tier reasoning: CSES string section, later.

## cses-1113 String Transform (tier 4, pattern sorted-suffixes, set reserved, for drill)
- Budget: n ≤ 10^6.
- Idea: Inverse Burrows–Wheeler: stably sorting the last column gives the first column; the k-th occurrence of a letter in both columns is the same character. Follow this mapping from '#' to rebuild the string.
- Techniques: 6.4, 1.1
- Needs this topic because: the transform is defined by sorted rotations (sorted suffixes with '#').
- Tier reasoning: CSES string section.

## ac-abc213_f Common Prefixes (tier 5, pattern common-substring, set practice)
- Budget: N ≤ 10^6.
- Idea: For each i, Σ_j LCP(suffix i, suffix j) = sum over SA neighbours of running minima of LCP. Compute left-to-right and right-to-left sums with a monotonic stack, then add N − i for j = i. 64-bit.
- Techniques: 6.4, 1.6
- Needs this topic because: LCP of any two suffixes = minimum of adjacent LCPs between them.
- Tier reasoning: ABC F.

## ac-arc044_d suffix array (tier 5, pattern sorted-suffixes, set practice)
- Budget: N ≤ 10^6.
- Idea: Given a permutation as a suffix array, print the smallest string over A–Z with this suffix array, or −1. With the inverse permutation rank, s[sa[i]] may equal s[sa[i−1]] only if rank[sa[i−1]+1] < rank[sa[i]+1] (an empty rest ranks lowest); otherwise the letter must grow by one. Fail if more than 26 letters are needed.
- Techniques: 6.4
- Needs this topic because: what the order of suffixes says about neighbouring letters; the inverse of the suffix array.
- Tier reasoning: AtCoder Problems difficulty 2335.

## ac-arc050_d Suffix Concat (tier 5, pattern sorted-suffixes, set practice)
- Budget: N ≤ 10^5.
- Idea: Print an order of the suffixes S_1..S_N whose concatenation is smallest. Sort the suffixes by the rule a+b < b+a; comparing two suffixes of the same string needs the LCP of two suffixes (suffix array + sparse table, or a Z-function on the doubled string) to decide in O(1) or O(log n).
- Techniques: 6.4, 6.2
- Needs this topic because: comparing suffixes (and suffix pairs) quickly: LCP of two suffixes.
- Tier reasoning: AtCoder Problems difficulty 2487.

## cf-128B String (tier 3, pattern occurrences-by-order, set reserved, for checkpoint) †
- Budget: |s| ≤ 10^5, k ≤ 10^5 (recalled).
- Idea: (recalled) Print the k-th string in the sorted list of all substrings of s, counting equal substrings at different positions separately. Walk down the implicit trie of the suffix array: keep the block [l, r) of suffixes that begin with the current prefix; the prefix itself occurs r − l times; otherwise subtract that and split the block by the next letter using prefix sums of the numbers of longer substrings. Each step costs at least 1 from k, so at most k steps.
- Techniques: 6.4, 1.4
- Needs this topic because: blocks of the suffix array for a prefix, with counts of substrings below the block.
- Tier reasoning: rating 2100.

## cf-557E Ann and Half-Palindrome (tier 4, pattern sorted-suffixes, set reserved, for exam) †
- Budget: |s| ≤ 5000, k ≤ number of half-palindromes (recalled).
