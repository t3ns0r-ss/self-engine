## cses-1647 Static Range Minimum Queries (tier 2, pattern static-min, set practice)
- Budget: n, q ≤ 2·10^5.
- Idea: Sparse table st[j][i] = min of a[i .. i + 2^j − 1]. Query [a, b]: k = ⌊log2(b − a + 1)⌋, min(st[k][a], st[k][b − 2^k + 1]).
- Techniques: 5.1
- Needs this topic because: the sparse-table template.
- Tier reasoning: first CSES range-query problem with min.

## cf-1709D Rorororobot (tier 2, pattern static-min, set practice) †
- Budget: m ≤ 2·10^5 columns, q ≤ 2·10^5 (recalled).
- Idea: (recalled) Need (xf − xs) and (yf − ys) divisible by k. The robot climbs to the highest row reachable with steps of k from xs; it passes iff the maximum blocked height over columns between ys and yf is below that row. Range max by sparse table.
- Techniques: 5.1
- Needs this topic because: static range maximum per query.
- Tier reasoning: rating 1700.

## cf-514D R2D2 and Droid Army (tier 3, pattern static-min, set practice) †
- Budget: n ≤ 10^5, m ≤ 5 types, k ≤ 10^9 (recalled).
- Idea: (recalled) A window costs Σ over types of the maximum detail count in it. Two pointers on the window, with one sparse table per type for range maximum; keep the longest window with cost ≤ k and print its per-type maxima.
- Techniques: 5.1, 1.3
- Needs this topic because: range maximum inside a two-pointer scan.
- Tier reasoning: rating 2000.

## cf-1691D Max GEQ Sum (tier 3, pattern static-min, set reserved, for review) †
- Budget: Σ n ≤ 2·10^5 (recalled).
- Idea: (recalled) For each i as the maximum, find the range (L, R) where a_i is the maximum (previous/next greater with a stack). The worst subarray containing i has sum max prefix[i..R] − min prefix[L − 1..i − 1]; it must be ≤ a_i. Sparse tables on prefix sums.
- Techniques: 5.1, 1.6, 1.2
- Needs this topic because: range max/min of prefix sums.
- Tier reasoning: rating 1800.

## cf-1696D Permutation Graph (tier 3, pattern static-min, set practice) †
- Budget: Σ n ≤ 2.5·10^5 (recalled).
- Idea: (recalled) Greedy jumps from position 1: if the next value is larger, jump to the position of the maximum of the part before the next smaller element (and symmetrically for smaller). Positions of range max/min from sparse tables, next smaller/greater from a stack.
- Techniques: 5.1, 1.6
- Needs this topic because: arg-max and arg-min on static ranges.
- Tier reasoning: rating 1900.

## cf-1904D2 Set To Max (Hard Version) (tier 3, pattern static-min, set reserved, for exam) †
- Budget: Σ n ≤ 2·10^5 (recalled).
- Idea: (recalled) For each i with a_i < b_i, a source j with a_j = b_i must exist on one side with max a over [j, i] ≤ b_i and min b over [j, i] ≥ b_i. Take the nearest occurrence on each side and check with sparse tables for range max of a and range min of b.
- Techniques: 5.1
- Needs this topic because: two static range queries per position.
- Tier reasoning: rating 1800.

## lc-maximum-number-of-robots-within-budget Maximum Number of Robots Within Budget (tier 4, pattern static-min, set practice)
- Budget: n ≤ 5·10^4, budget ≤ 10^15.
- Idea: Cost of a window = max(chargeTimes) + length · Σ runningCosts. Two pointers; window max by sparse table (or a monotonic deque), sum by prefix sums. 64-bit.
- Techniques: 5.1, 1.3, 1.2
- Needs this topic because: range maximum inside a sliding window.
- Tier reasoning: LeetCode Hard.

## cf-2050F Maximum modulo equality (tier 2, pattern idempotent-op, set practice) †
- Budget: Σ n, Σ q ≤ 2·10^5 (recalled).
- Idea: (recalled) All a_l..a_r are equal mod m iff m divides every adjacent difference. Answer = gcd of |a_{i+1} − a_i| over [l, r − 1] (sparse table of gcd; 0 when l = r).
- Techniques: 5.1, 2.1
- Needs this topic because: gcd is idempotent, so the overlapping-blocks query works.
- Tier reasoning: rating 1700.

## cf-1548B Integers Have Friends (tier 3, pattern idempotent-op, set practice) †
- Budget: Σ n ≤ 2·10^5, values ≤ 10^18 (recalled).
- Idea: (recalled) A friend group mod m means m divides adjacent differences. Find the longest range of differences with gcd > 1 by two pointers with a gcd sparse table; answer + 1. (n = 1 gives 1.)
- Techniques: 5.1, 2.1, 1.3
- Needs this topic because: O(1) range gcd queries inside two pointers.
- Tier reasoning: rating 1800.

## cf-359D Pair of Numbers (tier 3, pattern idempotent-op, set practice) †
- Budget: n ≤ 3·10^5 (recalled).
- Idea: (recalled) A segment is good iff gcd(segment) = min(segment). Binary search the length (good lengths are downward closed) and check all windows with sparse tables for gcd and min; print every l of the best length.
- Techniques: 5.1, 1.4
- Needs this topic because: two idempotent sparse tables.
- Tier reasoning: rating 2000.

## cf-475D CGCDSSQ (tier 3, pattern idempotent-op, set reserved, for review) †
- Budget: n ≤ 10^5, q ≤ 3·10^5 (recalled).
- Idea: (recalled) For a fixed left end, gcd changes at most log(max) times. Jump to the next change by binary search on a gcd sparse table, adding run lengths into a map from gcd to count. Answer queries from the map.
- Techniques: 5.1, 2.1, 0.6
- Needs this topic because: group subarrays by gcd using range gcd queries.
- Tier reasoning: rating 2000.

## cf-1632D New Year Concert (tier 3, pattern idempotent-op, set practice) †
- Budget: n ≤ 2·10^5 (recalled).
- Idea: (recalled) For each r, the bad segment ending at r has gcd(l..r) = r − l + 1; gcd falls and length grows as l moves left, so binary search finds it. Greedily change a_r (to a large prime) when a bad segment starts after the last change.
- Techniques: 5.1, 2.1
- Needs this topic because: range gcd queries drive a greedy.
- Tier reasoning: rating 2000.

## lc-find-a-value-of-a-mysterious-function-closest-to-target Find a Value of a Mysterious Function Closest to Target (tier 4, pattern idempotent-op, set practice)
- Budget: n ≤ 10^5, values ≤ 10^6.
- Idea: AND over [l, r] only falls as l moves left, taking at most 20 distinct values. For each r, binary search on an AND sparse table (or keep the set of distinct ANDs ending at r); minimise |value − target|.
- Techniques: 5.1
- Needs this topic because: AND is idempotent and monotone over ranges.
- Tier reasoning: LeetCode Hard.

## cf-1878E Iva & Pav (tier 1, pattern search-over-ranges, set practice) †
- Budget: Σ n, Σ q ≤ 2·10^5 (recalled).
- Idea: (recalled) AND(a_l..a_r) only falls as r grows. Binary search the largest r with AND ≥ k using an AND sparse table; −1 if a_l < k.
- Techniques: 5.1, 1.4
- Needs this topic because: binary search over O(1) range queries.
- Tier reasoning: rating 1400.

## lc-smallest-subarrays-with-maximum-bitwise-or Smallest Subarrays With Maximum Bitwise OR (tier 3, pattern search-over-ranges, set practice)
- Budget: n ≤ 10^5.
- Idea: For each i, the target is OR(i..n−1). OR(i..j) rises with j, so binary search the smallest j reaching it with an OR sparse table. (Tracking the next position of each bit also works.)
- Techniques: 5.1, 1.4, 1.7
- Needs this topic because: monotone range OR searched by binary search.
- Tier reasoning: LeetCode Medium.

## cf-1547F Array Stabilization (GCD version) (tier 3, pattern search-over-ranges, set reserved, for checkpoint) †
- Budget: Σ n ≤ 2·10^5 (recalled).
- Idea: (recalled) After t steps, b_i = gcd(a_i..a_{i+t}) (cyclically). The answer is the largest, over i, of the smallest t with gcd(a_i..a_{i+t}) = gcd(all). Double the array, sparse table of gcd, binary search per i.
- Techniques: 5.1, 2.1, 1.4
- Needs this topic because: per-position binary search on range gcd.
- Tier reasoning: rating 1900.

## cf-689D Friends and Subsequences (tier 4, pattern search-over-ranges, set reserved, for review) †
- Budget: n ≤ 2·10^5 (recalled).
- Idea: (recalled) For fixed l, max a[l..r] grows and min b[l..r] falls with r, so the r with max = min form a contiguous range. Find its ends with two binary searches on sparse tables; sum the lengths (64-bit).
- Techniques: 5.1, 1.4
- Needs this topic because: two monotone range aggregates compared by binary search.
- Tier reasoning: rating 2100.

## lc-number-of-subarrays-with-and-value-of-k Number of Subarrays With AND Value of K (tier 4, pattern search-over-ranges, set practice)
- Budget: n ≤ 10^5.
- Idea: For each r, AND(l..r) is non-decreasing in l. Two binary searches on an AND sparse table find the l range where it equals k; add its length (64-bit).
- Techniques: 5.1, 1.4
- Needs this topic because: count ranges with an exact aggregate by binary search.
- Tier reasoning: LeetCode Hard.

## lc-find-building-where-alice-and-bob-can-meet Find Building Where Alice and Bob Can Meet (tier 4, pattern search-over-ranges, set practice)
- Budget: n, queries ≤ 5·10^4.
- Idea: Let a ≤ b. If a = b or h[a] < h[b], the answer is b. Otherwise find the leftmost index > b with height > h[a]: binary search on a range-max sparse table; −1 if none.
- Techniques: 5.1, 1.4
- Needs this topic because: "first index after p with value > x" by binary search on range max.
- Tier reasoning: LeetCode Hard.
