## cses-1648 Dynamic Range Sum Queries (tier 2, pattern point-prefix, set reserved, for lookalike)
- Budget: n, q ≤ 2·10^5.
- Idea: Fenwick tree over the array; an update adds (new − old) at k; a query is prefix(b) − prefix(a − 1). 64-bit.
- Techniques: 5.2
- Needs this topic because: look-alike partner of Range Update Queries: point update with range query, so prefix sums of the values.

## ac-abc405_f Chord Crossing (tier 4, pattern offline-sorted-count, set reserved, for lookalike)
- Budget: N ≤ 10^6 (2N points), M, Q ≤ 2·10^5.

## cf-1076E Vasya and a Tree (tier 3, pattern range-add-point, set reserved, for review) †
- Budget: n, m ≤ 3·10^5 (recalled).
- Idea: (recalled) Each update (v, d, x) adds x to every vertex in the subtree of v at depth at most depth(v) + d. Group updates by v and run one DFS from the root. - Techniques: 5.2, 4.1

## cf-540E Infinite Inversions (tier 4, pattern inversions, set reserved, for review) †
- Budget: n ≤ 10^5 swaps, positions ≤ 10^9 (recalled).
- Idea: (recalled) The sequence starts as 1, 2, 3, … and each operation swaps two positions. Collect all positions named in the swaps (at most 2n), sort them (compression), and apply the swaps to the array of their values. Inversions among these touched positions: Fenwick count over ranks, scanning left to right. Between a touched position p holding value v and the untouched positions: the untouched elements strictly between p and v in coordinates each form one inversion with it, which is |v − p| − |rank(v) − rank(p)| (v is itself a touched coordinate). Sum both parts. 64-bit.
- Techniques: 5.2, 1.1
- Needs this topic because: inversion count over compressed values, combined with a gap formula.
- Tier reasoning: rating 2100, the boundary of tiers 3 and 4; the higher is taken.
