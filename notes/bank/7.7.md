## lc-di-string-match DI String Match (tier 2, pattern permutation-build, set reserved, for lookalike)
- Budget: n ≤ 10^5.
- Idea: Keep lo = 0, hi = n. For 'I' output lo++, for 'D' output hi−−; finish with the remaining value. Any valid permutation is accepted.
- Techniques: 7.7
- Needs this topic because: look-alike partner of Construct Smallest Number From DI String: any answer works, so two pointers build it directly.
- Tier reasoning: LeetCode Easy; tier 2 as a look-alike.

## lc-construct-smallest-number-from-di-string Construct Smallest Number From DI String (tier 2, pattern permutation-build, set reserved, for lookalike)
- Budget: pattern length ≤ 8, digits 1–9 once.
- Idea: Start from 1, 2, …, n + 1 and reverse each maximal block covering a run of 'D' (including the position before it); the result is the lexicographically smallest valid number.
- Techniques: 7.7
- Needs this topic because: look-alike partner of DI String Match: the smallest answer is required, so build ascending and reverse runs.
- Tier reasoning: LeetCode Medium.

## lc-beautiful-array Beautiful Array (tier 2, pattern permutation-build, set practice)
- Budget: n ≤ 1000.
