## ac-abc326_c Peak (tier 2, pattern shrinkable-window, set practice)
- Budget: N ≤ 3·10^5 → O(N log N).
- Idea: Sort the coordinates. For each right end r, advance l while A_r − A_l ≥ M; the window [l, r] holds r − l + 1 gifts; take the maximum.
- Techniques: 1.3, 1.1
- Needs this topic because: a valid window stays valid when shrunk, so l only moves forward.
- Tier reasoning: ABC C.

## lc-longest-substring-without-repeating-characters Longest Substring Without Repeating Characters (tier 3, pattern shrinkable-window, set practice)
- Budget: n ≤ 5·10^4 → O(n).
- Idea: Count characters in the window; extend r; while s[r] occurs twice, remove s[l] and advance l. Track the maximum length.
- Techniques: 1.3

- Tier reasoning: LeetCode Medium.
