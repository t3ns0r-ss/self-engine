Solution notes for every bank problem (bank plan Section 7.4). Not shown on the site. † = Codeforces problem checked through the official API only (title, rating, tags); the statement could not be opened from the build environment, so the idea below needs a spot-check on the page.

## ac-dp_d Knapsack 1 (tier 2, pattern zero-one, set reserved, for lookalike)
- Budget: N ≤ 100, W ≤ 10^5.
- Idea: best[w] = max value with weight ≤ w; for each item loop w downward: best[w] = max(best[w], best[w − w_i] + v_i). long long.
- Techniques: 3.3
- Needs this topic because: the 0/1 knapsack template. Look-alike partner of Knapsack 2: same statement, W ≤ 10^5 here, so index by weight.
- Tier reasoning: EDP D.

## ac-dp_e Knapsack 2 (tier 3, pattern value-indexed, set reserved, for lookalike)
- Budget: N ≤ 100, W ≤ 10^9, v_i ≤ 10^3.
- Idea: minW[v] = least weight reaching value exactly v (≤ 10^5 values); loop v downward per item. Answer: largest v with minW[v] ≤ W.
- Techniques: 3.3
- Needs this topic because: look-alike partner of Knapsack 1: W is too large, so swap the roles of weight and value.
- Tier reasoning: EDP E.

## ac-abc145_e All-you-can-eat (tier 4, pattern zero-one, set reserved, for exam)

## ac-abc169_f Knapsack for All Subsets (tier 5, pattern zero-one, set practice)

- Idea: Count (T, U) with U ⊆ T and sum(U) = S. Each element: in U (sum + a), in T only (×1), or not in T (×1). dp[s] = 2·dp[s] + dp[s − a] mod 998244353.
