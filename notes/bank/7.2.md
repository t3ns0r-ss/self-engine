## ac-dp_g Longest Path (tier 2, pattern longest-path, set practice)
- Budget: N, M ≤ 10^5, DAG.
- Idea: Topological order (Kahn); dp[v] = max over edges u → v of dp[u] + 1; answer max dp. Or memoised DFS.
- Techniques: 7.2
- Needs this topic because: longest path in a DAG.

## cf-1472G Moving to the Capital (tier 3, pattern longest-path, set reserved, for checkpoint) †
- Budget: Σ n ≤ 2·10^5 (recalled).
- Idea: (recalled) Breadth-first distances d from the capital. A move along a road u→v with d[v] > d[u] is free; at most once a move with d[v] ≤ d[u] is allowed. dp[v] = min over roads v→u of: d[u] if d[u] ≤ d[v] (the one backward move), or dp[u] if d[u] > d[v]; process vertices by decreasing d. The answer for each start is min(d[v], dp[v]).
- Techniques: 7.2, 4.1
- Needs this topic because: a DP over the DAG formed by the roads that go to a larger distance, processed in order of the distance.
- Tier reasoning: rating 2100.
