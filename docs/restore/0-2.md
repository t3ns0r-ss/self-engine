Current ("Limits on input size"): "n <= 400 O(n^3)", "n <= 7500 O(n^2)", "n <= 5*10^5 O(n log n)", "n <= 5*10^6 O(n)". Current also has rows for n <= 80 (n^4) and n <= 10^5 (n sqrt n) that the old table lacks, and O(log^2 n) at 10^18.
- Speed of the judge. Old: "about 10^8 simple steps per second, accurate to a factor of about 3". Current: "roughly 10^8 to 10^9 simple steps per second", with "at most 10^8 passes" and "at least 10^9 is TLE".
